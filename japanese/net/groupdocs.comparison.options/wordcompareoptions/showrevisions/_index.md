## WordCompareOptions.ShowRevisions property

結果ドキュメントが改訂マークアップを表示したままにするかどうかを取得または設定します。false の場合、すべての改訂が受け入れられ、結果は最終テキストとして表示されます。この設定は [`DisplayMode`](../displaymode) が Highlight に設定されている場合にのみ意味があります。既定値は true です。

```csharp
public bool ShowRevisions { get; set; }
```
