この名前空間は、ドキュメント比較プロセスの追加オプションを指定できるクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [ApplyChangeOptions](./applychangeoptions) | 結果ドキュメントに適用する前に変更リストを更新できます。 |
| [CompareOptions](./compareoptions) | 異なる比較オプションを設定できます。 |
| [DiagramMasterSetting](./diagrammastersetting) | 図のマスター設定。 |
| [FileAuthorMetadata](./fileauthormetadata) | ドキュメントの作者メタデータに関する情報。 |
| [GetChangeOptions](./getchangeoptions) | このオプションはタイプで変更をフィルタリングできます。 |
| [IgnoreChangeSensitivitySettings](./ignorechangesensitivitysettings) | このオプションは類似度パーセンテージで変更を無視できます。 |
| [LoadOptions](./loadoptions) | ドキュメントを読み込む際に追加オプションを指定できます。 |
| [OriginalSize](./originalsize) | 元のページサイズを表します。異なる形式の画像を比較する際にのみ使用されます。 |
| [PagesSetup](./pagessetup) | 比較に含めるページを指定します。 |
| [PdfCompareOptions](./pdfcompareoptions) | PDFドキュメント固有の比較オプション。共通オプションは[`CompareOptions`](../groupdocs.comparison.options/compareoptions)から継承します。 |
| [PreviewOptions](./previewoptions) | ドキュメントプレビューオプションを表します。 |
| [PreviewResolution](./previewresolution) | ドキュメントプレビュー生成の解像度設定を表します。 |
| [SaveOptions](./saveoptions) | ドキュメントを保存する際に追加オプション（パスワードなど）を指定できます。 |
| [Size](./size) | ドキュメントサイズ。 |
| [StyleSettings](./stylesettings) | スタイル設定。変更のスタイルルールを定義できます。[`CompareOptions`](../groupdocs.comparison.options/compareoptions) クラスで使用されます。 |
| [WordCompareOptions](./wordcompareoptions) | Wordドキュメント固有の比較オプション。共通オプションは[`CompareOptions`](../groupdocs.comparison.options/compareoptions)から継承します。 |
