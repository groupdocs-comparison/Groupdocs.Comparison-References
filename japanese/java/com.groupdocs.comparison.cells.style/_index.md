Cells 形式ファイルのコンポーネントスタイルを操作するためのクラスを提供します。


このパッケージのクラスを使用すると、Cells 形式ファイル（例: Excel ファイル）に固有のさまざまなスタイルや書式設定オプションを操作できます。

このパッケージに含まれる主要なクラスは次のとおりです:

* [MergeType](../../com.groupdocs.comparison.cells.style/mergetype) - Represents the enumeration the type of cell merge.


GroupDocs.Comparison for Java を使用した Word 文書の改訂と変更履歴の操作に関する詳細は、
以下の [GroupDocs.Comparison ドキュメント](../https://docs.groupdocs.com/comparison/java/) を参照してください。



## 列挙型

| 列挙 | 説明 |
| --- | --- |
| [MergeType](../com.groupdocs.comparison.cells.style/mergetype) | セル結合のタイプを列挙します。 |
