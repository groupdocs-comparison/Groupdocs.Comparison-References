GroupDocs.Comparison の出力の保存と構成のためのクラスとオプションを提供します。


このパッケージのクラスは、比較プロセスの出力ドキュメントを保存および構成するために使用されます
GroupDocs.Comparison 内です。メタデータの指定、出力ドキュメントのパスワード設定などのオプションを提供します。


このパッケージの主要クラスは [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions) です。
このパッケージのクラスは、さまざまな
出力形式を構成し、比較プロセスの目的の出力ドキュメントを生成できます。


GroupDocs.Comparison を使用した出力の保存と構成に関する詳細は、
以下の [GroupDocs.Comparison ドキュメント](../https://docs.groupdocs.com/comparison/java/) を参照してください。



## クラス

| クラス | 説明 |
| --- | --- |
| [SaveOptions](../com.groupdocs.comparison.options.save/saveoptions) | ドキュメントを保存する際に追加オプションを指定できます。 |
