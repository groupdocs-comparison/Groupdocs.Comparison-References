GroupDocs.Comparison のさまざまなコンポーネントと機能の契約を定義するインターフェイスを提供します。

このパッケージの主なインターフェイスは次のとおりです：

* [IDocumentInfo](../../com.groupdocs.comparison.interfaces/idocumentinfo) - The interface that defines the contract for the information about a document.


このパッケージのインターフェイスは、さまざまな実装および相互作用のために必要な契約を提供します。
GroupDocs.Comparison のコンポーネントと機能です。


GroupDocs.Comparison for Java を使用した Word 文書の改訂と変更履歴の操作に関する詳細は、
以下の [GroupDocs.Comparison ドキュメント](../https://docs.groupdocs.com/comparison/java/) を参照してください。
