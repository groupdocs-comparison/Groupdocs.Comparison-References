GroupDocs.Comparison のローカリゼーション用のクラスとインターフェイスを提供します。ローカリゼーション機能により、異なる言語や地域の設定に基づいて、比較プロセスで表示されるテキストやメッセージをカスタマイズできます。

このパッケージの主なクラスとインターフェイスは次のとおりです:

* [SupportedLocales](../../com.groupdocs.comparison.localization/supportedlocales) - A class provides constants representing the supported locales for GroupDocs.Comparison.


ローカリゼーション機能を使用することで、GroupDocs.Comparison で使用されるテキストやメッセージをユーザーの言語や好みに合わせてカスタマイズできます。


GroupDocs.Comparison for Java を使用した Word 文書の改訂と変更履歴の操作に関する詳細は、
以下の [GroupDocs.Comparison ドキュメント](../https://docs.groupdocs.com/comparison/java/) を参照してください。

| クラス | 説明 |
| --- | --- |
| [SupportedLocales](../com.groupdocs.comparison.localization/supportedlocales) | SupportedLocales クラスは、GroupDocs.Comparison がサポートするロケールを表す定数を提供します。 |
