GroupDocs.Comparison のロギング用クラスとインターフェイスを提供します。ロギング機能により、比較プロセスの実行中にさまざまなイベントやメッセージを記録および監視できます。

このパッケージの主なクラスとインターフェイスは次のとおりです:

* com.groupdocs.comparison.logging.ILogger - The interface that defines the contract for a logger.
* [ComparisonLogger](../../com.groupdocs.comparison.logging/comparisonlogger) - Provides methods and a way to configure integrated or set user defined logger.
* com.groupdocs.comparison.logging.ConsoleLogger - Provides logger implementation which sends all messages to console.


ロギング機能を使用することで、ログメッセージの処理方法をカスタマイズできます,
例えば、ファイルやコンソール、または任意の宛先に書き込むことができます。


GroupDocs.Comparison for Java を使用した Word 文書の改訂と変更履歴の操作に関する詳細は、
以下の [GroupDocs.Comparison ドキュメント](../https://docs.groupdocs.com/comparison/java/) を参照してください。



## クラス

| クラス | 説明 |
| --- | --- |
| [ComparisonLogger](../com.groupdocs.comparison.logging/comparisonlogger) | ロギングメソッドを実装し、統合ロガーまたはユーザー定義ロガーを設定する方法を提供します。 |
| [FileLogger](../com.groupdocs.comparison.logging/filelogger) | ファイルにログを書き込むロガーです。 |
