GroupDocs.Comparison ライセンスを操作するためのクラスを提供します。


このパッケージのクラスを使用すると、GroupDocs.Comparison のライセンスを管理および適用できます。
ライセンスファイルを読み込み設定し、ライセンスの状態を確認し、ライセンス関連の操作を実行できます。


ライセンス関連機能を使用するには、GroupDocs が提供する有効なライセンスファイルが必要です。
ライセンスファイルは、[License](../../com.groupdocs.comparison.license/license) クラスを使用してロードし、GroupDocs.Comparison ライブラリに適用できます。


GroupDocs.Comparison でのライセンスの使用方法の詳細については、以下をご参照ください。
[Licensing FAQ](../https://purchase.groupdocs.com/faqs/licensing).



## クラス

| クラス | 説明 |
| --- | --- |
| [License](../com.groupdocs.comparison.license/license) | License クラスは、GroupDocs.Comparison 用のライセンスを設定および適用するメソッドを提供します。 |
| [Metered](../com.groupdocs.comparison.license/metered) | Comparison に対して従量課金ライセンスを適用するメソッドを提供します。 |
