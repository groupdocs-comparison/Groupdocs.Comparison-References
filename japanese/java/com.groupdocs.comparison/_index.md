このパッケージは、すべての一般的な文書形式の比較用クラスを提供します。

このパッケージの主要クラスは以下です:

* [Comparer](../../com.groupdocs.comparison/comparer) is the entry point for comparing documents.
* [Document](../../com.groupdocs.comparison/document) provides details about a document.
* [ComparerSettings](../../com.groupdocs.comparison/comparersettings) defines settings for customizing logging behaviour.


この名前空間の主要クラスは [Comparer](../../com.groupdocs.comparison/comparer) です。このクラスはドキュメントの追加、変更の取得、ドキュメントの比較などのメソッドを提供します。



## クラス

| クラス | 説明 |
| --- | --- |
| [Comparer](../com.groupdocs.comparison/comparer) | Comparer クラスは、ドキュメントの比較と比較結果の生成機能を提供します。 |
| [ComparerSettings](../com.groupdocs.comparison/comparersettings) | [Comparer](../com.groupdocs.comparison/comparer) クラスの動作をカスタマイズするための設定を定義します。 |
| [Document](../com.groupdocs.comparison/document) | 比較プロセス用のドキュメントを表します。 |
