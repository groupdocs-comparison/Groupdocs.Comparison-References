GroupDocs.Comparison API を使用する際に役立つメソッドを備えたユーティリティクラスを提供します。


このパッケージのクラスは、さまざまなユーティリティメソッドを提供し、
GroupDocs.Comparison API を使用した文書比較に関連する一般的なタスクの実行を支援します。

このパッケージに含まれる主要なクラスは次のとおりです:

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


これらのユーティリティクラスは、一般的なタスクを簡素化し、
GroupDocs.Comparison API を使用した文書比較のコンテキストで、ファイル、パス、ストリームの操作のための便利なメソッドを提供します。


GroupDocs.Comparison for Java を使用した Word 文書の改訂と変更履歴の操作に関する詳細は、
以下の [GroupDocs.Comparison ドキュメント](../https://docs.groupdocs.com/comparison/java/) を参照してください。

| クラス | 説明 |
| --- | --- |
