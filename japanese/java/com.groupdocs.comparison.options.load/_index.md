GroupDocs.Comparison で文書の読み込みを構成するためのクラスとオプションを提供します。


このパッケージのクラスは、特定のオプションを使用してソースおよびターゲット文書をロードするために使用されます。
これらは、文書形式の指定やパスワードで保護された文書のロードなどのオプションを提供します、
フォントディレクトリの設定など、その他の機能も提供します。


このパッケージの主要クラスは [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions) です。
パッケージ内のクラスは、さまざまな
正確でカスタマイズされた文書比較のための文書形式。


GroupDocs.Comparison を使用した文書のロードおよび構成の詳細については、
以下の [GroupDocs.Comparison ドキュメント](../https://docs.groupdocs.com/comparison/java/) を参照してください。



## クラス

| クラス | 説明 |
| --- | --- |
| [LoadOptions](../com.groupdocs.comparison.options.load/loadoptions) | 文書をロードする際に追加オプションを指定できます。 |
