GroupDocs.Comparison の文書比較出力の視覚的外観をスタイリングおよび構成するためのクラスとオプションを提供します。


このパッケージのクラスは、色など、文書比較出力のさまざまなスタイリング要素を定義およびカスタマイズするために使用されます。
ハイライト、下線なども含まれます。これらにより、比較結果における追加、削除、変更されたコンテンツの視覚的外観を制御できます。


このパッケージの主要クラスは [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings) を含みます。
パッケージ内のクラスは、比較結果のさまざまなコンポーネントや要素のスタイル設定を定義および構成するためのメソッドとプロパティを提供します。
フォントスタイル、色、ハイライト、下線、その他の書式設定オプションを設定して、変更の望ましい視覚表現を実現できます。


GroupDocs.Comparison を使用した文書比較出力の外観のスタイリングと構成に関する詳細は、
以下の [GroupDocs.Comparison ドキュメント](../https://docs.groupdocs.com/comparison/java/) を参照してください。



## クラス

| クラス | 説明 |
| --- | --- |
| [DiagramMasterSetting](../com.groupdocs.comparison.options.style/diagrammastersetting) | 図マスタ比較の設定を表します。 |
| [Size](../com.groupdocs.comparison.options.style/size) | 比較におけるドキュメントのサイズを表します。 |
| [StyleSettings](../com.groupdocs.comparison.options.style/stylesettings) | このクラスはテキスト書式設定のスタイル設定を表します。 |

## 列挙型

| 列挙 | 説明 |
| --- | --- |
| [DetalisationLevel](../com.groupdocs.comparison.options.style/detalisationlevel) | 比較詳細のレベルを指定します。 |
