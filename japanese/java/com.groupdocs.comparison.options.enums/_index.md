GroupDocs.Comparison のさまざまなオプションと設定の列挙型を提供します。


このパッケージのクラスには、さまざまなオプションや設定を定義する列挙型が含まれています
GroupDocs.Comparison でカスタマイズおよび構成目的で使用されます。
これらの列挙型は、さまざまなメソッドやクラスのパラメータとして使用され、動作を制御します
およびドキュメント比較プロセスの外観を制御します。


このパッケージの主要な列挙型のいくつかには、[ChangeType](../../com.groupdocs.comparison.result/changetype) が含まれます、
com.groupdocs.comparison.cells.style.ComparisonStyle、その他多数。
これらの列挙型を使用すると、変更のタイプや比較のスタイルを取得できます
およびドキュメント比較プロセスのその他のオプションを取得できます。


利用可能なオプションとそれらの GroupDocs.Comparison での使用方法に関する詳細は、
以下の [GroupDocs.Comparison ドキュメント](../https://docs.groupdocs.com/comparison/java/) を参照してください。



## 列挙型

| 列挙 | 説明 |
| --- | --- |
| [ComparisonType](../com.groupdocs.comparison.options.enums/comparisontype) | 実行される比較のタイプを表します。 |
| [FolderComparisonExtension](../com.groupdocs.comparison.options.enums/foldercomparisonextension) | FolderComparisonExtension クラスは、フォルダー比較で使用できるさまざまなファイル拡張子を表す列挙型です。 |
| [MetadataType](../com.groupdocs.comparison.options.enums/metadatatype) | 結果ドキュメントがメタデータ情報を取得する場所を決定します。 |
| [PaperSize](../com.groupdocs.comparison.options.enums/papersize) | 文書比較の用紙サイズオプションを表します。 |
| [PasswordSaveOption](../com.groupdocs.comparison.options.enums/passwordsaveoption) | 比較プロセス中に文書のパスワード情報を保存するオプションを列挙します。 |
| [PreviewFormats](../com.groupdocs.comparison.options.enums/previewformats) | 文書比較でサポートされているプレビュー形式を列挙します。 |
