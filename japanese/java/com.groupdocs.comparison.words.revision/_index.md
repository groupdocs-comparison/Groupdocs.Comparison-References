Java 用 GroupDocs.Comparison の比較プロセス中に Word 文書のリビジョンと変更履歴を表すクラスとインターフェイスを提供します。


このパッケージのクラスは、比較プロセス中に Word 文書に加えられた改訂と変更履歴を表すために使用されます。
これらの改訂には、挿入、削除、書式変更、および文書内容のその他の変更が含まれます。


このパッケージに含まれる主要なクラスは [RevisionHandler](../../com.groupdocs.comparison.words.revision/revisionhandler),
[RevisionAction](../../com.groupdocs.comparison.words.revision/revisionaction), and [RevisionInfo](../../com.groupdocs.comparison.words.revision/revisioninfo).


このパッケージのクラスとインターフェイスを使用することで、Word 文書の改訂と変更履歴にアクセス、分析、操作できます。


GroupDocs.Comparison for Java を使用した Word 文書の改訂と変更履歴の操作に関する詳細は、
以下の [GroupDocs.Comparison ドキュメント](../https://docs.groupdocs.com/comparison/java/) を参照してください。



## クラス

| クラス | 説明 |
| --- | --- |
| [ApplyRevisionOptions](../com.groupdocs.comparison.words.revision/applyrevisionoptions) | ApplyRevisionOptions クラスは、改訂が最終文書に適用される前にその状態を更新できるようにします。 |
| [RevisionHandler](../com.groupdocs.comparison.words.revision/revisionhandler) | 改訂の処理を制御するクラスを表します。 |
| [RevisionInfo](../com.groupdocs.comparison.words.revision/revisioninfo) | 文書内の改訂を表します。 |

## 列挙型

| 列挙 | 説明 |
| --- | --- |
| [RevisionAction](../com.groupdocs.comparison.words.revision/revisionaction) | リビジョンに適用できるアクションを表します。 |
| [RevisionType](../com.groupdocs.comparison.words.revision/revisiontype) | ドキュメント内のリビジョンの種類を表します。 |
