ドキュメント比較に関連するさまざまなオプションや設定を構成するためのクラスとインターフェイスを提供します。これらのオプションには比較設定、ロードオプション、保存オプション、スタイル設定などが含まれます。これらのクラスを使用して、ドキュメント比較プロセスの動作と外観をカスタマイズします。

このパッケージの主要クラス:

* [CompareOptions](../../com.groupdocs.comparison.options/compareoptions) - Represents the options for document comparison.
* [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions) - Represents the options for loading documents.
* [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions) - Represents the options for saving comparison results.
* [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings) - Represents style settings for text formatting.


Java 用の GroupDocs.Comparison を使用したオプション クラスの操作に関する詳細は、
以下の [GroupDocs.Comparison ドキュメント](../https://docs.groupdocs.com/comparison/java/) を参照してください。



## クラス

| クラス | 説明 |
| --- | --- |
| [ApplyChangeOptions](../com.groupdocs.comparison.options/applychangeoptions) | 結果のドキュメントに適用する前に、変更リストを更新できるようにします。 |
| [CompareOptions](../com.groupdocs.comparison.options/compareoptions) | ドキュメント比較プロセスの構成を可能にします。 |
| [FileAuthorMetadata](../com.groupdocs.comparison.options/fileauthormetadata) | ドキュメントの作成者メタデータに関する情報の構成を可能にします。 |
| [GetChangeOptions](../com.groupdocs.comparison.options/getchangeoptions) | 比較結果から特定の変更タイプを取得するためのフィルタリングの構成を可能にします。 |
| [OriginalSize](../com.groupdocs.comparison.options/originalsize) | 比較結果におけるドキュメントの元のサイズを表します。 |
| [PreviewOptions](../com.groupdocs.comparison.options/previewoptions) | 比較プロセスでドキュメントプレビューを生成するためのオプションを提供します。 |
