Предоставляет классы и параметры для настройки загрузки документов в GroupDocs.Comparison.


Классы в этом пакете используются для загрузки исходных и целевых документов с определёнными параметрами.
Они предоставляют параметры для указания форматов документов, загрузки документов, защищённых паролем,
установки каталогов шрифтов и прочего.


Ключевой класс в этом пакете — [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions).
Классы в пакете позволяют вам настраивать конкретные параметры и настройки, связанные с различными
форматами документов для точного и индивидуального сравнения документов.


Для получения более подробной информации о загрузке и настройке документов с использованием GroupDocs.Comparison,
пожалуйста, обратитесь к [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
