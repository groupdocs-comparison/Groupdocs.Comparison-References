Предоставляет классы и параметры для стилизации и настройки визуального вида вывода сравнения документов в GroupDocs.Comparison.


Классы в этом пакете используются для определения и настройки различных аспектов стилизации вывода сравнения документов, таких как цвета,
выделение, подчеркивание и другое. Они позволяют контролировать визуальное представление добавленного, удалённого и изменённого контента в результате сравнения.


Ключевой класс в этом пакете включает [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings).
Классы в пакете предоставляют методы и свойства для определения и настройки параметров стиля различных компонентов и элементов результата сравнения.
Вы можете задавать стили шрифтов, цвета, выделение, подчеркивание и другие параметры форматирования, чтобы достичь желаемого визуального представления изменений.


Для получения более подробной информации о стилизации и настройке внешнего вида вывода сравнения документов с использованием GroupDocs.Comparison,
пожалуйста, обратитесь к [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Классы

| Класс | Описание |
| --- | --- |
| [DiagramMasterSetting](../com.groupdocs.comparison.options.style/diagrammastersetting) | Представляет настройки сравнения главной диаграммы. |
| [Size](../com.groupdocs.comparison.options.style/size) | Представляет размер документа при сравнении. |
| [StyleSettings](../com.groupdocs.comparison.options.style/stylesettings) | Этот класс представляет параметры стиля для форматирования текста. |
