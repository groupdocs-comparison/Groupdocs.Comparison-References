Предоставляет функциональные интерфейсы, позволяющие получать данные страниц во время процесса сравнения документов.

Функциональные интерфейсы в этом пакете используются для доступа к данным страниц при выполнении сравнения документов с помощью GroupDocs.Comparison.

Основные функциональные интерфейсы в этом пакете:

* [CreatePageStreamFunction](../../com.groupdocs.comparison.common.function/createpagestreamfunction) - Allows handling creating output stream used by Comparison to save pages data.
* [ReleasePageStreamFunction](../../com.groupdocs.comparison.common.function/releasepagestreamfunction) - Allows handling releasing output stream used by Comparison to save pages data.


Эти функциональные интерфейсы могут использоваться для определения пользовательской логики и поведения при работе со страницами документа.
Они предоставляют гибкость для настройки того, как и где сохраняются и обрабатываются страницы.


Для получения более подробной информации о работе с ревизиями и отслеживаемыми изменениями в документах Word с использованием GroupDocs.Comparison для Java,
пожалуйста, обратитесь к [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Интерфейсы

| Интерфейс | Описание |
| --- | --- |
| [CreatePageStreamFunction](../com.groupdocs.comparison.common.function/createpagestreamfunction) | Функциональный интерфейс, который используется для создания выходного потока, используемого Comparison для сохранения изображения предварительного просмотра. |
| [ReleasePageStreamFunction](../com.groupdocs.comparison.common.function/releasepagestreamfunction) | Функциональный интерфейс, который используется для закрытия выходного потока, использованного Comparison для сохранения изображения предварительного просмотра. |
