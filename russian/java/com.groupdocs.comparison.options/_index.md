Предоставляет классы и интерфейсы для настройки различных параметров и настроек, связанных со сравнением документов. Эти параметры включают настройки сравнения, параметры загрузки, параметры сохранения, настройки стиля и многое другое. Используйте эти классы для настройки поведения и внешнего вида процесса сравнения документов.

Ключевые классы в этом пакете:

* [CompareOptions](../../com.groupdocs.comparison.options/compareoptions) - Represents the options for document comparison.
* [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions) - Represents the options for loading documents.
* [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions) - Represents the options for saving comparison results.
* [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings) - Represents style settings for text formatting.


Для получения дополнительной информации о работе с классами параметров с использованием GroupDocs.Comparison для Java,
пожалуйста, обратитесь к [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
