Предоставляет классы и интерфейсы для работы с результатом сравнения документов. Результат сравнения включает информацию об изменениях, редакциях, различиях и других данных, связанных со сравнением.

Ключевые классы в этом пакете:

* [ChangeInfo](../../com.groupdocs.comparison.result/changeinfo) - Represents information about a specific change in the comparison result.
* [PageInfo](../../com.groupdocs.comparison.result/pageinfo) - Represents information about a page in the comparison result.
* [StyleChangeInfo](../../com.groupdocs.comparison.result/stylechangeinfo) - Represents information about a style change in a compared document.


Для получения более подробной информации о работе с результатом процесса сравнения с использованием GroupDocs.Comparison для Java,
пожалуйста, обратитесь к [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Классы

| Класс | Описание |
| --- | --- |
| [ChangeInfo](../com.groupdocs.comparison.result/changeinfo) | Класс ChangeInfo представляет информацию о конкретном изменении в сравнении документов. |
| [PageInfo](../com.groupdocs.comparison.result/pageinfo) | Класс PageInfo представляет информацию о конкретной странице в документе. |
| [Rectangle](../com.groupdocs.comparison.result/rectangle) | Класс Rectangle представляет изменённую область в документе. |
| [StyleChangeInfo](../com.groupdocs.comparison.result/stylechangeinfo) | Класс StyleChangeInfo представляет информацию об изменении стиля в сравниваемом документе. |
