Предоставляет классы для работы с лицензией GroupDocs.Comparison.


Классы в этом пакете позволяют управлять и применять лицензии для GroupDocs.Comparison.
Вы можете загрузить и установить файл лицензии, проверить статус лицензии и выполнять операции, связанные с лицензией.


Чтобы использовать функции, связанные с лицензией, вам нужен действительный файл лицензии, предоставленный GroupDocs.
Вы можете загрузить файл лицензии, используя класс [License](../../com.groupdocs.comparison.license/license), а затем применить его к библиотеке GroupDocs.Comparison.


Для получения более подробной информации о том, как работать с лицензиями в GroupDocs.Comparison, пожалуйста, обратитесь к
[Licensing FAQ](../https://purchase.groupdocs.com/faqs/licensing).

| Класс | Описание |
| --- | --- |
| [License](../com.groupdocs.comparison.license/license) | Класс License предоставляет методы для установки и применения лицензий для GroupDocs.Comparison. |
| [Metered](../com.groupdocs.comparison.license/metered) | Предоставляет методы для применения измеряемой лицензии к Comparison. |
