Предоставляет вспомогательные классы с методами, которые могут быть полезны при использовании API GroupDocs.Comparison.


Классы в этом пакете предлагают различные вспомогательные методы, которые могут помочь в работе
с API GroupDocs.Comparison и выполнении общих задач, связанных со сравнением документов.

Ключевые классы в этом пакете включают:

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


Эти вспомогательные классы направлены на упрощение общих задач и предоставление удобных методов для работы
с файлами, путями и потоками в контексте сравнения документов с использованием API GroupDocs.Comparison.


Для получения более подробной информации о работе с ревизиями и отслеживаемыми изменениями в документах Word с использованием GroupDocs.Comparison для Java,
пожалуйста, обратитесь к [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
