Предоставляет классы для работы со стилями компонентов в файлах формата Cells.


Классы в этом пакете позволяют работать с различными стилями и параметрами форматирования, специфичными для файлов формата Cells (например, файлов Excel).

Ключевые классы в этом пакете включают:

* [MergeType](../../com.groupdocs.comparison.cells.style/mergetype) - Represents the enumeration the type of cell merge.


Для получения более подробной информации о работе с ревизиями и отслеживаемыми изменениями в документах Word с использованием GroupDocs.Comparison для Java,
пожалуйста, обратитесь к [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
