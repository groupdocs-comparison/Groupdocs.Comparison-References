Пакет предоставляет классы для сравнения документов всех популярных форматов.

Основные классы в этом пакете:

* [Comparer](../../com.groupdocs.comparison/comparer) is the entry point for comparing documents.
* [Document](../../com.groupdocs.comparison/document) provides details about a document.
* [ComparerSettings](../../com.groupdocs.comparison/comparersettings) defines settings for customizing logging behaviour.


Основной класс этого пространства имён — [Comparer](../../com.groupdocs.comparison/comparer). Этот класс предоставляет методы для добавления документов, получения изменений, сравнения документов и т.д.

| Класс | Описание |

| [ComparerSettings](../com.groupdocs.comparison/comparersettings) | Определяет настройки для настройки поведения класса [Comparer](../com.groupdocs.comparison/comparer). |
| [Document](../com.groupdocs.comparison/document) | Представляет документ для процесса сравнения. |
