Предоставляет интерфейсы, определяющие контракты для различных компонентов и функций в GroupDocs.Comparison.

Основные интерфейсы в этом пакете:

* [IDocumentInfo](../../com.groupdocs.comparison.interfaces/idocumentinfo) - The interface that defines the contract for the information about a document.


Интерфейсы в этом пакете предоставляют необходимые контракты для реализации и взаимодействия с различными
компонентами и функциональностью в GroupDocs.Comparison.


Для получения более подробной информации о работе с ревизиями и отслеживаемыми изменениями в документах Word с использованием GroupDocs.Comparison для Java,
пожалуйста, обратитесь к [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Интерфейсы

| Интерфейс | Описание |
| --- | --- |
| [IDocumentInfo](../com.groupdocs.comparison.interfaces/idocumentinfo) | Обеспечивает доступ к свойствам документа. |
