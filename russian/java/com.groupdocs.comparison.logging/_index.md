Предоставляет классы и интерфейсы для логирования в GroupDocs.Comparison. Функциональность логирования позволяет записывать и отслеживать различные события и сообщения во время выполнения процесса сравнения.

Основные классы и интерфейсы в этом пакете:

* com.groupdocs.comparison.logging.ILogger - The interface that defines the contract for a logger.
* [ComparisonLogger](../../com.groupdocs.comparison.logging/comparisonlogger) - Provides methods and a way to configure integrated or set user defined logger.
* com.groupdocs.comparison.logging.ConsoleLogger - Provides logger implementation which sends all messages to console.


Используя функциональность логирования, вы можете настроить обработку сообщений журнала,
например, записывать их в файл, консоль или любое другое выбранное вами место назначения.


Для получения более подробной информации о работе с ревизиями и отслеживаемыми изменениями в документах Word с использованием GroupDocs.Comparison для Java,
пожалуйста, обратитесь к [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
