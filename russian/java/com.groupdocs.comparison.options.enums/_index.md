Предоставляет перечисления для различных параметров и настроек в GroupDocs.Comparison.


Классы в этом пакете содержат перечисления, определяющие различные параметры и настройки
используемые в GroupDocs.Comparison для целей настройки и конфигурации.
Эти перечисления используются в качестве параметров в различных методах и классах для управления поведением
и внешним видом процесса сравнения документов.


Некоторые из ключевых перечислений в этом пакете включают [ChangeType](../../com.groupdocs.comparison.result/changetype),
com.groupdocs.comparison.cells.style.ComparisonStyle и многое другое.
Эти перечисления позволяют получить тип изменений, стиль сравнения
и другие параметры для процесса сравнения документов.


Для получения дополнительной информации о доступных параметрах и о том, как их использовать в GroupDocs.Comparison,
пожалуйста, обратитесь к [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Перечисления

| Перечисление | Описание |
| --- | --- |
| [ComparisonType](../com.groupdocs.comparison.options.enums/comparisontype) | Представляет тип сравнения, который будет выполнен. |
| [FolderComparisonExtension](../com.groupdocs.comparison.options.enums/foldercomparisonextension) | Класс FolderComparisonExtension является перечислением, представляющим различные расширения файлов, которые могут использоваться при сравнении папок. |
| [MetadataType](../com.groupdocs.comparison.options.enums/metadatatype) | Определяет, откуда документ результата будет получать метаданные. |
| [PaperSize](../com.groupdocs.comparison.options.enums/papersize) | Представляет варианты размеров бумаги для сравнения документов. |
| [PasswordSaveOption](../com.groupdocs.comparison.options.enums/passwordsaveoption) | Перечисляет варианты сохранения информации о пароле в документе во время процесса сравнения. |
| [PreviewFormats](../com.groupdocs.comparison.options.enums/previewformats) | Перечисляет поддерживаемые форматы предварительного просмотра для сравнения документов. |
