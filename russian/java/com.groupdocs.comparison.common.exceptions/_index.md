Предоставляет исключения, которые могут быть выброшены во время процесса сравнения в GroupDocs.Comparison.

Основные классы исключений в этом пакете:

* [ComparisonException](../../com.groupdocs.comparison.common.exceptions/comparisonexception) - The base exception class for all exceptions related to document comparison.
* [InvalidPasswordException](../../com.groupdocs.comparison.common.exceptions/invalidpasswordexception) - The exception that is thrown when an invalid password is provided for a password-protected document.
* [UnsupportedFileFormatException](../../com.groupdocs.comparison.common.exceptions/unsupportedfileformatexception) - The exception that is thrown when file of this format is not supported by Comparison.


Исключения в этом пакете предоставляют специфическую обработку ошибок и отчетность для общих операций в GroupDocs.Comparison.
Они позволяют более детально обнаруживать и обрабатывать ошибки, позволяя разработчикам адекватно реагировать на различные сценарии ошибок.


Для получения более подробной информации о работе с ревизиями и отслеживаемыми изменениями в документах Word с использованием GroupDocs.Comparison для Java,
пожалуйста, обратитесь к [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Классы

| Класс | Описание |
| --- | --- |
| [ComparisonException](../com.groupdocs.comparison.common.exceptions/comparisonexception) | Базовый класс для всех исключений, которые выбрасываются при использовании API сравнения. |
| [DocumentComparisonException](../com.groupdocs.comparison.common.exceptions/documentcomparisonexception) | Исключение, которое выбрасывается, когда происходит ошибка при сравнении документов. |
| [FileFormatException](../com.groupdocs.comparison.common.exceptions/fileformatexception) | Исключение, которое выбрасывается при сравнении файлов с разными типами сравнения. |
| [InvalidPasswordException](../com.groupdocs.comparison.common.exceptions/invalidpasswordexception) | Исключение, которое выбрасывается, когда указанный пароль неверен. |
| [PasswordProtectedFileException](../com.groupdocs.comparison.common.exceptions/passwordprotectedfileexception) | Исключение, которое выбрасывается, когда документ защищен паролем, но пароль не был предоставлен. |
| [UnsupportedFileFormatException](../com.groupdocs.comparison.common.exceptions/unsupportedfileformatexception) | Исключение, которое выбрасывается, когда файл этого формата не поддерживается сравнением. |
