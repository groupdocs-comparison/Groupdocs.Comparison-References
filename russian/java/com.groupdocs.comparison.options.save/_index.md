Предоставляет классы и параметры для сохранения и настройки вывода GroupDocs.Comparison.


Классы в этом пакете используются для сохранения и настройки выходного документа процесса сравнения
в GroupDocs.Comparison. Они предоставляют параметры для указания метаданных, пароля выходного документа и многое другое.


Ключевой класс в этом пакете — [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions).
Классы в этом пакете позволяют настраивать конкретные параметры и настройки, связанные с различными
форматами вывода для создания требуемого выходного документа процесса сравнения.


Для получения более подробной информации о сохранении и настройке вывода с использованием GroupDocs.Comparison,
пожалуйста, обратитесь к [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
