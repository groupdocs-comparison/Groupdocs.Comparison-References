Это пространство имён предоставляет различные классы исключений.

## Классы

| Класс | Описание |
| --- | --- |
| [ComparisonException](./comparisonexception) | Базовый класс для всех исключений процесса сравнения. |
| [DocumentComparisonException](./documentcomparisonexception) | Исключение, которое выбрасывается, когда происходит ошибка при сравнении документов. |
| [FileFormatException](./fileformatexception) | Исключение, которое выбрасывается при сравнении файлов разных форматов. |
| [InvalidPasswordException](./invalidpasswordexception) | Исключение, которое выбрасывается, когда указанный пароль неверен. |
| [PasswordProtectedFileException](./passwordprotectedfileexception) | Исключение, которое выбрасывается, когда документ защищён паролем. |
| [UnsupportedFileFormatException](./unsupportedfileformatexception) | Исключение, которое выбрасывается, когда файл этого формата не поддерживает сравнение. |
