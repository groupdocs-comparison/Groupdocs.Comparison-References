Это пространство имён предоставляет классы, позволяющие задавать дополнительные параметры процесса сравнения документов.

## Классы

| Класс | Описание |
| --- | --- |
| [ApplyChangeOptions](./applychangeoptions) | Позволяет обновить список изменений перед их применением к результирующему документу. |
| [CompareOptions](./compareoptions) | Позволяет установить различные параметры сравнения. |
| [DiagramMasterSetting](./diagrammastersetting) | Настройки главного шаблона диаграммы. |
| [FileAuthorMetadata](./fileauthormetadata) | Информация о метаданных автора документа. |
| [GetChangeOptions](./getchangeoptions) | Опция позволяет фильтровать изменения по типу. |
| [IgnoreChangeSensitivitySettings](./ignorechangesensitivitysettings) | Опция позволяет игнорировать изменения по проценту схожести. |
| [LoadOptions](./loadoptions) | Позволяет указать дополнительные параметры при загрузке документа. |
| [OriginalSize](./originalsize) | Представляет оригинальный размер страницы. Используется только для сравнения изображений разных форматов. |
| [PagesSetup](./pagessetup) | Указывает, какие страницы включать в сравнение. |
| [PdfCompareOptions](./pdfcompareoptions) | Специфические параметры сравнения PDF‑документа. Наследует общие параметры от [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
| [PreviewOptions](./previewoptions) | Представляет параметры предварительного просмотра документа. |
| [PreviewResolution](./previewresolution) | Представляет настройки разрешения для генерации предварительного просмотра документа. |
| [SaveOptions](./saveoptions) | Позволяет указать дополнительные параметры (например, пароль) при сохранении документа. |
| [Size](./size) | Размер документа. |
| [StyleSettings](./stylesettings) | Настройки стиля. Позволяет определить правила стиля для изменений. Используется в классе [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
| [WordCompareOptions](./wordcompareoptions) | Специфические параметры сравнения Word‑документа. Наследует общие параметры от [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
