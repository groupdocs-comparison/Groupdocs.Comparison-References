## PreviewFormats enumeration

Поддерживаемые форматы предварительного просмотра документа.

```csharp
public enum PreviewFormats
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| PNG | `0` | Png (по умолчанию), может занимать много места на диске / трафика, если страница содержит много цветной графики. |
| JPEG | `1` | Jpeg — более быстрая обработка, небольшое использование дискового пространства / трафика, но может быть худшего качества. |
| BMP | `2` | BMP — медленная обработка, большое использование дискового пространства / трафика, но лучшего качества. |
