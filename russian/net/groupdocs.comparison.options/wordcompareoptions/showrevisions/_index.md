## WordCompareOptions.ShowRevisions property

Получает или задает, отображается ли разметка правок в результирующем документе. Если false, все правки принимаются, и результат выглядит как окончательный текст. Эта настройка имеет смысл только когда [`DisplayMode`](../displaymode) установлен в Highlight. Значение по умолчанию — true.

```csharp
public bool ShowRevisions { get; set; }
```
