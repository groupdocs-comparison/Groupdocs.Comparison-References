Ο χώρος ονομάτων παρέχει διαφορετικές κλάσεις εξαιρέσεων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ComparisonException](./comparisonexception) | Βασική κλάση για όλες τις εξαιρέσεις της διαδικασίας σύγκρισης. |
| [DocumentComparisonException](./documentcomparisonexception) | Η εξαίρεση που προκαλείται όταν συμβαίνει σφάλμα κατά τη σύγκριση εγγράφων. |
| [FileFormatException](./fileformatexception) | Η εξαίρεση που προκαλείται όταν συγκρίνονται αρχεία με διαφορετικές μορφές. |
| [InvalidPasswordException](./invalidpasswordexception) | Η εξαίρεση που προκαλείται όταν ο καθορισμένος κωδικός είναι λανθασμένος. |
| [PasswordProtectedFileException](./passwordprotectedfileexception) | Η εξαίρεση που προκαλείται όταν το έγγραφο είναι προστατευμένο με κωδικό. |
| [UnsupportedFileFormatException](./unsupportedfileformatexception) | Η εξαίρεση που προκαλείται όταν αρχείο αυτής της μορφής δεν υποστηρίζει σύγκριση. |
