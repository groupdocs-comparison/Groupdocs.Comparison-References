## WordCompareOptions.ShowRevisions property

Λαμβάνει ή ορίζει αν το τελικό έγγραφο διατηρεί την επισήμανση αναθεώρησης ορατή. Εάν είναι ψευδές, όλες οι αναθεωρήσεις γίνονται αποδεκτές και το αποτέλεσμα εμφανίζεται ως τελικό κείμενο. Αυτή η ρύθμιση είναι σημαντική μόνο όταν το [`DisplayMode`](../displaymode) ορίζεται σε Highlight. Η προεπιλεγμένη τιμή είναι true.

```csharp
public bool ShowRevisions { get; set; }
```
