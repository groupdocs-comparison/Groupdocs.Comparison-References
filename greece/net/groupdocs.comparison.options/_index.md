Ο χώρος ονομάτων παρέχει κλάσεις που επιτρέπουν τον καθορισμό πρόσθετων επιλογών για τη διαδικασία σύγκρισης εγγράφων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ApplyChangeOptions](./applychangeoptions) | Επιτρέπει την ενημέρωση της λίστας των αλλαγών πριν την εφαρμογή τους στο τελικό έγγραφο. |
| [CompareOptions](./compareoptions) | Επιτρέπει τον ορισμό διαφορετικών επιλογών σύγκρισης. |
| [DiagramMasterSetting](./diagrammastersetting) | Κύριες ρυθμίσεις διαγράμματος. |
| [FileAuthorMetadata](./fileauthormetadata) | Πληροφορίες σχετικά με τα μεταδεδομένα του συγγραφέα του εγγράφου. |
| [GetChangeOptions](./getchangeoptions) | Η επιλογή επιτρέπει το φιλτράρισμα των αλλαγών ανά τύπο. |
| [IgnoreChangeSensitivitySettings](./ignorechangesensitivitysettings) | Η επιλογή επιτρέπει την παράβλεψη των αλλαγών βάσει ποσοστού ομοιότητας. |
| [LoadOptions](./loadoptions) | Επιτρέπει τον καθορισμό πρόσθετων επιλογών κατά τη φόρτωση ενός εγγράφου. |
| [OriginalSize](./originalsize) | Αντιπροσωπεύει το αρχικό μέγεθος σελίδας. Χρησιμοποιείται μόνο για τη σύγκριση εικόνας με διαφορετικές μορφές. |
| [PagesSetup](./pagessetup) | Καθορίζει ποιες σελίδες θα συμπεριληφθούν στη σύγκριση. |
| [PdfCompareOptions](./pdfcompareoptions) | Ειδικές επιλογές σύγκρισης εγγράφου PDF. Κληρονομεί τις κοινές επιλογές από [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
| [PreviewOptions](./previewoptions) | Αντιπροσωπεύει τις επιλογές προεπισκόπησης εγγράφου. |
| [PreviewResolution](./previewresolution) | Αντιπροσωπεύει τις ρυθμίσεις ανάλυσης για τη δημιουργία προεπισκόπησης εγγράφου. |
| [SaveOptions](./saveoptions) | Επιτρέπει τον καθορισμό πρόσθετων επιλογών (όπως κωδικός πρόσβασης) κατά την αποθήκευση ενός εγγράφου. |
| [Size](./size) | Μέγεθος εγγράφου. |
| [StyleSettings](./stylesettings) | Ρυθμίσεις στυλ. Επιτρέπει τον ορισμό κανόνων στυλ για τις αλλαγές. Χρησιμοποιείται στην κλάση [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
| [WordCompareOptions](./wordcompareoptions) | Ειδικές επιλογές σύγκρισης εγγράφου Word. Κληρονομεί τις κοινές επιλογές από [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
