Παρέχει διεπαφές που ορίζουν συμβάσεις για διάφορα στοιχεία και λειτουργίες στο GroupDocs.Comparison.

Οι κύριες διεπαφές σε αυτό το πακέτο είναι:

* [IDocumentInfo](../../com.groupdocs.comparison.interfaces/idocumentinfo) - The interface that defines the contract for the information about a document.


Οι διεπαφές σε αυτό το πακέτο παρέχουν τις απαραίτητες συμβάσεις για την υλοποίηση και την αλληλεπίδραση με διαφορετικά
συστατικά και λειτουργίες στο GroupDocs.Comparison.


Για περισσότερες λεπτομέρειες σχετικά με τη δουλειά με αναθεωρήσεις και παρακολουθούμενες αλλαγές σε έγγραφα Word χρησιμοποιώντας το GroupDocs.Comparison για Java,
παρακαλούμε ανατρέξτε στην [GroupDocs.Comparison Τεκμηρίωση](../https://docs.groupdocs.com/comparison/java/).



## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [IDocumentInfo](../com.groupdocs.comparison.interfaces/idocumentinfo) | Παρέχει πρόσβαση στις ιδιότητες του εγγράφου. |
