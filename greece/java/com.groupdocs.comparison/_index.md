Το πακέτο παρέχει κλάσεις για τη σύγκριση εγγράφων για όλες τις δημοφιλείς μορφές εγγράφων.

Οι κύριες κλάσεις σε αυτό το πακέτο είναι:

* [Comparer](../../com.groupdocs.comparison/comparer) is the entry point for comparing documents.
* [Document](../../com.groupdocs.comparison/document) provides details about a document.
* [ComparerSettings](../../com.groupdocs.comparison/comparersettings) defines settings for customizing logging behaviour.


Η κύρια κλάση αυτού του ονοματοχώρου είναι [Comparer](../../com.groupdocs.comparison/comparer). Αυτή η κλάση παρέχει μεθόδους για προσθήκη εγγράφων, λήψη αλλαγών, σύγκριση εγγράφων κ.λπ.



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [Comparer](../com.groupdocs.comparison/comparer) | Η κλάση Comparer παρέχει λειτουργικότητα για τη σύγκριση εγγράφων και τη δημιουργία αποτελεσμάτων σύγκρισης. |
| [ComparerSettings](../com.groupdocs.comparison/comparersettings) | Ορίζει ρυθμίσεις για την προσαρμογή της συμπεριφοράς της κλάσης [Comparer](../com.groupdocs.comparison/comparer). |
| [Document](../com.groupdocs.comparison/document) | Αντιπροσωπεύει ένα έγγραφο για τη διαδικασία σύγκρισης. |
