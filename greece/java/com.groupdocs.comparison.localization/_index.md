Παρέχει κλάσεις και διεπαφές για localization στο GroupDocs.Comparison. Η λειτουργία localization σας επιτρέπει να προσαρμόσετε το κείμενο και τα μηνύματα που εμφανίζονται στη διαδικασία σύγκρισης βάσει διαφορετικών γλωσσών ή περιφερειακών προτιμήσεων.

Οι κύριες κλάσεις και διεπαφές σε αυτό το πακέτο είναι:

* [SupportedLocales](../../com.groupdocs.comparison.localization/supportedlocales) - A class provides constants representing the supported locales for GroupDocs.Comparison.


Χρησιμοποιώντας τη λειτουργία localization, μπορείτε να προσαρμόσετε το κείμενο και τα μηνύματα που χρησιμοποιούνται στο GroupDocs.Comparison ώστε να ταιριάζουν με τη γλώσσα ή τις προτιμήσεις των χρηστών σας.


Για περισσότερες λεπτομέρειες σχετικά με τη δουλειά με αναθεωρήσεις και παρακολουθούμενες αλλαγές σε έγγραφα Word χρησιμοποιώντας το GroupDocs.Comparison για Java,
παρακαλούμε ανατρέξτε στην [GroupDocs.Comparison Τεκμηρίωση](../https://docs.groupdocs.com/comparison/java/).
