Παρέχει απαριθμήσεις για διάφορες επιλογές και ρυθμίσεις στο GroupDocs.Comparison.


Οι κλάσεις σε αυτό το πακέτο περιέχουν απαριθμήσεις που ορίζουν διαφορετικές επιλογές και ρυθμίσεις
που χρησιμοποιούνται στο GroupDocs.Comparison για σκοπούς προσαρμογής και διαμόρφωσης.
Αυτές οι απαριθμήσεις χρησιμοποιούνται ως παράμετροι σε διάφορες μεθόδους και κλάσεις για τον έλεγχο της συμπεριφοράς
και της εμφάνισης της διαδικασίας σύγκρισης εγγράφων.


Μερικές από τις βασικές απαριθμήσεις σε αυτό το πακέτο περιλαμβάνουν το [ChangeType](../../com.groupdocs.comparison.result/changetype),
com.groupdocs.comparison.cells.style.ComparisonStyle και άλλα.
Αυτές οι απαριθμήσεις σας επιτρέπουν να λάβετε τον τύπο των αλλαγών, το στυλ της σύγκρισης
και άλλες επιλογές για τη διαδικασία σύγκρισης εγγράφων.


Για περισσότερες λεπτομέρειες σχετικά με τις διαθέσιμες επιλογές και πώς να τις χρησιμοποιήσετε στο GroupDocs.Comparison,
παρακαλούμε ανατρέξτε στην [GroupDocs.Comparison Τεκμηρίωση](../https://docs.groupdocs.com/comparison/java/).



## Απαριθμήσεις

| Απαριθμητικό | Περιγραφή |
| --- | --- |
| [ComparisonType](../com.groupdocs.comparison.options.enums/comparisontype) | Αναπαριστά τον τύπο σύγκρισης που θα εκτελεστεί. |
| [FolderComparisonExtension](../com.groupdocs.comparison.options.enums/foldercomparisonextension) | Η κλάση FolderComparisonExtension είναι μια απαρίθμηση που αναπαριστά διαφορετικές επεκτάσεις αρχείων που μπορούν να χρησιμοποιηθούν στη σύγκριση φακέλων. |
| [MetadataType](../com.groupdocs.comparison.options.enums/metadatatype) | Καθορίζει από πού το τελικό έγγραφο θα λάβει τις μεταδεδομένες πληροφορίες. |
| [PaperSize](../com.groupdocs.comparison.options.enums/papersize) | Αναπαριστά τις επιλογές μεγέθους χαρτιού για τη σύγκριση εγγράφων. |
| [PasswordSaveOption](../com.groupdocs.comparison.options.enums/passwordsaveoption) | Απαριθμεί τις επιλογές αποθήκευσης πληροφοριών κωδικού σε ένα έγγραφο κατά τη διαδικασία σύγκρισης. |
| [PreviewFormats](../com.groupdocs.comparison.options.enums/previewformats) | Απαριθμεί τις υποστηριζόμενες μορφές προεπισκόπησης για τη σύγκριση εγγράφων. |
