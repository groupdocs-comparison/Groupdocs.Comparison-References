Παρέχει λειτουργικές διεπαφές που επιτρέπουν την πρόσβαση σε δεδομένα σελίδων κατά τη διαδικασία σύγκρισης εγγράφων.

Οι λειτουργικές διεπαφές σε αυτό το πακέτο χρησιμοποιούνται για την πρόσβαση σε δεδομένα σελίδων κατά την εκτέλεση σύγκρισης εγγράφων χρησιμοποιώντας το GroupDocs.Comparison.

Οι κύριες λειτουργικές διεπαφές σε αυτό το πακέτο είναι:

* [CreatePageStreamFunction](../../com.groupdocs.comparison.common.function/createpagestreamfunction) - Allows handling creating output stream used by Comparison to save pages data.
* [ReleasePageStreamFunction](../../com.groupdocs.comparison.common.function/releasepagestreamfunction) - Allows handling releasing output stream used by Comparison to save pages data.


Αυτές οι λειτουργικές διεπαφές μπορούν να χρησιμοποιηθούν για τον ορισμό προσαρμοσμένης λογικής και συμπεριφοράς κατά την εργασία με σελίδες εγγράφων.
Παρέχουν ευελιξία για την προσαρμογή του πώς και πού αποθηκεύονται οι σελίδες που επεξεργάζονται.


Για περισσότερες λεπτομέρειες σχετικά με τη δουλειά με αναθεωρήσεις και παρακολουθούμενες αλλαγές σε έγγραφα Word χρησιμοποιώντας το GroupDocs.Comparison για Java,
παρακαλούμε ανατρέξτε στην [GroupDocs.Comparison Τεκμηρίωση](../https://docs.groupdocs.com/comparison/java/).
