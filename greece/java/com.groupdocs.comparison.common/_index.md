Παρέχει βοηθητικές κλάσεις με μεθόδους που μπορούν να είναι χρήσιμες κατά τη χρήση του API του GroupDocs.Comparison.


Οι κλάσεις σε αυτό το πακέτο προσφέρουν διάφορες βοηθητικές μεθόδους που μπορούν να βοηθήσουν στη δουλειά
με το API του GroupDocs.Comparison και στην εκτέλεση κοινών εργασιών σχετικών με τη σύγκριση εγγράφων.

Οι βασικές κλάσεις σε αυτό το πακέτο περιλαμβάνουν:

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


Αυτές οι βοηθητικές κλάσεις στοχεύουν στην απλοποίηση κοινών εργασιών και παρέχουν βολικές μεθόδους για τη δουλειά
με αρχεία, διαδρομές και ροές στο πλαίσιο της σύγκρισης εγγράφων χρησιμοποιώντας το API του GroupDocs.Comparison.


Για περισσότερες λεπτομέρειες σχετικά με τη δουλειά με αναθεωρήσεις και παρακολουθούμενες αλλαγές σε έγγραφα Word χρησιμοποιώντας το GroupDocs.Comparison για Java,
παρακαλούμε ανατρέξτε στην [GroupDocs.Comparison Τεκμηρίωση](../https://docs.groupdocs.com/comparison/java/).
