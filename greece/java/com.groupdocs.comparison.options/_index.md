Παρέχει κλάσεις και διεπαφές για τη διαμόρφωση διαφόρων επιλογών και ρυθμίσεων που σχετίζονται με τη σύγκριση εγγράφων. Αυτές οι επιλογές περιλαμβάνουν ρυθμίσεις σύγκρισης, επιλογές φόρτωσης, επιλογές αποθήκευσης, ρυθμίσεις στυλ και άλλα. Χρησιμοποιήστε αυτές τις κλάσεις για να προσαρμόσετε τη συμπεριφορά και την εμφάνιση της διαδικασίας σύγκρισης εγγράφων.

Κύριες κλάσεις σε αυτό το πακέτο:

* [CompareOptions](../../com.groupdocs.comparison.options/compareoptions) - Represents the options for document comparison.
* [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions) - Represents the options for loading documents.
* [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions) - Represents the options for saving comparison results.
* [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings) - Represents style settings for text formatting.


Για περισσότερες λεπτομέρειες σχετικά με τη χρήση των κλάσεων επιλογών με το GroupDocs.Comparison για Java,
παρακαλούμε ανατρέξτε στην [GroupDocs.Comparison Τεκμηρίωση](../https://docs.groupdocs.com/comparison/java/).



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ApplyChangeOptions](../com.groupdocs.comparison.options/applychangeoptions) | Επιτρέπει την ενημέρωση της λίστας αλλαγών πριν την εφαρμογή τους στο τελικό έγγραφο. |
| [CompareOptions](../com.groupdocs.comparison.options/compareoptions) | Επιτρέπει τη διαμόρφωση της διαδικασίας σύγκρισης εγγράφων. |
| [FileAuthorMetadata](../com.groupdocs.comparison.options/fileauthormetadata) | Επιτρέπει τη διαμόρφωση πληροφοριών σχετικά με τα μεταδεδομένα του συγγραφέα του εγγράφου. |
| [GetChangeOptions](../com.groupdocs.comparison.options/getchangeoptions) | Επιτρέπει τη διαμόρφωση φιλτραρίσματος για την ανάκτηση συγκεκριμένων τύπων αλλαγών από το αποτέλεσμα της σύγκρισης. |
| [OriginalSize](../com.groupdocs.comparison.options/originalsize) | Αντιπροσωπεύει το αρχικό μέγεθος ενός εγγράφου σε ένα αποτέλεσμα σύγκρισης. |
| [PreviewOptions](../com.groupdocs.comparison.options/previewoptions) | Παρέχει επιλογές για τη δημιουργία προεπισκοπήσεων εγγράφων στη διαδικασία σύγκρισης. |
