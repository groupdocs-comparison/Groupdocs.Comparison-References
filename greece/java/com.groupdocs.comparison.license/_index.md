Παρέχει κλάσεις για εργασία με την άδεια του GroupDocs.Comparison.


Οι κλάσεις σε αυτό το πακέτο σας επιτρέπουν να διαχειρίζεστε και να εφαρμόζετε άδειες για το GroupDocs.Comparison.
Μπορείτε να φορτώσετε και να ορίσετε το αρχείο άδειας, να ελέγξετε την κατάσταση της άδειας και να εκτελέσετε λειτουργίες σχετικές με την άδεια.


Για να χρησιμοποιήσετε τη λειτουργικότητα σχετική με την άδεια, χρειάζεστε ένα έγκυρο αρχείο άδειας που παρέχεται από το GroupDocs.
Μπορείτε να φορτώσετε το αρχείο άδειας χρησιμοποιώντας την κλάση [License](../../com.groupdocs.comparison.license/license) και στη συνέχεια να το εφαρμόσετε στη βιβλιοθήκη GroupDocs.Comparison.


Για περισσότερες λεπτομέρειες σχετικά με το πώς να εργάζεστε με άδειες στο GroupDocs.Comparison, παρακαλούμε ανατρέξτε στο
[Licensing FAQ](../https://purchase.groupdocs.com/faqs/licensing).
