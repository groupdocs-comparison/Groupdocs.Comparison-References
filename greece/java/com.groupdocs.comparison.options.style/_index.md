Παρέχει κλάσεις και επιλογές για το στυλ και τη διαμόρφωση της οπτικής εμφάνισης της εξόδου σύγκρισης εγγράφων στο GroupDocs.Comparison.


Οι κλάσεις σε αυτό το πακέτο χρησιμοποιούνται για τον ορισμό και την προσαρμογή διαφόρων πτυχών στυλ της εξόδου σύγκρισης εγγράφων, όπως τα χρώματα,
επισημάνσεις, υπογράμμιση και άλλα. Σας επιτρέπουν να ελέγχετε την οπτική εμφάνιση του προστιθέμενου, διαγραμμένου και τροποποιημένου περιεχομένου στο αποτέλεσμα της σύγκρισης.


Η κύρια κλάση σε αυτό το πακέτο περιλαμβάνει το [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings).
Οι κλάσεις στο πακέτο παρέχουν μεθόδους και ιδιότητες για τον ορισμό και τη διαμόρφωση των ρυθμίσεων στυλ για διαφορετικά συστατικά και στοιχεία του αποτελέσματος σύγκρισης.
Μπορείτε να ορίσετε στυλ γραμματοσειράς, χρώματα, επισημάνσεις, υπογράμμιση και άλλες επιλογές μορφοποίησης για να επιτύχετε την επιθυμητή οπτική αναπαράσταση των αλλαγών.


Για περισσότερες λεπτομέρειες σχετικά με το στυλ και τη διαμόρφωση της εμφάνισης της εξόδου σύγκρισης εγγράφων χρησιμοποιώντας το GroupDocs.Comparison,
παρακαλούμε ανατρέξτε στην [GroupDocs.Comparison Τεκμηρίωση](../https://docs.groupdocs.com/comparison/java/).



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [DiagramMasterSetting](../com.groupdocs.comparison.options.style/diagrammastersetting) | Αντιπροσωπεύει τις ρυθμίσεις για τη σύγκριση κυρίως διαγράμματος. |
| [Size](../com.groupdocs.comparison.options.style/size) | Αντιπροσωπεύει το μέγεθος του εγγράφου στη σύγκριση. |
| [StyleSettings](../com.groupdocs.comparison.options.style/stylesettings) | Αυτή η κλάση αντιπροσωπεύει τις ρυθμίσεις στυλ για τη μορφοποίηση κειμένου. |
