Παρέχει κλάσεις για εργασία με στυλ στοιχείων σε αρχεία μορφής Cells.


Οι κλάσεις σε αυτό το πακέτο σας επιτρέπουν να εργάζεστε με διάφορα στυλ και επιλογές μορφοποίησης ειδικές για αρχεία μορφής Cells (π.χ., αρχεία Excel).

Οι βασικές κλάσεις σε αυτό το πακέτο περιλαμβάνουν:

* [MergeType](../../com.groupdocs.comparison.cells.style/mergetype) - Represents the enumeration the type of cell merge.


Για περισσότερες λεπτομέρειες σχετικά με τη δουλειά με αναθεωρήσεις και παρακολουθούμενες αλλαγές σε έγγραφα Word χρησιμοποιώντας το GroupDocs.Comparison για Java,
παρακαλούμε ανατρέξτε στην [GroupDocs.Comparison Τεκμηρίωση](../https://docs.groupdocs.com/comparison/java/).
