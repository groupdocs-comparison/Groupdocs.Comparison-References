Παρέχει κλάσεις και επιλογές για την αποθήκευση και διαμόρφωση της εξόδου του GroupDocs.Comparison.


Οι κλάσεις σε αυτό το πακέτο χρησιμοποιούνται για την αποθήκευση και διαμόρφωση του τελικού εγγράφου της διαδικασίας σύγκρισης
στο GroupDocs.Comparison. Παρέχουν επιλογές για τον καθορισμό μεταδεδομένων, κωδικού πρόσβασης του τελικού εγγράφου και άλλα.


Η κύρια κλάση σε αυτό το πακέτο είναι [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions).
Οι κλάσεις σε αυτό το πακέτο σας επιτρέπουν να διαμορφώσετε συγκεκριμένες επιλογές και ρυθμίσεις σχετικές με διαφορετικά
μορφές εξόδου για τη δημιουργία του επιθυμητού τελικού εγγράφου της διαδικασίας σύγκρισης.


Για περισσότερες λεπτομέρειες σχετικά με την αποθήκευση και διαμόρφωση της εξόδου χρησιμοποιώντας το GroupDocs.Comparison,
παρακαλούμε ανατρέξτε στην [GroupDocs.Comparison Τεκμηρίωση](../https://docs.groupdocs.com/comparison/java/).



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [SaveOptions](../com.groupdocs.comparison.options.save/saveoptions) | Επιτρέπει τον καθορισμό πρόσθετων επιλογών κατά την αποθήκευση ενός εγγράφου. |
