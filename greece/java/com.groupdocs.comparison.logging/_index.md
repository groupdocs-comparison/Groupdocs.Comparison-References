Παρέχει κλάσεις και διεπαφές για καταγραφή στο GroupDocs.Comparison. Η λειτουργία καταγραφής σας επιτρέπει να καταγράφετε και να παρακολουθείτε διάφορα γεγονότα και μηνύματα κατά την εκτέλεση της διαδικασίας σύγκρισης.

Οι κύριες κλάσεις και διεπαφές σε αυτό το πακέτο είναι:

* com.groupdocs.comparison.logging.ILogger - The interface that defines the contract for a logger.
* [ComparisonLogger](../../com.groupdocs.comparison.logging/comparisonlogger) - Provides methods and a way to configure integrated or set user defined logger.
* com.groupdocs.comparison.logging.ConsoleLogger - Provides logger implementation which sends all messages to console.


Χρησιμοποιώντας τη λειτουργία καταγραφής, μπορείτε να προσαρμόσετε τον τρόπο με τον οποίο διαχειρίζονται τα μηνύματα καταγραφής,
όπως η εγγραφή τους σε αρχείο, κονσόλα ή οποιονδήποτε άλλο προορισμό της επιλογής σας.


Για περισσότερες λεπτομέρειες σχετικά με τη δουλειά με αναθεωρήσεις και παρακολουθούμενες αλλαγές σε έγγραφα Word χρησιμοποιώντας το GroupDocs.Comparison για Java,
παρακαλούμε ανατρέξτε στην [GroupDocs.Comparison Τεκμηρίωση](../https://docs.groupdocs.com/comparison/java/).

| [FileLogger](../com.groupdocs.comparison.logging/filelogger) | Καταγραφέας που γράφει τα αρχεία καταγραφής σε αρχείο. |
