Παρέχει κλάσεις και επιλογές για τη διαμόρφωση φόρτωσης εγγράφων στο GroupDocs.Comparison.


Οι κλάσεις σε αυτό το πακέτο χρησιμοποιούνται για τη φόρτωση των πηγών και των αρχείων-στόχων με συγκεκριμένες επιλογές.
Παρέχουν επιλογές για τον καθορισμό μορφών εγγράφων, τη φόρτωση εγγράφων με προστασία κωδικού,
ορισμό καταλόγων γραμματοσειρών και άλλα.


Η βασική κλάση σε αυτό το πακέτο είναι η [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions).
Οι κλάσεις στο πακέτο σας επιτρέπουν να διαμορφώσετε συγκεκριμένες επιλογές και ρυθμίσεις που σχετίζονται με διαφορετικά
μορφές εγγράφων για ακριβή και προσαρμοσμένη σύγκριση εγγράφων.


Για περισσότερες λεπτομέρειες σχετικά με τη φόρτωση και τη διαμόρφωση εγγράφων χρησιμοποιώντας το GroupDocs.Comparison,
παρακαλούμε ανατρέξτε στην [GroupDocs.Comparison Τεκμηρίωση](../https://docs.groupdocs.com/comparison/java/).



## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
