## License class

Διαχειρίζεται την αδειοδότηση του GroupDocs.Comparison.

Αδειοδοτημένες εκδόσεις ξεκλειδώνουν το πλήρες σύνολο λειτουργιών του wrapper στο
runtime. Οι μη αδειοδοτημένες εκδόσεις εκτελούνται σε λειτουργία αξιολόγησης με το ίδιο API
επιφάνεια, αλλά με περιορισμούς στο μέγεθος εξόδου και στο υδατογράφημα του περιεχομένου.

Ο τύπος License εκθέτει τα ακόλουθα μέλη:
