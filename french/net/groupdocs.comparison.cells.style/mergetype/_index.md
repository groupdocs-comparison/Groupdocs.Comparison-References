## MergeType enumeration

Énumère le type de fusion de cellules.

```csharp
public enum MergeType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | La cellule ne se fusionne pas. |
| Horizontal | `1` | La cellule se fusionne le long de la ligne. |
| Vertical | `2` | La cellule se fusionne le long de la colonne. |
| Range | `3` | La cellule se fusionne le long de la ligne et de la colonne, créant une zone. |
