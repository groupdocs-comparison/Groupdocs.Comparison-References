L'espace de noms fournit différentes classes d'exception.

## Classes

| Classe | Description |
| --- | --- |
| [ComparisonException](./comparisonexception) | Classe de base pour toutes les exceptions du processus de comparaison. |
| [DocumentComparisonException](./documentcomparisonexception) | L'exception qui est levée lorsqu'une erreur se produit lors de la comparaison de documents. |
| [FileFormatException](./fileformatexception) | L'exception qui est levée lors de la comparaison de fichiers avec des formats différents. |
| [InvalidPasswordException](./invalidpasswordexception) | L'exception qui est levée lorsque le mot de passe spécifié est incorrect. |
| [PasswordProtectedFileException](./passwordprotectedfileexception) | L'exception qui est levée lorsque le document est protégé par un mot de passe. |
| [UnsupportedFileFormatException](./unsupportedfileformatexception) | L'exception qui est levée lorsque le fichier de ce format ne prend pas en charge la comparaison. |
