L'espace de noms fournit des classes qui permettent de spécifier des options supplémentaires pour le processus de comparaison de documents.

## Classes

| Classe | Description |
| --- | --- |
| [ApplyChangeOptions](./applychangeoptions) | Permet de mettre à jour la liste des modifications avant de les appliquer au document résultant. |
| [CompareOptions](./compareoptions) | Permet de définir différentes options de comparaison. |
| [DiagramMasterSetting](./diagrammastersetting) | Paramètres principaux du diagramme. |
| [FileAuthorMetadata](./fileauthormetadata) | Informations sur les métadonnées de l'auteur du document. |
| [GetChangeOptions](./getchangeoptions) | L'option permet de filtrer les modifications par type. |
| [IgnoreChangeSensitivitySettings](./ignorechangesensitivitysettings) | L'option permet d'ignorer les modifications selon le pourcentage de similarité. |
| [LoadOptions](./loadoptions) | Permet de spécifier des options supplémentaires lors du chargement d'un document. |
| [OriginalSize](./originalsize) | Représente la taille originale de la page. Utilisé uniquement pour comparer des images avec différents formats. |
| [PagesSetup](./pagessetup) | Spécifie les pages à inclure dans la comparaison. |
| [PdfCompareOptions](./pdfcompareoptions) | Options de comparaison spécifiques aux documents PDF. Hérite des options communes de [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
| [PreviewOptions](./previewoptions) | Représente les options d'aperçu du document. |
| [PreviewResolution](./previewresolution) | Représente les paramètres de résolution pour la génération de l'aperçu du document. |
| [SaveOptions](./saveoptions) | Permet de spécifier des options supplémentaires (comme le mot de passe) lors de l'enregistrement d'un document. |
| [Size](./size) | Taille du document. |
| [StyleSettings](./stylesettings) | Paramètres de style. Permet de définir des règles de style pour les modifications. Utilisé dans la classe [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
| [WordCompareOptions](./wordcompareoptions) | Options de comparaison spécifiques aux documents Word. Hérite des options communes de [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
