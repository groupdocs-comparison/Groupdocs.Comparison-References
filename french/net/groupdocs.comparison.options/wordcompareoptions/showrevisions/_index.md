## WordCompareOptions.ShowRevisions property

Obtient ou définit si le document résultant conserve le balisage des révisions visible. Si false, toutes les révisions sont acceptées et le résultat apparaît comme texte final. Ce paramètre n'est significatif que lorsque [`DisplayMode`](../displaymode) est défini sur Highlight. La valeur par défaut est true.

```csharp
public bool ShowRevisions { get; set; }
```
