## PreviewFormats enumeration

Formats pris en charge pour l'aperçu du document.

```csharp
public enum PreviewFormats
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| PNG | `0` | Png (par défaut), peut prendre beaucoup d'espace disque / trafic si la page contient beaucoup de graphiques en couleur. |
| JPEG | `1` | Jpeg - traitement plus rapide, petite utilisation d'espace disque / trafic, mais peut être de mauvaise qualité. |
| BMP | `2` | BMP - traitement lent, forte utilisation d'espace disque / trafic, mais meilleure qualité. |
