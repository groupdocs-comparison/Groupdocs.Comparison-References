Fournit des interfaces qui définissent des contrats pour divers composants et fonctionnalités dans GroupDocs.Comparison.

Les principales interfaces de ce package sont :

* [IDocumentInfo](../../com.groupdocs.comparison.interfaces/idocumentinfo) - The interface that defines the contract for the information about a document.


Les interfaces de ce package fournissent les contrats nécessaires pour implémenter et interagir avec différents
composants et fonctionnalités dans GroupDocs.Comparison.


Pour plus de détails sur la gestion des révisions et des modifications suivies dans les documents Word à l'aide de GroupDocs.Comparison pour Java,
veuillez consulter la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Interfaces

| Interface | Description |
| --- | --- |
| [IDocumentInfo](../com.groupdocs.comparison.interfaces/idocumentinfo) | Fournit l'accès aux propriétés du document. |
