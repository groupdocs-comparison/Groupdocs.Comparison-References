Fournit des énumérations pour diverses options et paramètres dans GroupDocs.Comparison.


Les classes de ce package contiennent des énumérations qui définissent différentes options et paramètres
utilisées dans GroupDocs.Comparison à des fins de personnalisation et de configuration.
Ces énumérations sont utilisées comme paramètres dans diverses méthodes et classes pour contrôler le comportement
et l'apparence du processus de comparaison de documents.


Certaines des énumérations clés de ce package incluent [ChangeType](../../com.groupdocs.comparison.result/changetype),
com.groupdocs.comparison.cells.style.ComparisonStyle, et plus encore.
Ces énumérations vous permettent d'obtenir le type de modifications, le style de comparaison
et d'autres options pour le processus de comparaison de documents.


Pour plus de détails sur les options disponibles et comment les utiliser dans GroupDocs.Comparison,
veuillez consulter la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Énumérations

| Enum | Description |
| --- | --- |
| [ComparisonType](../com.groupdocs.comparison.options.enums/comparisontype) | Représente le type de comparaison à effectuer. |
| [FolderComparisonExtension](../com.groupdocs.comparison.options.enums/foldercomparisonextension) | La classe FolderComparisonExtension est une énumération qui représente différentes extensions de fichiers pouvant être utilisées dans la comparaison de dossiers. |
| [MetadataType](../com.groupdocs.comparison.options.enums/metadatatype) | Détermine d'où le document résultat prendra les informations de métadonnées. |
| [PaperSize](../com.groupdocs.comparison.options.enums/papersize) | Représente les options de format de papier pour la comparaison de documents. |
| [PasswordSaveOption](../com.groupdocs.comparison.options.enums/passwordsaveoption) | Énumère les options pour enregistrer les informations de mot de passe dans un document pendant le processus de comparaison. |
| [PreviewFormats](../com.groupdocs.comparison.options.enums/previewformats) | Énumère les formats d'aperçu pris en charge pour la comparaison de documents. |
