Fournit des classes et des interfaces pour configurer diverses options et paramètres liés à la comparaison de documents. Ces options incluent les paramètres de comparaison, les options de chargement, les options d'enregistrement, les paramètres de style, et plus encore. Utilisez ces classes pour personnaliser le comportement et l'apparence du processus de comparaison de documents.

Classes clés de ce package :

* [CompareOptions](../../com.groupdocs.comparison.options/compareoptions) - Represents the options for document comparison.
* [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions) - Represents the options for loading documents.
* [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions) - Represents the options for saving comparison results.
* [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings) - Represents style settings for text formatting.


Pour plus de détails sur l'utilisation des classes d'options avec GroupDocs.Comparison pour Java,
veuillez consulter la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
