Fournit des classes et des interfaces pour représenter les révisions et les modifications suivies dans les documents Word pendant le processus de comparaison dans GroupDocs.Comparison for Java.


Les classes de ce package sont utilisées pour représenter les révisions et les modifications suivies apportées aux documents Word pendant le processus de comparaison.
Ces révisions comprennent des insertions, suppressions, modifications de formatage et d'autres modifications du contenu du document.


Les classes clés de ce package incluent [RevisionHandler](../../com.groupdocs.comparison.words.revision/revisionhandler),
[RevisionAction](../../com.groupdocs.comparison.words.revision/revisionaction), and [RevisionInfo](../../com.groupdocs.comparison.words.revision/revisioninfo).


En utilisant les classes et interfaces de ce package, vous pouvez accéder, analyser et manipuler les révisions et les modifications suivies dans les documents Word.


Pour plus de détails sur la gestion des révisions et des modifications suivies dans les documents Word à l'aide de GroupDocs.Comparison pour Java,
veuillez consulter la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
