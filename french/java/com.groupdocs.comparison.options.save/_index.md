Fournit des classes et des options pour enregistrer et configurer la sortie de GroupDocs.Comparison.


Les classes de ce package sont utilisées pour enregistrer et configurer le document de sortie du processus de comparaison
dans GroupDocs.Comparison. Elles offrent des options pour spécifier les métadonnées, le mot de passe du document de sortie, et plus encore.


La classe clé de ce package est [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions).
Les classes de ce package vous permettent de configurer des options et paramètres spécifiques liés à différents
formats de sortie pour générer le document de sortie souhaité du processus de comparaison.


Pour plus de détails sur l'enregistrement et la configuration de la sortie en utilisant GroupDocs.Comparison,
veuillez consulter la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
