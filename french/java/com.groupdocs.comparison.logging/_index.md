Fournit des classes et des interfaces pour la journalisation dans GroupDocs.Comparison. La fonctionnalité de journalisation vous permet d'enregistrer et de surveiller divers événements et messages pendant l'exécution du processus de comparaison.

Les principales classes et interfaces de ce package sont :

* com.groupdocs.comparison.logging.ILogger - The interface that defines the contract for a logger.
* [ComparisonLogger](../../com.groupdocs.comparison.logging/comparisonlogger) - Provides methods and a way to configure integrated or set user defined logger.
* com.groupdocs.comparison.logging.ConsoleLogger - Provides logger implementation which sends all messages to console.


En utilisant la fonctionnalité de journalisation, vous pouvez personnaliser la façon dont les messages de log sont traités,
comme les écrire dans un fichier, la console ou toute autre destination de votre choix.


Pour plus de détails sur la gestion des révisions et des modifications suivies dans les documents Word à l'aide de GroupDocs.Comparison pour Java,
veuillez consulter la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
