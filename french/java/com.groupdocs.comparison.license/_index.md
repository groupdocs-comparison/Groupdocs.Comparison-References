Fournit des classes pour travailler avec la licence GroupDocs.Comparison.


Les classes de ce package vous permettent de gérer et d'appliquer les licences pour GroupDocs.Comparison.
Vous pouvez charger et définir le fichier de licence, vérifier l'état de la licence et effectuer des opérations liées à la licence.


Pour utiliser les fonctionnalités liées à la licence, vous avez besoin d'un fichier de licence valide fourni par GroupDocs.
Vous pouvez charger le fichier de licence en utilisant la classe [License](../../com.groupdocs.comparison.license/license) puis l'appliquer à la bibliothèque GroupDocs.Comparison.


Pour plus de détails sur la façon de travailler avec les licences dans GroupDocs.Comparison, veuillez vous référer à la
[Licensing FAQ](../https://purchase.groupdocs.com/faqs/licensing).
