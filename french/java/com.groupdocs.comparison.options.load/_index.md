Fournit des classes et des options pour configurer le chargement des documents dans GroupDocs.Comparison.


Les classes de ce package sont utilisées pour charger les documents source et cible avec des options spécifiques.
Elles offrent des options pour spécifier les formats de document, charger des documents protégés par mot de passe,
définir les répertoires de polices et plus encore.


La classe clé de ce package est [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions).
Les classes du package vous permettent de configurer des options et paramètres spécifiques liés à différents
formats de document pour une comparaison de documents précise et personnalisée.


Pour plus de détails sur le chargement et la configuration des documents avec GroupDocs.Comparison,
veuillez consulter la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
