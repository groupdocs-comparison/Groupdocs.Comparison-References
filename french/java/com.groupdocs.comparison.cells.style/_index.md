Fournit des classes pour travailler avec les styles de composants dans les fichiers au format Cells.


Les classes de ce package vous permettent de travailler avec divers styles et options de mise en forme spécifiques aux fichiers au format Cells (par ex., les fichiers Excel).

Les classes clés de ce package incluent :

* [MergeType](../../com.groupdocs.comparison.cells.style/mergetype) - Represents the enumeration the type of cell merge.


Pour plus de détails sur la gestion des révisions et des modifications suivies dans les documents Word à l'aide de GroupDocs.Comparison pour Java,
veuillez consulter la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).

| --- | --- |
| [MergeType](../com.groupdocs.comparison.cells.style/mergetype) | Énumère le type de fusion de cellules. |
