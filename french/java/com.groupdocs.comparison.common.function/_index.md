Fournit des interfaces fonctionnelles qui permettent d'accéder aux données des pages pendant le processus de comparaison de documents.

Les interfaces fonctionnelles de ce package sont utilisées pour accéder aux données des pages lors de la comparaison de documents avec GroupDocs.Comparison.

Les principales interfaces fonctionnelles de ce package sont :

* [CreatePageStreamFunction](../../com.groupdocs.comparison.common.function/createpagestreamfunction) - Allows handling creating output stream used by Comparison to save pages data.
* [ReleasePageStreamFunction](../../com.groupdocs.comparison.common.function/releasepagestreamfunction) - Allows handling releasing output stream used by Comparison to save pages data.


Ces interfaces fonctionnelles peuvent être utilisées pour définir une logique et un comportement personnalisés lors du travail avec les pages de documents.
Elles offrent une flexibilité pour personnaliser comment et où les pages sont traitées et enregistrées.


Pour plus de détails sur la gestion des révisions et des modifications suivies dans les documents Word à l'aide de GroupDocs.Comparison pour Java,
veuillez consulter la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Interfaces

| Interface | Description |
| --- | --- |
| [CreatePageStreamFunction](../com.groupdocs.comparison.common.function/createpagestreamfunction) | Interface fonctionnelle utilisée pour créer le flux de sortie employé par Comparison pour enregistrer l'image d'aperçu. |
| [ReleasePageStreamFunction](../com.groupdocs.comparison.common.function/releasepagestreamfunction) | Interface fonctionnelle utilisée pour fermer le flux de sortie qui a été utilisé par Comparison pour enregistrer l'image d'aperçu. |
