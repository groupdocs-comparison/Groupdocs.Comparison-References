Fournit des classes et des interfaces pour la localisation dans GroupDocs.Comparison. La fonctionnalité de localisation vous permet de personnaliser le texte et les messages affichés dans le processus de comparaison en fonction de différentes langues ou préférences régionales.

Les principales classes et interfaces de ce package sont :

* [SupportedLocales](../../com.groupdocs.comparison.localization/supportedlocales) - A class provides constants representing the supported locales for GroupDocs.Comparison.


En utilisant la fonctionnalité de localisation, vous pouvez personnaliser le texte et les messages utilisés dans GroupDocs.Comparison pour correspondre à la langue ou aux préférences de vos utilisateurs.


Pour plus de détails sur la gestion des révisions et des modifications suivies dans les documents Word à l'aide de GroupDocs.Comparison pour Java,
veuillez consulter la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
