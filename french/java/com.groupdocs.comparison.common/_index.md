Fournit des classes utilitaires avec des méthodes qui peuvent être utiles lors de l'utilisation de l'API GroupDocs.Comparison.


Les classes de ce package offrent diverses méthodes utilitaires qui peuvent aider à travailler
avec l'API GroupDocs.Comparison et à effectuer des tâches courantes liées à la comparaison de documents.

Les classes clés de ce package incluent :

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


Ces classes utilitaires visent à simplifier les tâches courantes et à fournir des méthodes pratiques pour travailler
avec les fichiers, chemins et flux dans le contexte de la comparaison de documents en utilisant l'API GroupDocs.Comparison.


Pour plus de détails sur la gestion des révisions et des modifications suivies dans les documents Word à l'aide de GroupDocs.Comparison pour Java,
veuillez consulter la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
