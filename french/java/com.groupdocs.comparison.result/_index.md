Fournit des classes et des interfaces pour travailler avec le résultat de la comparaison de documents. Le résultat de la comparaison comprend des informations sur les modifications, les révisions, les différences et d'autres données liées à la comparaison.

Classes clés de ce package :

* [ChangeInfo](../../com.groupdocs.comparison.result/changeinfo) - Represents information about a specific change in the comparison result.
* [PageInfo](../../com.groupdocs.comparison.result/pageinfo) - Represents information about a page in the comparison result.
* [StyleChangeInfo](../../com.groupdocs.comparison.result/stylechangeinfo) - Represents information about a style change in a compared document.


Pour plus de détails sur le travail avec le résultat du processus de comparaison en utilisant GroupDocs.Comparison pour Java,
veuillez consulter la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
