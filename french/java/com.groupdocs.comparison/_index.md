Le package fournit des classes pour comparer des documents pour tous les formats de documents populaires.

Les classes principales de ce package sont :

* [Comparer](../../com.groupdocs.comparison/comparer) is the entry point for comparing documents.
* [Document](../../com.groupdocs.comparison/document) provides details about a document.
* [ComparerSettings](../../com.groupdocs.comparison/comparersettings) defines settings for customizing logging behaviour.


La classe principale de cet espace de noms est [Comparer](../../com.groupdocs.comparison/comparer). Cette classe fournit des méthodes pour ajouter des documents, obtenir les modifications, comparer des documents, etc.
