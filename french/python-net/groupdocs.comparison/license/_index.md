## License class

Gère la licence de GroupDocs.Comparison.

Les versions sous licence débloquent l'ensemble complet des fonctionnalités du wrapper à
runtime. Les versions non licenciées s'exécutent en mode d'évaluation avec la même API
interface mais avec des limites sur la taille de sortie et le contenu filigrané.

Le type License expose les membres suivants :

### Méthodes
| Méthode | Description |
| :- | :- |
| [set_license](/comparison/python-net/groupdocs.comparison/license/set_license/#license_source) | Appliquer une licence au processus actuel. |
