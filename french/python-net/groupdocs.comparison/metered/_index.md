## Metered class

Gère la licence à la consommation (paiement à l'usage).

Les licences Metered facturent selon la consommation réelle (généralement les pages ou
documents traités). Définissez la paire de clés publique/privée une fois au
démarrage de l'application ; le wrapper renvoie l'utilisation au GroupDocs
serveur de licence en arrière-plan.

Le type Metered expose les membres suivants :

### Méthodes
| Méthode | Description |
| :- | :- |
| [get_consumption_credit](/comparison/python-net/groupdocs.comparison/metered/get_consumption_credit/) | Renvoie le crédit meteré restant pour la clé actuelle. |
| [get_consumption_quantity](/comparison/python-net/groupdocs.comparison/metered/get_consumption_quantity/) | Renvoie la quantité totale meterée consommée jusqu'à présent. |
| [set_metered_key](/comparison/python-net/groupdocs.comparison/metered/set_metered_key/#public_key-private_key) | Activez la facturation meterée avec la paire de clés publique/privée fournie. |
