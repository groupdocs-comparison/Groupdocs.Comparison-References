Cells format dosyalarındaki bileşen stilleriyle çalışmak için sınıflar sağlar.


Bu paketteki sınıflar, Cells format dosyalarına (ör. Excel dosyaları) özgü çeşitli stiller ve biçimlendirme seçenekleriyle çalışmanıza olanak tanır.

Bu paketteki ana sınıflar şunlardır:

* [MergeType](../../com.groupdocs.comparison.cells.style/mergetype) - Represents the enumeration the type of cell merge.


GroupDocs.Comparison for Java kullanarak Word belgelerinde revizyonlar ve izlenen değişikliklerle çalışmaya ilişkin daha fazla ayrıntı için,
lütfen [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/) adresine bakın.
