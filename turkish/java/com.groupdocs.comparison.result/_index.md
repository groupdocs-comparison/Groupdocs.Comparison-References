Belge karşılaştırmasının sonucuyla çalışmak için sınıflar ve arabirimler sağlar. Karşılaştırma sonucu, değişiklikler, revizyonlar, farklar ve diğer karşılaştırma ile ilgili veriler hakkında bilgi içerir.

Bu paketteki ana sınıflar:

* [ChangeInfo](../../com.groupdocs.comparison.result/changeinfo) - Represents information about a specific change in the comparison result.
* [PageInfo](../../com.groupdocs.comparison.result/pageinfo) - Represents information about a page in the comparison result.
* [StyleChangeInfo](../../com.groupdocs.comparison.result/stylechangeinfo) - Represents information about a style change in a compared document.


Java için GroupDocs.Comparison kullanarak karşılaştırma sürecinin sonucu ile çalışmaya ilişkin daha fazla ayrıntı için,
lütfen [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/) adresine bakın.
