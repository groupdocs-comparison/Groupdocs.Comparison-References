GroupDocs.Comparison API'sini kullanırken faydalı olabilecek yöntemlere sahip yardımcı sınıflar sağlar.


Bu paketteki sınıflar, çalışmaya yardımcı olabilecek çeşitli yardımcı yöntemler sunar
GroupDocs.Comparison API'si ile ve belge karşılaştırmasıyla ilgili ortak görevleri gerçekleştirirken.

Bu paketteki ana sınıflar şunlardır:

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


Bu yardımcı sınıflar, ortak görevleri basitleştirmeyi ve belge karşılaştırması bağlamında dosyalar, yollar ve akışlarla çalışmak için kolaylık yöntemleri sağlamayı amaçlar.
GroupDocs.Comparison API'si kullanılarak belge karşılaştırması bağlamında dosyalar, yollar ve akışlarla çalışmak.


GroupDocs.Comparison for Java kullanarak Word belgelerinde revizyonlar ve izlenen değişikliklerle çalışmaya ilişkin daha fazla ayrıntı için,
lütfen [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/) adresine bakın.
