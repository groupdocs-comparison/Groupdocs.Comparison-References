Belge karşılaştırma sürecinde sayfa verilerine erişim sağlayan işlevsel arayüzler sağlar.

Bu paketteki işlevsel arabirimler, GroupDocs.Comparison kullanarak belge karşılaştırması yaparken sayfa verilerine erişmek için kullanılır.

Bu paketteki ana işlevsel arabirimler şunlardır:

* [CreatePageStreamFunction](../../com.groupdocs.comparison.common.function/createpagestreamfunction) - Allows handling creating output stream used by Comparison to save pages data.
* [ReleasePageStreamFunction](../../com.groupdocs.comparison.common.function/releasepagestreamfunction) - Allows handling releasing output stream used by Comparison to save pages data.


Bu işlevsel arabirimler, belge sayfalarıyla çalışırken özel mantık ve davranış tanımlamak için kullanılabilir.
Sayfaların nasıl ve nerede kaydedileceğini özelleştirmek için esneklik sağlarlar.


GroupDocs.Comparison for Java kullanarak Word belgelerinde revizyonlar ve izlenen değişikliklerle çalışmaya ilişkin daha fazla ayrıntı için,
lütfen [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/) adresine bakın.

| [ReleasePageStreamFunction](../com.groupdocs.comparison.common.function/releasepagestreamfunction) | Karşılaştırma tarafından ön izleme görüntüsü kaydetmek için kullanılan çıktı akışını kapatmak için kullanılan işlevsel arabirim. |
