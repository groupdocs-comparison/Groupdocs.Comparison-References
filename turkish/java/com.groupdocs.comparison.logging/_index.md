GroupDocs.Comparison içinde günlük kaydı için sınıflar ve arayüzler sağlar. Günlük kaydı işlevi, karşılaştırma sürecinin yürütülmesi sırasında çeşitli olayları ve mesajları kaydetmenize ve izlemenize olanak tanır.

Bu paketteki ana sınıflar ve arabirimler şunlardır:

* com.groupdocs.comparison.logging.ILogger - The interface that defines the contract for a logger.
* [ComparisonLogger](../../com.groupdocs.comparison.logging/comparisonlogger) - Provides methods and a way to configure integrated or set user defined logger.
* com.groupdocs.comparison.logging.ConsoleLogger - Provides logger implementation which sends all messages to console.


Günlükleme işlevselliğini kullanarak, günlük mesajlarının nasıl işlendiğini özelleştirebilirsiniz,
örneğin mesajları bir dosyaya, konsola veya seçiminize göre başka bir hedefe yazabilirsiniz.


GroupDocs.Comparison for Java kullanarak Word belgelerinde revizyonlar ve izlenen değişikliklerle çalışmaya ilişkin daha fazla ayrıntı için,
lütfen [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/) adresine bakın.
