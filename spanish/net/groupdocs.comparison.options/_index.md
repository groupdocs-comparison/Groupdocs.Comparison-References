El espacio de nombres proporciona clases que permiten especificar opciones adicionales para el proceso de comparación de documentos.

## Clases

| Clase | Descripción |
| --- | --- |
| [ApplyChangeOptions](./applychangeoptions) | Permite actualizar la lista de cambios antes de aplicarlos al documento resultante. |
| [CompareOptions](./compareoptions) | Permite establecer diferentes opciones de comparación. |
| [DiagramMasterSetting](./diagrammastersetting) | Configuración maestra del diagrama. |
| [FileAuthorMetadata](./fileauthormetadata) | Información sobre los metadatos del autor del documento. |
| [GetChangeOptions](./getchangeoptions) | La opción permite filtrar los cambios por tipo. |
| [IgnoreChangeSensitivitySettings](./ignorechangesensitivitysettings) | La opción permite ignorar los cambios según el porcentaje de similitud. |
| [LoadOptions](./loadoptions) | Permite especificar opciones adicionales al cargar un documento. |
| [OriginalSize](./originalsize) | Representa el tamaño original de la página. Se usa solo para comparar imágenes con diferentes formatos. |
| [PagesSetup](./pagessetup) | Especifica qué páginas incluir en la comparación. |
| [PdfCompareOptions](./pdfcompareoptions) | Opciones de comparación específicas para documentos PDF. Hereda opciones comunes de [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
| [PreviewOptions](./previewoptions) | Representa las opciones de vista previa del documento. |
| [PreviewResolution](./previewresolution) | Representa la configuración de resolución para la generación de vistas previas del documento. |
| [SaveOptions](./saveoptions) | Permite especificar opciones adicionales (como la contraseña) al guardar un documento. |
| [Size](./size) | Tamaño del documento. |
| [StyleSettings](./stylesettings) | Configuración de estilo. Permite definir reglas de estilo para los cambios. Se usa en la clase [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
| [WordCompareOptions](./wordcompareoptions) | Opciones de comparación específicas para documentos Word. Hereda opciones comunes de [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
