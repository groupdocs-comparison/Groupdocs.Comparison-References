## WordCompareOptions.ShowRevisions property

Obtiene o establece si el documento resultante mantiene visible el marcado de revisión. Si es false, todas las revisiones se aceptan y el resultado aparece como texto final. Esta configuración solo tiene sentido cuando [`DisplayMode`](../displaymode) está configurado a Highlight. El valor predeterminado es true.

```csharp
public bool ShowRevisions { get; set; }
```
