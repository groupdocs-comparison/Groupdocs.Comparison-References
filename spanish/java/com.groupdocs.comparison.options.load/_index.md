Proporciona clases y opciones para configurar la carga de documentos en GroupDocs.Comparison.


Las clases en este paquete se utilizan para cargar los documentos de origen y destino con opciones específicas.
Proporcionan opciones para especificar formatos de documento, cargar documentos protegidos con contraseña,
establecer directorios de fuentes y más.


La clase clave en este paquete es [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions).
Las clases en el paquete le permiten configurar opciones y ajustes específicos relacionados con diferentes
formatos de documento para una comparación de documentos precisa y personalizada.


Para obtener más detalles sobre la carga y configuración de documentos usando GroupDocs.Comparison,
consulta la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
