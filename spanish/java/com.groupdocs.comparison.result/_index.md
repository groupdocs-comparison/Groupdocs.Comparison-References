Proporciona clases e interfaces para trabajar con el resultado de la comparación de documentos. El resultado de la comparación incluye información sobre cambios, revisiones, diferencias y otros datos relacionados con la comparación.

Clases clave en este paquete:

* [ChangeInfo](../../com.groupdocs.comparison.result/changeinfo) - Represents information about a specific change in the comparison result.
* [PageInfo](../../com.groupdocs.comparison.result/pageinfo) - Represents information about a page in the comparison result.
* [StyleChangeInfo](../../com.groupdocs.comparison.result/stylechangeinfo) - Represents information about a style change in a compared document.


Para obtener más detalles sobre cómo trabajar con el resultado del proceso de comparación usando GroupDocs.Comparison para Java,
consulta la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
