Proporciona clases e interfaces para la localización en GroupDocs.Comparison. La funcionalidad de localización le permite personalizar el texto y los mensajes mostrados en el proceso de comparación según diferentes idiomas o preferencias regionales.

Las clases principales e interfaces en este paquete son:

* [SupportedLocales](../../com.groupdocs.comparison.localization/supportedlocales) - A class provides constants representing the supported locales for GroupDocs.Comparison.


Al utilizar la funcionalidad de localización, puede personalizar el texto y los mensajes utilizados en GroupDocs.Comparison para que coincidan con el idioma o las preferencias de sus usuarios.


Para obtener más detalles sobre cómo trabajar con revisiones y cambios rastreados en documentos Word usando GroupDocs.Comparison para Java,
consulta la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
