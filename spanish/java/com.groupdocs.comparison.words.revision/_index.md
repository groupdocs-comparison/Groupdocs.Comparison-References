Proporciona clases e interfaces para representar revisiones y cambios rastreados en documentos Word durante el proceso de comparación en GroupDocs.Comparison for Java.


Las clases en este paquete se utilizan para representar revisiones y cambios rastreados realizados en documentos Word durante el proceso de comparación.
Estas revisiones incluyen inserciones, eliminaciones, cambios de formato y otras modificaciones al contenido del documento.


Las clases clave en este paquete incluyen [RevisionHandler](../../com.groupdocs.comparison.words.revision/revisionhandler),
[RevisionAction](../../com.groupdocs.comparison.words.revision/revisionaction), and [RevisionInfo](../../com.groupdocs.comparison.words.revision/revisioninfo).


Al usar las clases e interfaces en este paquete, puedes acceder, analizar y manipular revisiones y cambios rastreados en documentos Word.


Para obtener más detalles sobre cómo trabajar con revisiones y cambios rastreados en documentos Word usando GroupDocs.Comparison para Java,
consulta la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
