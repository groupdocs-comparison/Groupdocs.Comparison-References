El paquete proporciona clases para comparar documentos en todos los formatos de documento populares.

Las clases principales en este paquete son:

* [Comparer](../../com.groupdocs.comparison/comparer) is the entry point for comparing documents.
* [Document](../../com.groupdocs.comparison/document) provides details about a document.
* [ComparerSettings](../../com.groupdocs.comparison/comparersettings) defines settings for customizing logging behaviour.


La clase principal de este espacio de nombres es [Comparer](../../com.groupdocs.comparison/comparer). Esta clase proporciona métodos para agregar documentos, obtener cambios, comparar documentos, etc.
