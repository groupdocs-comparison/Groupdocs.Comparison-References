Proporciona clases e interfaces para configurar varias opciones y ajustes relacionados con la comparación de documentos. Estas opciones incluyen configuraciones de comparación, opciones de carga, opciones de guardado, ajustes de estilo y más. Utilice estas clases para personalizar el comportamiento y la apariencia del proceso de comparación de documentos.

Clases clave en este paquete:

* [CompareOptions](../../com.groupdocs.comparison.options/compareoptions) - Represents the options for document comparison.
* [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions) - Represents the options for loading documents.
* [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions) - Represents the options for saving comparison results.
* [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings) - Represents style settings for text formatting.


Para obtener más detalles sobre el uso de clases de opciones con GroupDocs.Comparison para Java,
consulta la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).

| [PreviewOptions](../com.groupdocs.comparison.options/previewoptions) | Proporciona opciones para generar vistas previas de documentos en el proceso de comparación. |
