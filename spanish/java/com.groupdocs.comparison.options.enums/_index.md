Proporciona enumeraciones para varias opciones y ajustes en GroupDocs.Comparison.


Las clases en este paquete contienen enumeraciones que definen diferentes opciones y configuraciones
utilizadas en GroupDocs.Comparison con fines de personalización y configuración.
Estas enumeraciones se utilizan como parámetros en varios métodos y clases para controlar el comportamiento
y la apariencia del proceso de comparación de documentos.


Algunas de las enumeraciones clave en este paquete incluyen [ChangeType](../../com.groupdocs.comparison.result/changetype),
com.groupdocs.comparison.cells.style.ComparisonStyle, y más.
Estas enumeraciones le permiten obtener el tipo de cambios, el estilo de comparación
y otras opciones para el proceso de comparación de documentos.


Para obtener más detalles sobre las opciones disponibles y cómo utilizarlas en GroupDocs.Comparison,
consulta la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
