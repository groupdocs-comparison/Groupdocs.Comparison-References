Proporciona interfaces que definen contratos para varios componentes y funcionalidades en GroupDocs.Comparison.

Las principales interfaces en este paquete son:

* [IDocumentInfo](../../com.groupdocs.comparison.interfaces/idocumentinfo) - The interface that defines the contract for the information about a document.


Las interfaces en este paquete proporcionan los contratos necesarios para implementar e interactuar con diferentes
componentes y funcionalidades en GroupDocs.Comparison.


Para obtener más detalles sobre cómo trabajar con revisiones y cambios rastreados en documentos Word usando GroupDocs.Comparison para Java,
consulta la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Interfaces

| Interfaz | Descripción |
| --- | --- |
| [IDocumentInfo](../com.groupdocs.comparison.interfaces/idocumentinfo) | Proporciona acceso a las propiedades del documento. |
