Proporciona interfaces funcionales que permiten acceder a los datos de las páginas durante el proceso de comparación de documentos.

Las interfaces funcionales en este paquete se utilizan para acceder a los datos de las páginas al realizar la comparación de documentos usando GroupDocs.Comparison.

Las principales interfaces funcionales en este paquete son:

* [CreatePageStreamFunction](../../com.groupdocs.comparison.common.function/createpagestreamfunction) - Allows handling creating output stream used by Comparison to save pages data.
* [ReleasePageStreamFunction](../../com.groupdocs.comparison.common.function/releasepagestreamfunction) - Allows handling releasing output stream used by Comparison to save pages data.


Estas interfaces funcionales pueden usarse para definir lógica y comportamiento personalizados al trabajar con páginas de documentos.
Proporcionan flexibilidad para personalizar cómo y dónde se procesan las páginas.


Para obtener más detalles sobre cómo trabajar con revisiones y cambios rastreados en documentos Word usando GroupDocs.Comparison para Java,
consulta la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Interfaces

| Interfaz | Descripción |
| --- | --- |
| [CreatePageStreamFunction](../com.groupdocs.comparison.common.function/createpagestreamfunction) | Interfaz funcional que se usa para crear el flujo de salida utilizado por Comparison para guardar la imagen de vista previa. |
| [ReleasePageStreamFunction](../com.groupdocs.comparison.common.function/releasepagestreamfunction) | Interfaz funcional que se usa para cerrar el flujo de salida que fue utilizado por Comparison para guardar la imagen de vista previa. |
