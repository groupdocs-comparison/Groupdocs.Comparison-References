Proporciona clases para trabajar con la licencia de GroupDocs.Comparison.


Las clases en este paquete le permiten gestionar y aplicar licencias para GroupDocs.Comparison.
Puede cargar y establecer el archivo de licencia, verificar el estado de la licencia y realizar operaciones relacionadas con la licencia.


Para usar la funcionalidad relacionada con la licencia, necesita un archivo de licencia válido proporcionado por GroupDocs.
Puede cargar el archivo de licencia usando la clase [License](../../com.groupdocs.comparison.license/license) y luego aplicarlo a la biblioteca GroupDocs.Comparison.


Para obtener más detalles sobre cómo trabajar con licencias en GroupDocs.Comparison, consulte el
[Licensing FAQ](../https://purchase.groupdocs.com/faqs/licensing).
