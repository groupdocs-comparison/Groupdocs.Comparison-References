Proporciona excepciones que pueden lanzarse durante el proceso de comparación en GroupDocs.Comparison.

Las principales clases de excepción en este paquete son:

* [ComparisonException](../../com.groupdocs.comparison.common.exceptions/comparisonexception) - The base exception class for all exceptions related to document comparison.
* [InvalidPasswordException](../../com.groupdocs.comparison.common.exceptions/invalidpasswordexception) - The exception that is thrown when an invalid password is provided for a password-protected document.
* [UnsupportedFileFormatException](../../com.groupdocs.comparison.common.exceptions/unsupportedfileformatexception) - The exception that is thrown when file of this format is not supported by Comparison.


Las excepciones en este paquete proporcionan un manejo de errores específico y reportes para operaciones comunes en GroupDocs.Comparison.
Permiten una detección y manejo de errores más granular, habilitando a los desarrolladores a responder adecuadamente a diferentes escenarios de error.


Para obtener más detalles sobre cómo trabajar con revisiones y cambios rastreados en documentos Word usando GroupDocs.Comparison para Java,
consulta la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
