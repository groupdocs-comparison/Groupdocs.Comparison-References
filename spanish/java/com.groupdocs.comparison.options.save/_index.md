Proporciona clases y opciones para guardar y configurar la salida de GroupDocs.Comparison.


Las clases en este paquete se utilizan para guardar y configurar el documento de salida del proceso de comparación
en GroupDocs.Comparison. Proporcionan opciones para especificar metadatos, contraseña del documento de salida y más.


La clase clave en este paquete es [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions).
Las clases en este paquete le permiten configurar opciones y ajustes específicos relacionados con diferentes
formatos de salida para generar el documento de salida deseado del proceso de comparación.


Para obtener más detalles sobre cómo guardar y configurar la salida usando GroupDocs.Comparison,
consulta la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
