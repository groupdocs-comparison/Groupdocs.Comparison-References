Proporciona clases para trabajar con estilos de componentes en archivos de formato Cells.


Las clases en este paquete le permiten trabajar con varios estilos y opciones de formato específicas de los archivos de formato Cells (p. ej., archivos Excel).

Las clases clave en este paquete incluyen:

* [MergeType](../../com.groupdocs.comparison.cells.style/mergetype) - Represents the enumeration the type of cell merge.


Para obtener más detalles sobre cómo trabajar con revisiones y cambios rastreados en documentos Word usando GroupDocs.Comparison para Java,
consulta la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).

| --- | --- |
