Proporciona clases de utilidad con métodos que pueden ser útiles al usar la API de GroupDocs.Comparison.


Las clases en este paquete ofrecen varios métodos de utilidad que pueden ayudar al trabajar
con la API de GroupDocs.Comparison y al realizar tareas comunes relacionadas con la comparación de documentos.

Las clases clave en este paquete incluyen:

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


Estas clases de utilidad buscan simplificar tareas comunes y proporcionar métodos convenientes para trabajar
con archivos, rutas y flujos en el contexto de la comparación de documentos usando la API de GroupDocs.Comparison.


Para obtener más detalles sobre cómo trabajar con revisiones y cambios rastreados en documentos Word usando GroupDocs.Comparison para Java,
consulta la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
