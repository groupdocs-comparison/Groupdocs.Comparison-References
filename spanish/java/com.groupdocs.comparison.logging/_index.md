Proporciona clases e interfaces para el registro en GroupDocs.Comparison. La funcionalidad de registro le permite registrar y monitorear varios eventos y mensajes durante la ejecución del proceso de comparación.

Las clases principales e interfaces en este paquete son:

* com.groupdocs.comparison.logging.ILogger - The interface that defines the contract for a logger.
* [ComparisonLogger](../../com.groupdocs.comparison.logging/comparisonlogger) - Provides methods and a way to configure integrated or set user defined logger.
* com.groupdocs.comparison.logging.ConsoleLogger - Provides logger implementation which sends all messages to console.


Al usar la funcionalidad de registro, puedes personalizar cómo se manejan los mensajes de registro,
como escribirlos en un archivo, consola o cualquier otro destino que elijas.


Para obtener más detalles sobre cómo trabajar con revisiones y cambios rastreados en documentos Word usando GroupDocs.Comparison para Java,
consulta la [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
