## 클래스

| 클래스 | 설명 |
| --- | --- |
| [ApplyChangeOptions](./applychangeoptions) | 결과 문서에 적용하기 전에 변경 목록을 업데이트할 수 있습니다. |
| [CompareOptions](./compareoptions) | 다양한 비교 옵션을 설정할 수 있습니다. |
| [DiagramMasterSetting](./diagrammastersetting) | 다이어그램 마스터 설정. |
| [FileAuthorMetadata](./fileauthormetadata) | 문서 작성자 메타데이터에 대한 정보. |
| [GetChangeOptions](./getchangeoptions) | 이 옵션은 유형별로 변경을 필터링할 수 있게 합니다. |
| [IgnoreChangeSensitivitySettings](./ignorechangesensitivitysettings) | 이 옵션은 유사도 비율에 따라 변경을 무시할 수 있게 합니다. |

| [PagesSetup](./pagessetup) | 비교에 포함할 페이지를 지정합니다. |
| [PdfCompareOptions](./pdfcompareoptions) | PDF 문서 전용 비교 옵션. [`CompareOptions`](../groupdocs.comparison.options/compareoptions)에서 공통 옵션을 상속합니다. |
| [PreviewOptions](./previewoptions) | 문서 미리보기 옵션을 나타냅니다. |
| [PreviewResolution](./previewresolution) | 문서 미리보기 생성에 대한 해상도 설정을 나타냅니다. |
| [SaveOptions](./saveoptions) | 문서를 저장할 때 추가 옵션(예: 비밀번호)을 지정할 수 있습니다. |
| [Size](./size) | 문서 크기. |
| [StyleSettings](./stylesettings) | 스타일 설정. 변경에 대한 스타일 규칙을 정의할 수 있습니다. [`CompareOptions`](../groupdocs.comparison.options/compareoptions) 클래스에서 사용됩니다. |
| [WordCompareOptions](./wordcompareoptions) | Word 문서 전용 비교 옵션. [`CompareOptions`](../groupdocs.comparison.options/compareoptions)에서 공통 옵션을 상속합니다. |
