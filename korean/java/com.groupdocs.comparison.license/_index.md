GroupDocs.Comparison 라이선스를 작업하기 위한 클래스를 제공합니다.


이 패키지의 클래스는 GroupDocs.Comparison에 대한 라이선스를 관리하고 적용할 수 있게 해줍니다.
라이선스 파일을 로드하고 설정하며, 라이선스 상태를 확인하고, 라이선스 관련 작업을 수행할 수 있습니다.


라이선스 관련 기능을 사용하려면 GroupDocs에서 제공하는 유효한 라이선스 파일이 필요합니다.
라이선스 파일을 [License](../../com.groupdocs.comparison.license/license) 클래스를 사용하여 로드한 다음 GroupDocs.Comparison 라이브러리에 적용할 수 있습니다.


GroupDocs.Comparison에서 라이선스를 사용하는 방법에 대한 자세한 내용은 다음을 참조하십시오.
[Licensing FAQ](../https://purchase.groupdocs.com/faqs/licensing).
