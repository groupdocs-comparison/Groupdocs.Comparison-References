GroupDocs.Comparison에서 로컬라이제이션을 위한 클래스와 인터페이스를 제공합니다. 로컬라이제이션 기능을 사용하면 다양한 언어 또는 지역 설정에 따라 비교 프로세스에 표시되는 텍스트와 메시지를 사용자 지정할 수 있습니다.

이 패키지의 주요 클래스와 인터페이스는 다음과 같습니다:

* [SupportedLocales](../../com.groupdocs.comparison.localization/supportedlocales) - A class provides constants representing the supported locales for GroupDocs.Comparison.


로컬라이제이션 기능을 사용하면 GroupDocs.Comparison에서 사용되는 텍스트와 메시지를 사용자의 언어 또는 선호도에 맞게 사용자 지정할 수 있습니다.


Java용 GroupDocs.Comparison을 사용하여 Word 문서의 수정 및 추적 변경 작업에 대한 자세한 내용은
다음 [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/)을 참조하십시오.
