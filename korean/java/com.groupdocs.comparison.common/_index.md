GroupDocs.Comparison API를 사용할 때 유용할 수 있는 메서드를 포함한 유틸리티 클래스를 제공합니다.


이 패키지의 클래스는 작업에 도움이 될 수 있는 다양한 유틸리티 메서드를 제공합니다
GroupDocs.Comparison API와 문서 비교와 관련된 일반 작업을 수행합니다.

이 패키지의 핵심 클래스는 다음과 같습니다:

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


이 유틸리티 클래스는 일반 작업을 단순화하고 작업을 위한 편리한 메서드를 제공하는 것을 목표로 합니다
GroupDocs.Comparison API를 사용한 문서 비교 컨텍스트에서 파일, 경로 및 스트림을 다룹니다.


Java용 GroupDocs.Comparison을 사용하여 Word 문서의 수정 및 추적 변경 작업에 대한 자세한 내용은
다음 [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/)을 참조하십시오.
