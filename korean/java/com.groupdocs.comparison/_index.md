패키지는 모든 인기 문서 형식에 대한 문서를 비교하는 클래스를 제공합니다.

이 패키지의 주요 클래스는 다음과 같습니다:

* [Comparer](../../com.groupdocs.comparison/comparer) is the entry point for comparing documents.
* [Document](../../com.groupdocs.comparison/document) provides details about a document.
* [ComparerSettings](../../com.groupdocs.comparison/comparersettings) defines settings for customizing logging behaviour.


이 네임스페이스의 주요 클래스는 [Comparer](../../com.groupdocs.comparison/comparer)입니다. 이 클래스는 문서를 추가하고, 변경 사항을 얻으며, 문서를 비교하는 등의 메서드를 제공합니다.



## 클래스

| 클래스 | 설명 |
| --- | --- |
| [Comparer](../com.groupdocs.comparison/comparer) | Comparer 클래스는 문서를 비교하고 비교 결과를 생성하는 기능을 제공합니다. |
| [ComparerSettings](../com.groupdocs.comparison/comparersettings) | 비교기([Comparer](../com.groupdocs.comparison/comparer)) 클래스의 동작을 사용자 지정하기 위한 설정을 정의합니다. |
| [Document](../com.groupdocs.comparison/document) | 비교 프로세스에 사용할 문서를 나타냅니다. |
