문서 비교 결과를 작업하기 위한 클래스와 인터페이스를 제공합니다. 비교 결과에는 변경 사항, 수정본, 차이점 및 기타 비교 관련 데이터에 대한 정보가 포함됩니다.

이 패키지의 주요 클래스:

* [ChangeInfo](../../com.groupdocs.comparison.result/changeinfo) - Represents information about a specific change in the comparison result.
* [PageInfo](../../com.groupdocs.comparison.result/pageinfo) - Represents information about a page in the comparison result.
* [StyleChangeInfo](../../com.groupdocs.comparison.result/stylechangeinfo) - Represents information about a style change in a compared document.


GroupDocs.Comparison for Java를 사용하여 비교 프로세스 결과를 작업하는 자세한 내용은,
다음 [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/)을 참조하십시오.



## 클래스

| 클래스 | 설명 |
| --- | --- |
| [ChangeInfo](../com.groupdocs.comparison.result/changeinfo) | ChangeInfo 클래스는 문서 비교에서 특정 변경에 대한 정보를 나타냅니다. |
| [PageInfo](../com.groupdocs.comparison.result/pageinfo) | PageInfo 클래스는 문서의 특정 페이지에 대한 정보를 나타냅니다. |
| [Rectangle](../com.groupdocs.comparison.result/rectangle) | Rectangle 클래스는 문서의 변경된 영역을 나타냅니다. |
| [StyleChangeInfo](../com.groupdocs.comparison.result/stylechangeinfo) | StyleChangeInfo 클래스는 비교된 문서에서 스타일 변경에 대한 정보를 나타냅니다. |

## 열거형

| 열거형 | 설명 |
| --- | --- |
| [ChangeType](../com.groupdocs.comparison.result/changetype) | ChangeType 열거형은 문서 비교 프로세스 중 발생할 수 있는 변경 유형을 나타냅니다. |
| [ComparisonAction](../com.groupdocs.comparison.result/comparisonaction) | ComparisonAction 열거형은 문서 비교 프로세스 중 변경에 적용될 수 있는 작업을 나타냅니다. |
| [FileType](../com.groupdocs.comparison.result/filetype) | FileType 열거형은 문서 비교 프로세스에 사용되는 파일 유형을 나타냅니다. |
