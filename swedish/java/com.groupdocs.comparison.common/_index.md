Tillhandahåller verktygsklasser med metoder som kan vara användbara när du använder GroupDocs.Comparison API.


Klasserna i detta paket erbjuder olika hjälpfunktioner som kan underlätta arbetet
med GroupDocs.Comparison API och utför vanliga uppgifter relaterade till dokumentjämförelse.

Viktiga klasser i detta paket inkluderar:

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


Dessa hjälpprogramklasser syftar till att förenkla vanliga uppgifter och erbjuda bekväma metoder för att arbeta
med filer, sökvägar och strömmar i samband med dokumentjämförelse med hjälp av GroupDocs.Comparison API.


För mer information om hur du arbetar med revisioner och spårade ändringar i Word-dokument med GroupDocs.Comparison för Java,
se [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
