Tillhandahåller klasser och gränssnitt för loggning i GroupDocs.Comparison. Loggningsfunktionen gör det möjligt att registrera och övervaka olika händelser och meddelanden under körningen av jämförelseprocessen.

De viktigaste klasserna och gränssnitten i detta paket är:

* com.groupdocs.comparison.logging.ILogger - The interface that defines the contract for a logger.
* [ComparisonLogger](../../com.groupdocs.comparison.logging/comparisonlogger) - Provides methods and a way to configure integrated or set user defined logger.
* com.groupdocs.comparison.logging.ConsoleLogger - Provides logger implementation which sends all messages to console.


Genom att använda loggningsfunktionaliteten kan du anpassa hur loggmeddelanden hanteras,
till exempel skriva dem till en fil, konsol eller någon annan destination du väljer.


För mer information om hur du arbetar med revisioner och spårade ändringar i Word-dokument med GroupDocs.Comparison för Java,
se [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
