Paketet tillhandahåller klasser för att jämföra dokument för alla populära dokumentformat.

De viktigaste klasserna i detta paket är:

* [Comparer](../../com.groupdocs.comparison/comparer) is the entry point for comparing documents.
* [Document](../../com.groupdocs.comparison/document) provides details about a document.
* [ComparerSettings](../../com.groupdocs.comparison/comparersettings) defines settings for customizing logging behaviour.


Den huvudsakliga klassen i detta namnrum är [Comparer](../../com.groupdocs.comparison/comparer). Denna klass tillhandahåller metoder för att lägga till dokument, hämta ändringar, jämföra dokument etc.



## Klasser

| Klass | Beskrivning |
| --- | --- |
| [Comparer](../com.groupdocs.comparison/comparer) | Comparer-klassen erbjuder funktionalitet för att jämföra dokument och generera jämförelsresultat. |
| [ComparerSettings](../com.groupdocs.comparison/comparersettings) | Definierar inställningar för att anpassa beteendet hos klassen [Comparer](../com.groupdocs.comparison/comparer). |
| [Document](../com.groupdocs.comparison/document) | Representerar ett dokument för jämförelseprocessen. |
