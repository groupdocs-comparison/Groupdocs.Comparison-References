Tillhandahåller klasser för att arbeta med GroupDocs.Comparison-licensen.


Klasserna i detta paket låter dig hantera och tillämpa licenser för GroupDocs.Comparison.
Du kan läsa in och ange licensfilen, kontrollera licensstatusen och utföra licensrelaterade operationer.


För att använda licensrelaterad funktionalitet behöver du en giltig licensfil som tillhandahålls av GroupDocs.
Du kan läsa in licensfilen med hjälp av klassen [License](../../com.groupdocs.comparison.license/license) och sedan tillämpa den på GroupDocs.Comparison-biblioteket.


För mer information om hur du arbetar med licenser i GroupDocs.Comparison, se
[Licensing FAQ](../https://purchase.groupdocs.com/faqs/licensing).
