Tillhandahåller klasser och alternativ för att konfigurera inläsning av dokument i GroupDocs.Comparison.


Klasserna i detta paket används för att läsa in käll- och mål dokument med specifika alternativ.
De erbjuder alternativ för att ange dokumentformat, läsa in lösenordsskyddade dokument,
sätta teckensnittskataloger och mer.


Nyckelklassen i detta paket är [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions).
Klasser i paketet låter dig konfigurera specifika alternativ och inställningar relaterade till olika
dokumentformat för exakt och anpassad dokumentjämförelse.


För mer information om inläsning och konfiguration av dokument med hjälp av GroupDocs.Comparison,
se [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Klasser

| Klass | Beskrivning |
| --- | --- |
| [LoadOptions](../com.groupdocs.comparison.options.load/loadoptions) | Tillåter att ange ytterligare alternativ när ett dokument läses in. |
