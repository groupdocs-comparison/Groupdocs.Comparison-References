Tillhandahåller klasser och gränssnitt för att konfigurera olika alternativ och inställningar relaterade till dokumentjämförelse. Dessa alternativ inkluderar jämförelsinställningar, inläsningsalternativ, sparalternativ, stilinställningar och mer. Använd dessa klasser för att anpassa beteendet och utseendet på dokumentjämförelseprocessen.

Viktiga klasser i detta paket:

* [CompareOptions](../../com.groupdocs.comparison.options/compareoptions) - Represents the options for document comparison.
* [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions) - Represents the options for loading documents.
* [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions) - Represents the options for saving comparison results.
* [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings) - Represents style settings for text formatting.


För mer information om hur du arbetar med alternativklasser med GroupDocs.Comparison för Java,
se [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
