Tillhandahåller funktionella gränssnitt som möjliggör åtkomst till siddata under dokumentjämförelseprocessen.

De funktionella gränssnitten i detta paket används för att komma åt siddata när dokumentjämförelse utförs med GroupDocs.Comparison.

De viktigaste funktionella gränssnitten i detta paket är:

* [CreatePageStreamFunction](../../com.groupdocs.comparison.common.function/createpagestreamfunction) - Allows handling creating output stream used by Comparison to save pages data.
* [ReleasePageStreamFunction](../../com.groupdocs.comparison.common.function/releasepagestreamfunction) - Allows handling releasing output stream used by Comparison to save pages data.


Dessa funktionella gränssnitt kan användas för att definiera anpassad logik och beteende när du arbetar med dokumentsidor.
De ger flexibilitet att anpassa hur och var sidor som bearbetas sparas.


För mer information om hur du arbetar med revisioner och spårade ändringar i Word-dokument med GroupDocs.Comparison för Java,
se [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
