Tillhandahåller klasser och gränssnitt för att arbeta med resultatet av dokumentjämförelse. Jämförelsresultatet innehåller information om ändringar, revisioner, skillnader och annan jämförelsespecifik data.

Viktiga klasser i detta paket:

* [ChangeInfo](../../com.groupdocs.comparison.result/changeinfo) - Represents information about a specific change in the comparison result.
* [PageInfo](../../com.groupdocs.comparison.result/pageinfo) - Represents information about a page in the comparison result.
* [StyleChangeInfo](../../com.groupdocs.comparison.result/stylechangeinfo) - Represents information about a style change in a compared document.


För mer information om hur du arbetar med resultatet av jämförelseprocessen med GroupDocs.Comparison för Java,
se [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
