Tillhandahåller klasser och alternativ för styling och konfigurering av det visuella utseendet på dokumentjämförelsens utdata i GroupDocs.Comparison.


Klasserna i detta paket används för att definiera och anpassa olika stilaspekter av dokumentjämförelsens utdata, såsom färger,
markering, understrykning och mer. De låter dig kontrollera det visuella utseendet på tillagt, raderat och ändrat innehåll i jämförelsens resultat.


Den viktigaste klassen i detta paket inkluderar [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings).
Klasserna i paketet tillhandahåller metoder och egenskaper för att definiera och konfigurera stilinställningarna för olika komponenter och element i jämförelsens resultat.
Du kan ställa in teckensnittsstilar, färger, markering, understrykning och andra formateringsalternativ för att uppnå önskad visuell representation av förändringarna.


För mer information om stilisering och konfiguration av utseendet på dokumentjämförelsens utdata med GroupDocs.Comparison,
se [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Klasser

| Klass | Beskrivning |
| --- | --- |
| [DiagramMasterSetting](../com.groupdocs.comparison.options.style/diagrammastersetting) | Representerar inställningarna för diagramhuvudjämförelse. |
| [Size](../com.groupdocs.comparison.options.style/size) | Representerar dokumentets storlek i jämförelsen. |
| [StyleSettings](../com.groupdocs.comparison.options.style/stylesettings) | Denna klass representerar stilinställningar för textformatering. |
