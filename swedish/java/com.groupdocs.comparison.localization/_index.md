Tillhandahåller klasser och gränssnitt för lokalisering i GroupDocs.Comparison. Lokaliseringfunktionaliteten gör det möjligt att anpassa text och meddelanden som visas i jämförelseprocessen baserat på olika språk eller regionala preferenser.

De viktigaste klasserna och gränssnitten i detta paket är:

* [SupportedLocales](../../com.groupdocs.comparison.localization/supportedlocales) - A class provides constants representing the supported locales for GroupDocs.Comparison.


Genom att använda lokaliseringfunktionaliteten kan du anpassa text och meddelanden som används i GroupDocs.Comparison för att matcha språk eller preferenser hos dina användare.


För mer information om hur du arbetar med revisioner och spårade ändringar i Word-dokument med GroupDocs.Comparison för Java,
se [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
