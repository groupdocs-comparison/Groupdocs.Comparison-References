Tillhandahåller klasser och alternativ för att spara och konfigurera utdata från GroupDocs.Comparison.


Klasserna i detta paket används för att spara och konfigurera utdata-dokumentet för jämförelseprocessen
i GroupDocs.Comparison. De tillhandahåller alternativ för att specificera metadata, lösenord för utdata-dokumentet och mer.


Den nyckelklass i detta paket är [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions).
Klasser i detta paket låter dig konfigurera specifika alternativ och inställningar relaterade till olika
utdataformat för att generera det önskade utdata-dokumentet för jämförelseprocessen.


För mer information om att spara och konfigurera utdata med GroupDocs.Comparison,
se [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Klasser

| Klass | Beskrivning |
| --- | --- |
| [SaveOptions](../com.groupdocs.comparison.options.save/saveoptions) | Tillåter att specificera ytterligare alternativ när ett dokument sparas. |
