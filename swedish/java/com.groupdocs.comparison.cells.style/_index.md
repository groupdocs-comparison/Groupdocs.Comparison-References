Tillhandahåller klasser för att arbeta med komponentstilar i Cells-formatfiler.


Klasserna i detta paket låter dig arbeta med olika stilar och formateringsalternativ som är specifika för Cells-formatfiler (t.ex. Excel-filer).

Viktiga klasser i detta paket inkluderar:

* [MergeType](../../com.groupdocs.comparison.cells.style/mergetype) - Represents the enumeration the type of cell merge.


För mer information om hur du arbetar med revisioner och spårade ändringar i Word-dokument med GroupDocs.Comparison för Java,
se [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
