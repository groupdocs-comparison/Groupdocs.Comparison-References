Namnrymden tillhandahåller klasser som möjliggör att ange ytterligare alternativ för dokumentjämförelseprocessen.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [ApplyChangeOptions](./applychangeoptions) | Tillåter att uppdatera listan över förändringar innan de tillämpas på det resulterande dokumentet. |
| [CompareOptions](./compareoptions) | Tillåter att ställa in olika jämförelsealternativ. |
| [DiagramMasterSetting](./diagrammastersetting) | Diagram huvudinställningar. |
| [FileAuthorMetadata](./fileauthormetadata) | Information om dokumentets författarmetadata. |
| [GetChangeOptions](./getchangeoptions) | Alternativet tillåter att filtrera förändringar efter typ. |
| [IgnoreChangeSensitivitySettings](./ignorechangesensitivitysettings) | Alternativet tillåter att ignorera förändringar baserat på likhetsprocent. |
| [LoadOptions](./loadoptions) | Tillåter att ange ytterligare alternativ vid inläsning av ett dokument. |
| [OriginalSize](./originalsize) | Representerar original sidstorlek. Används endast för att jämföra bild med olika format. |
| [PagesSetup](./pagessetup) | Anger vilka sidor som ska inkluderas i jämförelsen. |
| [PdfCompareOptions](./pdfcompareoptions) | PDF-dokumentspecifika jämförelsealternativ. Ärver gemensamma alternativ från [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
| [PreviewOptions](./previewoptions) | Representerar förhandsgranskningsalternativ för dokument. |
| [PreviewResolution](./previewresolution) | Representerar upplösningsinställningar för generering av dokumentförhandsgranskning. |
| [SaveOptions](./saveoptions) | Tillåter att ange ytterligare alternativ (t.ex. lösenord) vid sparande av ett dokument. |
| [Size](./size) | Dokumentstorlek. |
| [StyleSettings](./stylesettings) | Stilinställningar. Tillåter att definiera stilregler för förändringar. Används i klassen [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
| [WordCompareOptions](./wordcompareoptions) | Word-dokumentspecifika jämförelsealternativ. Ärver gemensamma alternativ från [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
