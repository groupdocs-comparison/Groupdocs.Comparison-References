## WordCompareOptions.ShowRevisions property

Liest oder setzt, ob das Ergebnisdokument die Revisions-Markup sichtbar hält. Wenn false, werden alle Revisionen akzeptiert und das Ergebnis erscheint als endgültiger Text. Diese Einstellung ist nur sinnvoll, wenn [`DisplayMode`](../displaymode) auf Highlight gesetzt ist. Der Standardwert ist true.

```csharp
public bool ShowRevisions { get; set; }
```
