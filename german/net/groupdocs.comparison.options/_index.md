Der Namespace stellt Klassen zur Verfügung, die das Festlegen zusätzlicher Optionen für den Dokumentvergleichs‑Prozess ermöglichen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ApplyChangeOptions](./applychangeoptions) | Ermöglicht das Aktualisieren der Änderungsliste, bevor sie auf das resultierende Dokument angewendet wird. |
| [CompareOptions](./compareoptions) | Ermöglicht das Festlegen verschiedener Vergleichsoptionen. |
| [DiagramMasterSetting](./diagrammastersetting) | Diagramm-Mastereinstellungen. |
| [FileAuthorMetadata](./fileauthormetadata) | Informationen zu den Metadaten des Dokumentautors. |
| [GetChangeOptions](./getchangeoptions) | Die Option ermöglicht das Filtern von Änderungen nach Typ. |
| [IgnoreChangeSensitivitySettings](./ignorechangesensitivitysettings) | Die Option ermöglicht das Ignorieren von Änderungen nach Ähnlichkeitsprozentsatz. |
| [LoadOptions](./loadoptions) | Ermöglicht das Angeben zusätzlicher Optionen beim Laden eines Dokuments. |
| [OriginalSize](./originalsize) | Stellt die Originalseitengröße dar. Wird nur zum Vergleich von Bildern mit unterschiedlichen Formaten verwendet. |
| [PagesSetup](./pagessetup) | Gibt an, welche Seiten in den Vergleich einbezogen werden sollen. |
| [PdfCompareOptions](./pdfcompareoptions) | PDF-dokumentspezifische Vergleichsoptionen. Erbt gemeinsame Optionen von [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
| [PreviewOptions](./previewoptions) | Stellt Optionen für die Dokumentvorschau dar. |
| [PreviewResolution](./previewresolution) | Stellt Auflösungseinstellungen für die Generierung der Dokumentvorschau dar. |
| [SaveOptions](./saveoptions) | Ermöglicht das Angeben zusätzlicher Optionen (wie z. B. ein Passwort), wenn ein Dokument gespeichert wird. |
| [Size](./size) | Dokumentgröße. |
| [StyleSettings](./stylesettings) | Stileinstellungen. Ermöglicht das Definieren von Stilregeln für Änderungen. Wird in der Klasse [`CompareOptions`](../groupdocs.comparison.options/compareoptions) verwendet. |
| [WordCompareOptions](./wordcompareoptions) | Word-dokumentspezifische Vergleichsoptionen. Erbt gemeinsame Optionen von [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
