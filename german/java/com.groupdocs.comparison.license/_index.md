Stellt Klassen für die Arbeit mit der GroupDocs.Comparison‑Lizenz bereit.


Die Klassen in diesem Paket ermöglichen es Ihnen, Lizenzen für GroupDocs.Comparison zu verwalten und anzuwenden.
Sie können die Lizenzdatei laden und festlegen, den Lizenzstatus prüfen und lizenzbezogene Vorgänge ausführen.


Um die lizenzbezogene Funktionalität zu nutzen, benötigen Sie eine gültige Lizenzdatei, die von GroupDocs bereitgestellt wird.
Sie können die Lizenzdatei mit der [License](../../com.groupdocs.comparison.license/license) Klasse laden und sie dann auf die GroupDocs.Comparison Bibliothek anwenden.


Weitere Details dazu, wie man mit Lizenzen in GroupDocs.Comparison arbeitet, finden Sie im
[Licensing FAQ](../https://purchase.groupdocs.com/faqs/licensing).



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [License](../com.groupdocs.comparison.license/license) | Die License Klasse stellt Methoden zum Festlegen und Anwenden von Lizenzen für GroupDocs.Comparison bereit. |
| [Metered](../com.groupdocs.comparison.license/metered) | Stellt Methoden zum Anwenden einer nutzungsbasierten Lizenz auf Comparison bereit. |
