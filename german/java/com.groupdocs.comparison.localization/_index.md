Stellt Klassen und Schnittstellen für die Lokalisierung in GroupDocs.Comparison bereit. Die Lokalisierungsfunktion ermöglicht es Ihnen, den im Vergleichsprozess angezeigten Text und die Meldungen basierend auf verschiedenen Sprachen oder regionalen Präferenzen anzupassen.

Die Hauptklassen und Schnittstellen in diesem Paket sind:

* [SupportedLocales](../../com.groupdocs.comparison.localization/supportedlocales) - A class provides constants representing the supported locales for GroupDocs.Comparison.


Durch die Verwendung der Lokalisierungsfunktion können Sie den in GroupDocs.Comparison verwendeten Text und die Meldungen an die Sprache oder Präferenzen Ihrer Benutzer anpassen.


Weitere Details zur Arbeit mit Revisionen und nachverfolgten Änderungen in Word-Dokumenten mit GroupDocs.Comparison für Java,
Bitte beachten Sie die [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
