Stellt Klassen und Schnittstellen zum Konfigurieren verschiedener Optionen und Einstellungen im Zusammenhang mit dem Dokumentvergleich bereit. Diese Optionen umfassen Vergleichseinstellungen, Ladeoptionen, Speicheroptionen, Stileinstellungen und mehr. Verwenden Sie diese Klassen, um das Verhalten und das Erscheinungsbild des Dokumentvergleichsprozesses anzupassen.

Wichtige Klassen in diesem Paket:

* [CompareOptions](../../com.groupdocs.comparison.options/compareoptions) - Represents the options for document comparison.
* [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions) - Represents the options for loading documents.
* [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions) - Represents the options for saving comparison results.
* [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings) - Represents style settings for text formatting.


Weitere Details zur Arbeit mit Optionsklassen unter Verwendung von GroupDocs.Comparison für Java,
Bitte beachten Sie die [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ApplyChangeOptions](../com.groupdocs.comparison.options/applychangeoptions) | Ermöglicht das Aktualisieren der Liste von Änderungen, bevor sie auf das resultierende Dokument angewendet werden. |
| [CompareOptions](../com.groupdocs.comparison.options/compareoptions) | Ermöglicht die Konfiguration des Dokumentvergleichsprozesses. |
| [FileAuthorMetadata](../com.groupdocs.comparison.options/fileauthormetadata) | Ermöglicht die Konfiguration von Informationen über die Autor-Metadaten des Dokuments. |
| [GetChangeOptions](../com.groupdocs.comparison.options/getchangeoptions) | Ermöglicht die Konfiguration von Filtern zum Abrufen bestimmter Änderungstypen aus dem Vergleichsergebnis. |
| [OriginalSize](../com.groupdocs.comparison.options/originalsize) | Stellt die ursprüngliche Größe eines Dokuments in einem Vergleichsergebnis dar. |
| [PreviewOptions](../com.groupdocs.comparison.options/previewoptions) | Stellt Optionen zum Erzeugen von Dokumentvorschauen im Vergleichsprozess bereit. |
