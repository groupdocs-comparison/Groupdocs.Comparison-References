Stellt Schnittstellen bereit, die Verträge für verschiedene Komponenten und Funktionalitäten in GroupDocs.Comparison definieren.

Die wichtigsten Schnittstellen in diesem Paket sind:

* [IDocumentInfo](../../com.groupdocs.comparison.interfaces/idocumentinfo) - The interface that defines the contract for the information about a document.


Die Schnittstellen in diesem Paket bieten die notwendigen Verträge für die Implementierung und Interaktion mit verschiedenen
Komponenten und Funktionalitäten in GroupDocs.Comparison.


Weitere Details zur Arbeit mit Revisionen und nachverfolgten Änderungen in Word-Dokumenten mit GroupDocs.Comparison für Java,
Bitte beachten Sie die [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
