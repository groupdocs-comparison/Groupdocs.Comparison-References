Stellt Klassen und Optionen zur Konfiguration des Ladens von Dokumenten in GroupDocs.Comparison bereit.


Die Klassen in diesem Paket werden verwendet, um Quell- und Zieldokumente mit spezifischen Optionen zu laden.
Sie bieten Optionen zum Festlegen von Dokumentformaten, zum Laden passwortgeschützter Dokumente,
zum Festlegen von Schriftartenverzeichnissen und mehr.


Die Schlüsselklasse in diesem Paket ist [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions).
Klassen im Paket ermöglichen es Ihnen, spezifische Optionen und Einstellungen für verschiedene
Dokumentformate für einen genauen und individuellen Dokumentenvergleich.


Weitere Details zum Laden und Konfigurieren von Dokumenten mit GroupDocs.Comparison,
Bitte beachten Sie die [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
