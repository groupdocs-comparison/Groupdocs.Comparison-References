Stellt Klassen und Schnittstellen zur Arbeit mit dem Ergebnis des Dokumentenvergleichs bereit. Das Vergleichsergebnis enthält Informationen über Änderungen, Revisionen, Unterschiede und weitere vergleichsbezogene Daten.

Wichtige Klassen in diesem Paket:

* [ChangeInfo](../../com.groupdocs.comparison.result/changeinfo) - Represents information about a specific change in the comparison result.
* [PageInfo](../../com.groupdocs.comparison.result/pageinfo) - Represents information about a page in the comparison result.
* [StyleChangeInfo](../../com.groupdocs.comparison.result/stylechangeinfo) - Represents information about a style change in a compared document.


Weitere Details zur Arbeit mit dem Ergebnis des Vergleichsprozesses mit GroupDocs.Comparison für Java erhalten Sie,
Bitte beachten Sie die [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Klassen

| Klasse | Beschreibung |

| [PageInfo](../com.groupdocs.comparison.result/pageinfo) | Die Klasse PageInfo stellt Informationen über eine bestimmte Seite in einem Dokument dar. |
| [Rectangle](../com.groupdocs.comparison.result/rectangle) | Die Klasse Rectangle stellt den geänderten Bereich in einem Dokument dar. |
