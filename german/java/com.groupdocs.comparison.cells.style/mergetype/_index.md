## Felder

| Feld | Beschreibung |
| --- | --- |
|  | [NONE](#NONE) | Zeigt an, dass die Zelle nicht zusammengeführt wird. |
|

|

|
|  | [RANGE](#RANGE) | Zeigt an, dass die Zelle entlang der Zeile und Spalte zusammengeführt wird und einen Bereich erstellt. |
