Stellt Klassen für die Arbeit mit Komponentenstilen in Cells‑Formatdateien bereit.


Die Klassen in diesem Paket ermöglichen die Arbeit mit verschiedenen Stilen und Formatierungsoptionen, die speziell für Cells-Formatdateien (z. B. Excel-Dateien) gelten.

Wichtige Klassen in diesem Paket umfassen:

* [MergeType](../../com.groupdocs.comparison.cells.style/mergetype) - Represents the enumeration the type of cell merge.


Weitere Details zur Arbeit mit Revisionen und nachverfolgten Änderungen in Word-Dokumenten mit GroupDocs.Comparison für Java,
Bitte beachten Sie die [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
