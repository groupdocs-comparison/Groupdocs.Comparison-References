Stellt Hilfsklassen mit Methoden bereit, die bei der Verwendung der GroupDocs.Comparison‑API nützlich sein können.


Die Klassen in diesem Paket bieten verschiedene Hilfsmethoden, die bei der Arbeit unterstützen
mit der GroupDocs.Comparison API und bei der Durchführung gängiger Aufgaben im Zusammenhang mit dem Dokumentenvergleich.

Wichtige Klassen in diesem Paket umfassen:

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


Diese Hilfsklassen zielen darauf ab, gängige Aufgaben zu vereinfachen und praktische Methoden für die Arbeit
mit Dateien, Pfaden und Streams im Kontext des Dokumentenvergleichs unter Verwendung der GroupDocs.Comparison API.


Weitere Details zur Arbeit mit Revisionen und nachverfolgten Änderungen in Word-Dokumenten mit GroupDocs.Comparison für Java,
Bitte beachten Sie die [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
