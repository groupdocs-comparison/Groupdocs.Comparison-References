Stellt funktionale Schnittstellen bereit, die den Zugriff auf Seitendaten während des Dokumentvergleichsprozesses ermöglichen.

Die funktionalen Schnittstellen in diesem Paket werden verwendet, um auf Daten von Seiten zuzugreifen, wenn ein Dokumentenvergleich mit GroupDocs.Comparison durchgeführt wird.

Die wichtigsten funktionalen Schnittstellen in diesem Paket sind:

* [CreatePageStreamFunction](../../com.groupdocs.comparison.common.function/createpagestreamfunction) - Allows handling creating output stream used by Comparison to save pages data.
* [ReleasePageStreamFunction](../../com.groupdocs.comparison.common.function/releasepagestreamfunction) - Allows handling releasing output stream used by Comparison to save pages data.


Diese funktionalen Schnittstellen können verwendet werden, um benutzerdefinierte Logik und Verhalten bei der Arbeit mit Dokumentenseiten zu definieren.
Sie bieten Flexibilität, um anzupassen, wie und wo verarbeitete Seiten gespeichert werden.


Weitere Details zur Arbeit mit Revisionen und nachverfolgten Änderungen in Word-Dokumenten mit GroupDocs.Comparison für Java,
Bitte beachten Sie die [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [CreatePageStreamFunction](../com.groupdocs.comparison.common.function/createpagestreamfunction) | Funktionale Schnittstelle, die verwendet wird, um einen Ausgabestream zu erstellen, der von Comparison zum Speichern des Vorschaubildes verwendet wird. |
| [ReleasePageStreamFunction](../com.groupdocs.comparison.common.function/releasepagestreamfunction) | Funktionale Schnittstelle, die verwendet wird, um den Ausgabestream zu schließen, der von Comparison zum Speichern des Vorschaubildes verwendet wurde. |
