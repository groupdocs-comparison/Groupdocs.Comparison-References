Stellt Klassen und Schnittstellen zur Darstellung von Revisionen und nachverfolgten Änderungen in Word‑Dokumenten während des Vergleichsprozesses in GroupDocs.Comparison für Java bereit.


Die Klassen in diesem Paket werden verwendet, um Revisionen und nachverfolgte Änderungen an Word-Dokumenten während des Vergleichsprozesses darzustellen.
Diese Revisionen umfassen Einfügungen, Löschungen, Formatierungsänderungen und weitere Modifikationen des Dokumenteninhalts.


Die wichtigsten Klassen in diesem Paket umfassen [RevisionHandler](../../com.groupdocs.comparison.words.revision/revisionhandler),
[RevisionAction](../../com.groupdocs.comparison.words.revision/revisionaction), and [RevisionInfo](../../com.groupdocs.comparison.words.revision/revisioninfo).


Durch die Verwendung der Klassen und Schnittstellen in diesem Paket können Sie Revisionen und nachverfolgte Änderungen in Word-Dokumenten zugreifen, analysieren und manipulieren.


Weitere Details zur Arbeit mit Revisionen und nachverfolgten Änderungen in Word-Dokumenten mit GroupDocs.Comparison für Java,
Bitte beachten Sie die [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ApplyRevisionOptions](../com.groupdocs.comparison.words.revision/applyrevisionoptions) | Die Klasse ApplyRevisionOptions ermöglicht es Ihnen, den Zustand von Revisionen zu aktualisieren, bevor sie auf das endgültige Dokument angewendet werden. |
| [RevisionHandler](../com.groupdocs.comparison.words.revision/revisionhandler) | Stellt eine Klasse dar, die die Handhabung von Revisionen steuert. |
| [RevisionInfo](../com.groupdocs.comparison.words.revision/revisioninfo) | Stellt eine Revision im Dokument dar. |
