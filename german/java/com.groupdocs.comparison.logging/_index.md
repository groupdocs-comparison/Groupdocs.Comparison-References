Stellt Klassen und Schnittstellen für das Logging in GroupDocs.Comparison bereit. Die Logging‑Funktionalität ermöglicht es Ihnen, verschiedene Ereignisse und Nachrichten während der Ausführung des Vergleichsprozesses aufzuzeichnen und zu überwachen.

Die Hauptklassen und Schnittstellen in diesem Paket sind:

* com.groupdocs.comparison.logging.ILogger - The interface that defines the contract for a logger.
* [ComparisonLogger](../../com.groupdocs.comparison.logging/comparisonlogger) - Provides methods and a way to configure integrated or set user defined logger.
* com.groupdocs.comparison.logging.ConsoleLogger - Provides logger implementation which sends all messages to console.


Durch die Nutzung der Protokollierungsfunktionalität können Sie anpassen, wie Protokollnachrichten verarbeitet werden,
wie zum Beispiel das Schreiben in eine Datei, die Konsole oder ein anderes Ziel Ihrer Wahl.


Weitere Details zur Arbeit mit Revisionen und nachverfolgten Änderungen in Word-Dokumenten mit GroupDocs.Comparison für Java,
Bitte beachten Sie die [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
