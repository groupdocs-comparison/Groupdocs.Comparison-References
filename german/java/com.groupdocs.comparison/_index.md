Das Paket stellt Klassen zum Vergleichen von Dokumenten für alle gängigen Dokumentformate bereit.

Die Hauptklassen in diesem Paket sind:

* [Comparer](../../com.groupdocs.comparison/comparer) is the entry point for comparing documents.
* [Document](../../com.groupdocs.comparison/document) provides details about a document.
* [ComparerSettings](../../com.groupdocs.comparison/comparersettings) defines settings for customizing logging behaviour.


Die Hauptklasse dieses Namespace ist [Comparer](../../com.groupdocs.comparison/comparer). Diese Klasse bietet Methoden zum Hinzufügen von Dokumenten, zum Abrufen von Änderungen, zum Vergleichen von Dokumenten usw.



## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Comparer](../com.groupdocs.comparison/comparer) | Die Comparer-Klasse bietet Funktionalität zum Vergleichen von Dokumenten und zum Erzeugen von Vergleichsergebnissen. |
| [ComparerSettings](../com.groupdocs.comparison/comparersettings) | Definiert Einstellungen zum Anpassen des Verhaltens der [Comparer](../com.groupdocs.comparison/comparer)-Klasse. |
| [Document](../com.groupdocs.comparison/document) | Stellt ein Dokument für den Vergleichsprozess dar. |
