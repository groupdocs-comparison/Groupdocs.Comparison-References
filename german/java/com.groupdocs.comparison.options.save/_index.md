Stellt Klassen und Optionen zum Speichern und Konfigurieren der Ausgabe von GroupDocs.Comparison bereit.


Die Klassen in diesem Paket werden verwendet, um das Ausgabedokument des Vergleichsprozesses zu speichern und zu konfigurieren.
in GroupDocs.Comparison. Sie bieten Optionen zum Festlegen von Metadaten, dem Passwort für das Ausgabedokument und mehr.


Die Schlüsselklasse in diesem Paket ist [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions).
Klassen in diesem Paket ermöglichen die Konfiguration spezifischer Optionen und Einstellungen, die sich auf verschiedene
Ausgabeformate zum Erzeugen des gewünschten Ausgabedokuments des Vergleichsprozesses.


Weitere Details zum Speichern und Konfigurieren der Ausgabe mit GroupDocs.Comparison erhalten Sie,
Bitte beachten Sie die [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).

| --- | --- |
| [SaveOptions](../com.groupdocs.comparison.options.save/saveoptions) | Ermöglicht das Festlegen zusätzlicher Optionen beim Speichern eines Dokuments. |
