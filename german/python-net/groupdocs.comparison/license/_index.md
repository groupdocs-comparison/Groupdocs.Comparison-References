## License class

Verwaltet die Lizenzierung von GroupDocs.Comparison.

Lizenzierte Builds schalten den vollen Funktionsumfang des Wrappers frei bei
Laufzeit. Nicht lizenzierte Builds laufen im Evaluierungsmodus mit derselben API
Oberfläche, jedoch mit Begrenzungen bei der Ausgabengröße und wasserzeichenhaltigem Inhalt.

Der Typ License stellt die folgenden Mitglieder bereit:

| :- | :- |
| [set_license](/comparison/python-net/groupdocs.comparison/license/set_license/#license_source) | Wenden Sie eine Lizenz auf den aktuellen Prozess an. |
