## Metered class

Verwaltet die nutzungsbasierte (Pay-per-Use) Lizenzierung.

Metered Lizenzen werden nach tatsächlichem Verbrauch abgerechnet (typischerweise Seiten oder
verarbeitete Dokumente). Setzen Sie das public/private Schlüssel‑Paar einmal bei
Anwendungsstart; der Wrapper meldet die Nutzung zurück an die GroupDocs
Lizenzserver im Hintergrund.

Der Metered Typ stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [get_consumption_credit](/comparison/python-net/groupdocs.comparison/metered/get_consumption_credit/) | Gibt das verbleibende Metered Guthaben für den aktuellen Schlüssel zurück. |
| [get_consumption_quantity](/comparison/python-net/groupdocs.comparison/metered/get_consumption_quantity/) | Gibt die bisher verbrauchte gesamte Metered Menge zurück. |
| [set_metered_key](/comparison/python-net/groupdocs.comparison/metered/set_metered_key/#public_key-private_key) | Aktivieren Sie die Metered-Abrechnung mit dem angegebenen public/private Schlüssel‑Paar. |
