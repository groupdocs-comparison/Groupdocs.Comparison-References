توفر الحزمة الفئات لمقارنة المستندات لجميع صيغ المستندات الشائعة.

الفئات الرئيسية في هذه الحزمة هي:

* [Comparer](../../com.groupdocs.comparison/comparer) is the entry point for comparing documents.
* [Document](../../com.groupdocs.comparison/document) provides details about a document.
* [ComparerSettings](../../com.groupdocs.comparison/comparersettings) defines settings for customizing logging behaviour.


الفئة الرئيسية في هذا النطاق هي [Comparer](../../com.groupdocs.comparison/comparer). توفر هذه الفئة طرقًا لإضافة المستندات، الحصول على التغييرات، مقارنة المستندات، إلخ.



## الفئات

| الفئة | الوصف |
| --- | --- |
| [Comparer](../com.groupdocs.comparison/comparer) | توفر فئة Comparer وظائف لمقارنة المستندات وتوليد نتائج المقارنة. |
| [ComparerSettings](../com.groupdocs.comparison/comparersettings) | يحدد الإعدادات لتخصيص سلوك الفئة [Comparer](../com.groupdocs.comparison/comparer). |
| [Document](../com.groupdocs.comparison/document) | يمثل مستندًا لعملية المقارنة. |
