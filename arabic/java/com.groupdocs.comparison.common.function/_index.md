توفر الواجهات الوظيفية التي تسمح بالوصول إلى بيانات الصفحات أثناء عملية مقارنة المستندات.

تُستخدم الواجهات الوظيفية في هذه الحزمة للوصول إلى بيانات الصفحات عند إجراء مقارنة المستندات باستخدام GroupDocs.Comparison.

الواجهات الوظيفية الرئيسية في هذه الحزمة هي:

* [CreatePageStreamFunction](../../com.groupdocs.comparison.common.function/createpagestreamfunction) - Allows handling creating output stream used by Comparison to save pages data.
* [ReleasePageStreamFunction](../../com.groupdocs.comparison.common.function/releasepagestreamfunction) - Allows handling releasing output stream used by Comparison to save pages data.


يمكن استخدام هذه الواجهات الوظيفية لتعريف المنطق والسلوك المخصص عند العمل مع صفحات المستند.
توفر مرونة لتخصيص كيفية وأين يتم حفظ الصفحات التي تتم معالجتها.


لمزيد من التفاصيل حول العمل مع المراجعات والتغييرات المتتبعة في مستندات Word باستخدام GroupDocs.Comparison للغة Java،
يرجى الرجوع إلى [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
