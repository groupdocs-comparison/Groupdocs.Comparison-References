توفر الفئات المساعدة مع طرق يمكن أن تكون مفيدة عند استخدام API الخاص بـ GroupDocs.Comparison.


الفئات في هذه الحزمة تقدم طرق مساعدة متنوعة يمكن أن تساعد في العمل
مع واجهة برمجة تطبيقات GroupDocs.Comparison وأداء المهام الشائعة المتعلقة بمقارنة المستندات.

الفئات الرئيسية في هذه الحزمة تشمل:

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


تهدف هذه الفئات المساعدة إلى تبسيط المهام الشائعة وتوفير طرق مريحة للعمل
مع الملفات والمسارات وتدفقات البيانات في سياق مقارنة المستندات باستخدام واجهة برمجة تطبيقات GroupDocs.Comparison.


لمزيد من التفاصيل حول العمل مع المراجعات والتغييرات المتتبعة في مستندات Word باستخدام GroupDocs.Comparison للغة Java،
يرجى الرجوع إلى [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
