توفر مساحة الاسم فئات تسمح بتحديد خيارات إضافية لعملية مقارنة المستندات.

## الفئات

| الفئة | الوصف |
| --- | --- |
| [ApplyChangeOptions](./applychangeoptions) | يسمح بتحديث قائمة التغييرات قبل تطبيقها على المستند الناتج. |
| [CompareOptions](./compareoptions) | يسمح بتعيين خيارات مقارنة مختلفة. |
| [DiagramMasterSetting](./diagrammastersetting) | إعدادات المخطط الرئيسي. |
| [FileAuthorMetadata](./fileauthormetadata) | معلومات حول بيانات تعريف مؤلف المستند. |
| [GetChangeOptions](./getchangeoptions) | الخيار يسمح بتصفية التغييرات حسب النوع. |
| [IgnoreChangeSensitivitySettings](./ignorechangesensitivitysettings) | الخيار يسمح بتجاهل التغييرات بناءً على نسبة التشابه. |
| [LoadOptions](./loadoptions) | يسمح بتحديد خيارات إضافية عند تحميل مستند. |
| [OriginalSize](./originalsize) | يمثل حجم الصفحة الأصلي. يُستخدم فقط لمقارنة صورة ذات صيغ مختلفة. |
| [PagesSetup](./pagessetup) | يحدد الصفحات التي يجب تضمينها في المقارنة. |
| [PdfCompareOptions](./pdfcompareoptions) | خيارات مقارنة خاصة بمستند PDF. يرث الخيارات العامة من [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
| [PreviewOptions](./previewoptions) | يمثل خيارات معاينة المستند. |
| [PreviewResolution](./previewresolution) | يمثل إعدادات الدقة لتوليد معاينة المستند. |
| [SaveOptions](./saveoptions) | يسمح بتحديد خيارات إضافية (مثل كلمة المرور) عند حفظ مستند. |
| [Size](./size) | حجم المستند. |
| [StyleSettings](./stylesettings) | إعدادات النمط. يسمح بتعريف قواعد النمط للتغييرات. يُستخدم في فئة [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
| [WordCompareOptions](./wordcompareoptions) | خيارات مقارنة خاصة بمستند Word. يرث الخيارات العامة من [`CompareOptions`](../groupdocs.comparison.options/compareoptions). |
