## WordCompareOptions.ShowRevisions property

Ottiene o imposta se il documento risultante mantiene visibile il markup delle revisioni. Se false, tutte le revisioni sono accettate e il risultato appare come testo finale. Questa impostazione è significativa solo quando [`DisplayMode`](../displaymode) è impostato su Highlight. Il valore predefinito è true.

public bool ShowRevisions { get; set; }
