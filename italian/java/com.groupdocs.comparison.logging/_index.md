Fornisce classi e interfacce per la registrazione in GroupDocs.Comparison. La funzionalità di registrazione consente di registrare e monitorare vari eventi e messaggi durante l'esecuzione del processo di confronto.

Le classi e le interfacce principali in questo pacchetto sono:

* com.groupdocs.comparison.logging.ILogger - The interface that defines the contract for a logger.
* [ComparisonLogger](../../com.groupdocs.comparison.logging/comparisonlogger) - Provides methods and a way to configure integrated or set user defined logger.
* com.groupdocs.comparison.logging.ConsoleLogger - Provides logger implementation which sends all messages to console.


Utilizzando la funzionalità di logging, è possibile personalizzare il modo in cui i messaggi di log vengono gestiti,
ad esempio scrivendoli su un file, sulla console o su qualsiasi altra destinazione a tua scelta.


Per ulteriori dettagli su come lavorare con revisioni e modifiche tracciate nei documenti Word utilizzando GroupDocs.Comparison per Java,
consulta la [Documentazione di GroupDocs.Comparison](../https://docs.groupdocs.com/comparison/java/).
