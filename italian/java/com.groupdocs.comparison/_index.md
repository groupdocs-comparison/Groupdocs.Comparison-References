Il pacchetto fornisce classi per confrontare documenti in tutti i formati di documento più popolari.

Le classi principali in questo pacchetto sono:

* [Comparer](../../com.groupdocs.comparison/comparer) is the entry point for comparing documents.
* [Document](../../com.groupdocs.comparison/document) provides details about a document.
* [ComparerSettings](../../com.groupdocs.comparison/comparersettings) defines settings for customizing logging behaviour.


La classe principale di questo namespace è [Comparer](../../com.groupdocs.comparison/comparer). Questa classe fornisce metodi per aggiungere documenti, ottenere modifiche, confrontare documenti ecc.



## Classi

| Classe | Descrizione |
| --- | --- |
| [Comparer](../com.groupdocs.comparison/comparer) | La classe Comparer fornisce funzionalità per confrontare documenti e generare risultati di confronto. |
| [ComparerSettings](../com.groupdocs.comparison/comparersettings) | Definisce le impostazioni per personalizzare il comportamento della classe [Comparer](../com.groupdocs.comparison/comparer). |
| [Document](../com.groupdocs.comparison/document) | Rappresenta un documento per il processo di confronto dei documenti. |
