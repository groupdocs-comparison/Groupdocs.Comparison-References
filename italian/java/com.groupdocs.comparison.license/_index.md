Fornisce classi per lavorare con la licenza di GroupDocs.Comparison.


Le classi in questo pacchetto consentono di gestire e applicare le licenze per GroupDocs.Comparison.
È possibile caricare e impostare il file di licenza, verificare lo stato della licenza ed eseguire operazioni correlate alla licenza.


Per utilizzare le funzionalità relative alla licenza, è necessario un file di licenza valido fornito da GroupDocs.
Puoi caricare il file di licenza usando la classe [License](../../com.groupdocs.comparison.license/license) e quindi applicarlo alla libreria GroupDocs.Comparison.


Per ulteriori dettagli su come gestire le licenze in GroupDocs.Comparison, fai riferimento a
[Licensing FAQ](../https://purchase.groupdocs.com/faqs/licensing).



## Classi

| Classe | Descrizione |
| --- | --- |
| [License](../com.groupdocs.comparison.license/license) | La classe License fornisce metodi per impostare e applicare le licenze per GroupDocs.Comparison. |
| [Metered](../com.groupdocs.comparison.license/metered) | Fornisce metodi per applicare una licenza a consumo a Comparison. |
