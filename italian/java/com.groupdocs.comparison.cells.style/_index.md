Fornisce classi per lavorare con gli stili dei componenti nei file in formato Cells.


Le classi in questo pacchetto consentono di lavorare con vari stili e opzioni di formattazione specifici per i file in formato Cells (ad esempio, file Excel).

Le classi chiave in questo pacchetto includono:

* [MergeType](../../com.groupdocs.comparison.cells.style/mergetype) - Represents the enumeration the type of cell merge.

consulta la [Documentazione di GroupDocs.Comparison](../https://docs.groupdocs.com/comparison/java/).
