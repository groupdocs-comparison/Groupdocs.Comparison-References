Fornisce classi e interfacce per configurare varie opzioni e impostazioni relative al confronto dei documenti. Queste opzioni includono impostazioni di confronto, opzioni di caricamento, opzioni di salvataggio, impostazioni di stile e altro. Utilizza queste classi per personalizzare il comportamento e l'aspetto del processo di confronto dei documenti.

Classi chiave in questo pacchetto:

* [CompareOptions](../../com.groupdocs.comparison.options/compareoptions) - Represents the options for document comparison.
* [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions) - Represents the options for loading documents.
* [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions) - Represents the options for saving comparison results.
* [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings) - Represents style settings for text formatting.


Per ulteriori dettagli sul lavoro con le classi delle opzioni usando GroupDocs.Comparison per Java,
consulta la [Documentazione di GroupDocs.Comparison](../https://docs.groupdocs.com/comparison/java/).

| Classe | Descrizione |

| [FileAuthorMetadata](../com.groupdocs.comparison.options/fileauthormetadata) | Consente di configurare le informazioni sui metadati dell'autore del documento. |

| [PreviewOptions](../com.groupdocs.comparison.options/previewoptions) | Fornisce opzioni per generare anteprime dei documenti nel processo di confronto. |
