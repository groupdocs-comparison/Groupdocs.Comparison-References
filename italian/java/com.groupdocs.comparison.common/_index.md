Fornisce classi di utilità con metodi che possono essere utili quando si utilizza l'API di GroupDocs.Comparison.


Le classi in questo pacchetto offrono vari metodi di utilità che possono assistere nel lavoro
con l'API GroupDocs.Comparison e nell'esecuzione di attività comuni relative al confronto dei documenti.

Le classi chiave in questo pacchetto includono:

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


Queste classi di utilità mirano a semplificare le attività comuni e a fornire metodi di comodità per lavorare
con file, percorsi e stream nel contesto del confronto dei documenti utilizzando l'API GroupDocs.Comparison.


Per ulteriori dettagli su come lavorare con revisioni e modifiche tracciate nei documenti Word utilizzando GroupDocs.Comparison per Java,
consulta la [Documentazione di GroupDocs.Comparison](../https://docs.groupdocs.com/comparison/java/).
