Fornisce interfacce funzionali che consentono di accedere ai dati delle pagine durante il processo di confronto dei documenti.

Le interfacce funzionali in questo pacchetto sono utilizzate per accedere ai dati delle pagine durante l'esecuzione del confronto di documenti con GroupDocs.Comparison.

Le principali interfacce funzionali in questo pacchetto sono:

* [CreatePageStreamFunction](../../com.groupdocs.comparison.common.function/createpagestreamfunction) - Allows handling creating output stream used by Comparison to save pages data.
* [ReleasePageStreamFunction](../../com.groupdocs.comparison.common.function/releasepagestreamfunction) - Allows handling releasing output stream used by Comparison to save pages data.


Queste interfacce funzionali possono essere utilizzate per definire logica e comportamento personalizzati quando si lavora con le pagine dei documenti.
Offrono flessibilità per personalizzare come e dove le pagine vengono elaborate e salvate.


Per ulteriori dettagli su come lavorare con revisioni e modifiche tracciate nei documenti Word utilizzando GroupDocs.Comparison per Java,
consulta la [Documentazione di GroupDocs.Comparison](../https://docs.groupdocs.com/comparison/java/).



## Interfacce

| Interfaccia | Descrizione |
| --- | --- |
| [CreatePageStreamFunction](../com.groupdocs.comparison.common.function/createpagestreamfunction) | Interfaccia funzionale utilizzata per creare lo stream di output usato da Comparison per salvare l'immagine di anteprima. |
| [ReleasePageStreamFunction](../com.groupdocs.comparison.common.function/releasepagestreamfunction) | Interfaccia funzionale utilizzata per chiudere lo stream di output che è stato usato da Comparison per salvare l'immagine di anteprima. |
