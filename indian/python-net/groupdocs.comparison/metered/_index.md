## Metered class

मीटरड (पे-पर-यूज़) लाइसेंसिंग को प्रबंधित करता है।

Metered लाइसेंस वास्तविक उपभोग पर बिल बनाते हैं (आमतौर पर पृष्ठ या
दस्तावेज़ प्रसंस्कृत)। सार्वजनिक/निजी कुंजी जोड़ी को एक बार सेट करें
एप्लिकेशन स्टार्टअप; रैपर उपयोग को GroupDocs को वापस रिपोर्ट करता है
पृष्ठभूमि में लाइसेंस सर्वर।

Metered प्रकार निम्नलिखित सदस्य उजागर करता है:

### विधियाँ
| विधि | विवरण |
| :- | :- |
| [get_consumption_credit](/comparison/python-net/groupdocs.comparison/metered/get_consumption_credit/) | वर्तमान कुंजी के लिए शेष मीटरेड क्रेडिट लौटाएँ। |
| [get_consumption_quantity](/comparison/python-net/groupdocs.comparison/metered/get_consumption_quantity/) | अब तक उपभोग की गई कुल मीटरेड मात्रा लौटाएँ। |
| [set_metered_key](/comparison/python-net/groupdocs.comparison/metered/set_metered_key/#public_key-private_key) | दिए गए सार्वजनिक/निजी कुंजी जोड़ी के साथ मीटरेड बिलिंग सक्रिय करें। |
