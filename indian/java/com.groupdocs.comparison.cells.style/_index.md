इस पैकेज में प्रमुख क्लासेस शामिल हैं:

* [MergeType](../../com.groupdocs.comparison.cells.style/mergetype) - Represents the enumeration the type of cell merge.

कृपया देखें [GroupDocs.Comparison दस्तावेज़ीकरण](../https://docs.groupdocs.com/comparison/java/).
