GroupDocs.Comparison API का उपयोग करते समय उपयोगी हो सकने वाले मेथड्स वाली यूटिलिटी क्लास प्रदान करता है।


इस पैकेज की क्लासेस विभिन्न उपयोगी मेथड्स प्रदान करती हैं जो काम करने में सहायता कर सकते हैं
GroupDocs.Comparison API के साथ और दस्तावेज़ तुलना से संबंधित सामान्य कार्यों को करने में।

इस पैकेज में प्रमुख क्लासेस शामिल हैं:

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


ये उपयोगी क्लासेस सामान्य कार्यों को सरल बनाने और काम करने के लिए सुविधाजनक मेथड्स प्रदान करने का लक्ष्य रखती हैं
फ़ाइलों, पाथों और स्ट्रीम्स के साथ, GroupDocs.Comparison API का उपयोग करके दस्तावेज़ तुलना के संदर्भ में।


GroupDocs.Comparison for Java का उपयोग करके Word दस्तावेज़ों में संशोधन और ट्रैक्ड परिवर्तन के साथ काम करने के बारे में अधिक विवरण के लिए,
कृपया देखें [GroupDocs.Comparison दस्तावेज़ीकरण](../https://docs.groupdocs.com/comparison/java/).



## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [MemoryCleaner](../com.groupdocs.comparison.common/memorycleaner) | विभिन्न संसाधनों को साफ़ करता है ताकि मेमोरी मुक्त हो सके। |
| [Utils](../com.groupdocs.comparison.common/utils) | उपयोगी क्लास जो सामान्य हेल्पर मेथड्स प्रदान करती है, जो Comparison API का उपयोग करते समय उपयोगी हो सकते हैं। |
