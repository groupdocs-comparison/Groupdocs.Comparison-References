पैकेज सभी लोकप्रिय दस्तावेज़ फ़ॉर्मेट्स की तुलना करने के लिए क्लास प्रदान करता है।

इस पैकेज में मुख्य क्लासेस हैं:

* [Comparer](../../com.groupdocs.comparison/comparer) is the entry point for comparing documents.
* [Document](../../com.groupdocs.comparison/document) provides details about a document.
* [ComparerSettings](../../com.groupdocs.comparison/comparersettings) defines settings for customizing logging behaviour.


इस नेमस्पेस की मुख्य क्लास है [Comparer](../../com.groupdocs.comparison/comparer)। यह क्लास दस्तावेज़ जोड़ने, परिवर्तन प्राप्त करने, दस्तावेज़ों की तुलना करने आदि के लिए मेथड्स प्रदान करती है।



## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [Comparer](../com.groupdocs.comparison/comparer) | Comparer क्लास दस्तावेज़ों की तुलना करने और तुलना परिणाम उत्पन्न करने की कार्यक्षमता प्रदान करती है। |
| [ComparerSettings](../com.groupdocs.comparison/comparersettings) | परिभाषित करता है सेटिंग्स को [Comparer](../com.groupdocs.comparison/comparer) क्लास के व्यवहार को अनुकूलित करने के लिए। |
| [Document](../com.groupdocs.comparison/document) | तुलना प्रक्रिया के लिए एक दस्तावेज़ का प्रतिनिधित्व करता है। |
