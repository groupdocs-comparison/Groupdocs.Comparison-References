दस्तावेज़ तुलना के परिणाम के साथ काम करने के लिए क्लासेस और इंटरफ़ेस प्रदान करता है। तुलना परिणाम में परिवर्तन, संशोधन, अंतर, और अन्य तुलना-संबंधी डेटा की जानकारी शामिल होती है।

इस पैकेज में प्रमुख क्लासेस:

* [ChangeInfo](../../com.groupdocs.comparison.result/changeinfo) - Represents information about a specific change in the comparison result.
* [PageInfo](../../com.groupdocs.comparison.result/pageinfo) - Represents information about a page in the comparison result.
* [StyleChangeInfo](../../com.groupdocs.comparison.result/stylechangeinfo) - Represents information about a style change in a compared document.


GroupDocs.Comparison for Java का उपयोग करके तुलना प्रक्रिया के परिणाम के साथ काम करने के बारे में अधिक विवरण के लिए,
कृपया देखें [GroupDocs.Comparison दस्तावेज़ीकरण](../https://docs.groupdocs.com/comparison/java/).



## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [ChangeInfo](../com.groupdocs.comparison.result/changeinfo) | ChangeInfo क्लास दस्तावेज़ तुलना में एक विशिष्ट परिवर्तन की जानकारी दर्शाती है। |
| [PageInfo](../com.groupdocs.comparison.result/pageinfo) | PageInfo क्लास दस्तावेज़ में एक विशिष्ट पृष्ठ की जानकारी दर्शाती है। |
| [Rectangle](../com.groupdocs.comparison.result/rectangle) | Rectangle क्लास दस्तावेज़ पर बदलित क्षेत्र को दर्शाती है। |
| [StyleChangeInfo](../com.groupdocs.comparison.result/stylechangeinfo) | StyleChangeInfo क्लास तुलना किए गए दस्तावेज़ में शैली परिवर्तन की जानकारी दर्शाती है। |

## एन्यूमरेशन

| एन्यूम | विवरण |
| --- | --- |
| [ChangeType](../com.groupdocs.comparison.result/changetype) | ChangeType enum दस्तावेज़ तुलना प्रक्रिया के दौरान हो सकने वाले परिवर्तन प्रकारों को दर्शाता है। |
| [ComparisonAction](../com.groupdocs.comparison.result/comparisonaction) | ComparisonAction enum दस्तावेज़ तुलना प्रक्रिया के दौरान परिवर्तन पर लागू की जा सकने वाली क्रियाओं को दर्शाता है। |
| [FileType](../com.groupdocs.comparison.result/filetype) | FileType enum दस्तावेज़ तुलना प्रक्रिया में उपयोग की जाने वाली फ़ाइल के प्रकार को दर्शाता है। |
