नामस्थान दस्तावेज़ तुलना प्रक्रिया के लिए अतिरिक्त विकल्प निर्दिष्ट करने की अनुमति देने वाली क्लास प्रदान करता है।

## क्लासेस

| क्लास | विवरण |
| --- | --- |
| [ApplyChangeOptions](./applychangeoptions) | परिणामी दस्तावेज़ पर लागू करने से पहले परिवर्तन सूची को अपडेट करने की अनुमति देता है। |
| [CompareOptions](./compareoptions) | विभिन्न तुलना विकल्प सेट करने की अनुमति देता है। |
| [DiagramMasterSetting](./diagrammastersetting) | डायग्राम मास्टर सेटिंग्स। |
| [FileAuthorMetadata](./fileauthormetadata) | दस्तावेज़ के लेखक मेटाडेटा के बारे में जानकारी। |
| [GetChangeOptions](./getchangeoptions) | यह विकल्प प्रकार के आधार पर परिवर्तन को फ़िल्टर करने की अनुमति देता है। |
| [IgnoreChangeSensitivitySettings](./ignorechangesensitivitysettings) | यह विकल्प समानता प्रतिशत के आधार पर परिवर्तन को अनदेखा करने की अनुमति देता है। |
| [LoadOptions](./loadoptions) | दस्तावेज़ लोड करते समय अतिरिक्त विकल्प निर्दिष्ट करने की अनुमति देता है। |
| [OriginalSize](./originalsize) | मूल पृष्ठ आकार को दर्शाता है। केवल विभिन्न स्वरूपों की छवि की तुलना करने के लिए उपयोग किया जाता है। |
| [PagesSetup](./pagessetup) | तुलना में शामिल करने के लिए पृष्ठों को निर्दिष्ट करता है। |
| [PdfCompareOptions](./pdfcompareoptions) | PDF दस्तावेज़ के विशिष्ट तुलना विकल्प। सामान्य विकल्पों को [`CompareOptions`](../groupdocs.comparison.options/compareoptions) से विरासत में प्राप्त करता है। |
| [PreviewOptions](./previewoptions) | दस्तावेज़ प्रीव्यू विकल्पों को दर्शाता है। |
| [PreviewResolution](./previewresolution) | दस्तावेज़ प्रीव्यू जनरेशन के लिए रिज़ॉल्यूशन सेटिंग्स को दर्शाता है। |
| [SaveOptions](./saveoptions) | दस्तावेज़ सहेजते समय अतिरिक्त विकल्प (जैसे पासवर्ड) निर्दिष्ट करने की अनुमति देता है। |
| [Size](./size) | दस्तावेज़ आकार। |
| [StyleSettings](./stylesettings) | स्टाइल सेटिंग्स। परिवर्तन के लिए स्टाइल नियम परिभाषित करने की अनुमति देता है। [`CompareOptions`](../groupdocs.comparison.options/compareoptions) क्लास में उपयोग किया जाता है। |
| [WordCompareOptions](./wordcompareoptions) | Word दस्तावेज़ के विशिष्ट तुलना विकल्प। सामान्य विकल्पों को [`CompareOptions`](../groupdocs.comparison.options/compareoptions) से विरासत में प्राप्त करता है। |
