Menyediakan kelas dan opsi untuk menata dan mengkonfigurasi tampilan visual output perbandingan dokumen di GroupDocs.Comparison.


Kelas-kelas dalam paket ini digunakan untuk mendefinisikan dan menyesuaikan berbagai aspek gaya pada output perbandingan dokumen, seperti warna,
penyorotan, penggarisan, dan lainnya. Mereka memungkinkan Anda mengontrol tampilan visual konten yang ditambahkan, dihapus, dan diubah dalam hasil perbandingan.


Kelas kunci dalam paket ini meliputi [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings).
Kelas-kelas dalam paket ini menyediakan metode dan properti untuk mendefinisikan serta mengonfigurasi pengaturan gaya bagi berbagai komponen dan elemen hasil perbandingan.
Anda dapat mengatur gaya font, warna, penyorotan, penggarisan, dan opsi pemformatan lainnya untuk mencapai representasi visual yang diinginkan dari perubahan.


Untuk detail lebih lanjut tentang penataan gaya dan konfigurasi tampilan output perbandingan dokumen menggunakan GroupDocs.Comparison,
silakan merujuk ke [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
