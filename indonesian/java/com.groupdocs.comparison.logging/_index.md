Menyediakan kelas dan antarmuka untuk pencatatan di GroupDocs.Comparison. Fungsionalitas pencatatan memungkinkan Anda merekam dan memantau berbagai peristiwa dan pesan selama pelaksanaan proses perbandingan.

Kelas utama dan antarmuka dalam paket ini adalah:

* com.groupdocs.comparison.logging.ILogger - The interface that defines the contract for a logger.
* [ComparisonLogger](../../com.groupdocs.comparison.logging/comparisonlogger) - Provides methods and a way to configure integrated or set user defined logger.
* com.groupdocs.comparison.logging.ConsoleLogger - Provides logger implementation which sends all messages to console.


Dengan menggunakan fungsi pencatatan, Anda dapat menyesuaikan cara pesan log ditangani,
seperti menuliskannya ke file, konsol, atau tujuan lain apa pun yang Anda pilih.


Untuk detail lebih lanjut tentang bekerja dengan revisi dan perubahan yang dilacak dalam dokumen Word menggunakan GroupDocs.Comparison untuk Java,
silakan merujuk ke [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [ComparisonLogger](../com.groupdocs.comparison.logging/comparisonlogger) | Mengimplementasikan metode pencatatan dan cara untuk mengkonfigurasi logger terintegrasi atau menetapkan logger yang didefinisikan pengguna. |
| [FileLogger](../com.groupdocs.comparison.logging/filelogger) | Logger yang menulis log ke file. |
