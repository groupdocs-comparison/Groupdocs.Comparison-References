Paket ini menyediakan kelas untuk membandingkan dokumen untuk semua format dokumen populer.

Kelas utama dalam paket ini adalah:

* [Comparer](../../com.groupdocs.comparison/comparer) is the entry point for comparing documents.
* [Document](../../com.groupdocs.comparison/document) provides details about a document.
* [ComparerSettings](../../com.groupdocs.comparison/comparersettings) defines settings for customizing logging behaviour.


Kelas utama dalam namespace ini adalah [Comparer](../../com.groupdocs.comparison/comparer). Kelas ini menyediakan metode untuk menambahkan dokumen, memperoleh perubahan, membandingkan dokumen, dll.



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [Comparer](../com.groupdocs.comparison/comparer) | Kelas Comparer menyediakan fungsionalitas untuk membandingkan dokumen dan menghasilkan hasil perbandingan. |
| [ComparerSettings](../com.groupdocs.comparison/comparersettings) | Mendefinisikan pengaturan untuk menyesuaikan perilaku kelas [Comparer](../com.groupdocs.comparison/comparer). |
| [Document](../com.groupdocs.comparison/document) | Mewakili dokumen untuk proses perbandingan. |
