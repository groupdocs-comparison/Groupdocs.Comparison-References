Menyediakan kelas untuk bekerja dengan lisensi GroupDocs.Comparison.


Kelas dalam paket ini memungkinkan Anda mengelola dan menerapkan lisensi untuk GroupDocs.Comparison.
Anda dapat memuat dan mengatur file lisensi, memeriksa status lisensi, serta melakukan operasi terkait lisensi.


Untuk menggunakan fungsionalitas terkait lisensi, Anda memerlukan file lisensi yang valid yang disediakan oleh GroupDocs.
Anda dapat memuat file lisensi menggunakan kelas [License](../../com.groupdocs.comparison.license/license) dan kemudian menerapkannya ke pustaka GroupDocs.Comparison.


Untuk detail lebih lanjut tentang cara bekerja dengan lisensi di GroupDocs.Comparison, silakan merujuk ke
[Licensing FAQ](../https://purchase.groupdocs.com/faqs/licensing).
