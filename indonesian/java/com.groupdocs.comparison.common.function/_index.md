Menyediakan antarmuka fungsional yang memungkinkan mengakses data halaman selama proses perbandingan dokumen.

Antarmuka fungsional dalam paket ini digunakan untuk mengakses data halaman saat melakukan perbandingan dokumen menggunakan GroupDocs.Comparison.

Antarmuka fungsional utama dalam paket ini adalah:

* [CreatePageStreamFunction](../../com.groupdocs.comparison.common.function/createpagestreamfunction) - Allows handling creating output stream used by Comparison to save pages data.
* [ReleasePageStreamFunction](../../com.groupdocs.comparison.common.function/releasepagestreamfunction) - Allows handling releasing output stream used by Comparison to save pages data.


Antarmuka fungsional ini dapat digunakan untuk mendefinisikan logika dan perilaku khusus saat bekerja dengan halaman dokumen.
Mereka memberikan fleksibilitas untuk menyesuaikan cara dan tempat pemrosesan halaman.


Untuk detail lebih lanjut tentang bekerja dengan revisi dan perubahan yang dilacak dalam dokumen Word menggunakan GroupDocs.Comparison untuk Java,
silakan merujuk ke [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
