Menyediakan kelas utilitas dengan metode yang dapat berguna saat menggunakan API GroupDocs.Comparison.


Kelas dalam paket ini menawarkan berbagai metode utilitas yang dapat membantu dalam bekerja
dengan API GroupDocs.Comparison dan melakukan tugas umum yang terkait dengan perbandingan dokumen.

Kelas kunci dalam paket ini meliputi:

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


Kelas utilitas ini bertujuan menyederhanakan tugas umum dan menyediakan metode yang memudahkan dalam bekerja
dengan file, jalur, dan aliran dalam konteks perbandingan dokumen menggunakan API GroupDocs.Comparison.


Untuk detail lebih lanjut tentang bekerja dengan revisi dan perubahan yang dilacak dalam dokumen Word menggunakan GroupDocs.Comparison untuk Java,
silakan merujuk ke [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
