Menyediakan enumerasi untuk berbagai opsi dan pengaturan di GroupDocs.Comparison.


Kelas-kelas dalam paket ini berisi enumerasi yang mendefinisikan berbagai opsi dan pengaturan
yang digunakan dalam GroupDocs.Comparison untuk tujuan penyesuaian dan konfigurasi.
Enumerasi ini digunakan sebagai parameter dalam berbagai metode dan kelas untuk mengontrol perilaku
dan tampilan proses perbandingan dokumen.


Beberapa enumerasi kunci dalam paket ini meliputi [ChangeType](../../com.groupdocs.comparison.result/changetype),
com.groupdocs.comparison.cells.style.ComparisonStyle, dan lainnya.
Enumerasi ini memungkinkan Anda mendapatkan jenis perubahan, gaya perbandingan
dan opsi lainnya untuk proses perbandingan dokumen.


Untuk detail lebih lanjut tentang opsi yang tersedia dan cara menggunakannya dalam GroupDocs.Comparison,
silakan merujuk ke [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Enumerasi

| Enum | Deskripsi |
| --- | --- |
| [ComparisonType](../com.groupdocs.comparison.options.enums/comparisontype) | Mewakili jenis perbandingan yang akan dilakukan. |
| [FolderComparisonExtension](../com.groupdocs.comparison.options.enums/foldercomparisonextension) | Kelas FolderComparisonExtension adalah enumerasi yang mewakili berbagai ekstensi file yang dapat digunakan dalam perbandingan folder. |
| [MetadataType](../com.groupdocs.comparison.options.enums/metadatatype) | Menentukan dari mana dokumen hasil akan mengambil informasi metadata. |
| [PaperSize](../com.groupdocs.comparison.options.enums/papersize) | Mewakili opsi ukuran kertas untuk perbandingan dokumen. |
| [PasswordSaveOption](../com.groupdocs.comparison.options.enums/passwordsaveoption) | Menumerasikan opsi untuk menyimpan informasi kata sandi dalam dokumen selama proses perbandingan. |
| [PreviewFormats](../com.groupdocs.comparison.options.enums/previewformats) | Menumerasikan format pratinjau yang didukung untuk perbandingan dokumen. |
