Menyediakan kelas dan antarmuka untuk mengonfigurasi berbagai opsi dan pengaturan yang terkait dengan perbandingan dokumen. Opsi-opsi ini mencakup pengaturan perbandingan, opsi pemuatan, opsi penyimpanan, pengaturan gaya, dan lainnya. Gunakan kelas-kelas ini untuk menyesuaikan perilaku dan tampilan proses perbandingan dokumen.

Kelas utama dalam paket ini:

* [CompareOptions](../../com.groupdocs.comparison.options/compareoptions) - Represents the options for document comparison.
* [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions) - Represents the options for loading documents.
* [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions) - Represents the options for saving comparison results.
* [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings) - Represents style settings for text formatting.


Untuk detail lebih lanjut tentang penggunaan kelas opsi dengan GroupDocs.Comparison untuk Java,
silakan merujuk ke [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).



## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [ApplyChangeOptions](../com.groupdocs.comparison.options/applychangeoptions) | Memungkinkan pembaruan daftar perubahan sebelum menerapkannya ke dokumen hasil. |
| [CompareOptions](../com.groupdocs.comparison.options/compareoptions) | Memungkinkan konfigurasi proses perbandingan dokumen. |
| [FileAuthorMetadata](../com.groupdocs.comparison.options/fileauthormetadata) | Memungkinkan konfigurasi informasi tentang metadata penulis dokumen. |
| [GetChangeOptions](../com.groupdocs.comparison.options/getchangeoptions) | Memungkinkan konfigurasi penyaringan untuk mengambil jenis perubahan tertentu dari hasil perbandingan. |
| [OriginalSize](../com.groupdocs.comparison.options/originalsize) | Mewakili ukuran asli dokumen dalam hasil perbandingan. |
| [PreviewOptions](../com.groupdocs.comparison.options/previewoptions) | Menyediakan opsi untuk menghasilkan pratinjau dokumen dalam proses perbandingan. |
