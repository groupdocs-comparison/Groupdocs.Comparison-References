Menyediakan kelas dan opsi untuk mengkonfigurasi pemuatan dokumen di GroupDocs.Comparison.


Kelas-kelas dalam paket ini digunakan untuk memuat dokumen sumber dan target dengan opsi tertentu.
Mereka menyediakan opsi untuk menentukan format dokumen, memuat dokumen yang dilindungi kata sandi,
menetapkan direktori font dan lainnya.


Kelas kunci dalam paket ini adalah [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions).
Kelas dalam paket memungkinkan Anda mengonfigurasi opsi dan pengaturan spesifik yang terkait dengan berbagai
format dokumen untuk perbandingan dokumen yang akurat dan disesuaikan.


Untuk detail lebih lanjut tentang memuat dan mengonfigurasi dokumen menggunakan GroupDocs.Comparison,
silakan merujuk ke [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
