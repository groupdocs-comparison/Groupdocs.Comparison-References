Menyediakan kelas dan opsi untuk menyimpan dan mengkonfigurasi output GroupDocs.Comparison.


Kelas-kelas dalam paket ini digunakan untuk menyimpan dan mengonfigurasi dokumen output dari proses perbandingan
di GroupDocs.Comparison. Mereka menyediakan opsi untuk menentukan metadata, kata sandi dokumen output, dan lainnya.


Kelas kunci dalam paket ini adalah [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions).
Kelas-kelas dalam paket ini memungkinkan Anda mengonfigurasi opsi dan pengaturan spesifik yang terkait dengan berbagai
format output untuk menghasilkan dokumen output yang diinginkan dari proses perbandingan.


Untuk detail lebih lanjut tentang menyimpan dan mengonfigurasi output menggunakan GroupDocs.Comparison,
silakan merujuk ke [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
