## WordCompareOptions.ShowRevisions property

Mendapatkan atau mengatur apakah dokumen hasil mempertahankan markup revisi tetap terlihat. Jika false, semua revisi diterima dan hasilnya muncul sebagai teks akhir. Pengaturan ini hanya bermakna ketika [`DisplayMode`](../displaymode) diatur ke Highlight. Nilai default adalah true.

public bool ShowRevisions { get; set; }
