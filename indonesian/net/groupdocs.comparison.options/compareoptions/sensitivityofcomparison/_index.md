## CompareOptions.SensitivityOfComparison property

Mendapatkan atau mengatur sensitivitas perbandingan.

```csharp
public int SensitivityOfComparison { get; set; }
```

### Property Value

Persentase elemen yang dihapus dan disisipkan dari dua objek yang dibandingkan relatif terhadap semua elemen objek tersebut. jika persentase ini terlampaui, objek tidak dibandingkan tetapi dianggap sepenuhnya disisipkan dan dihapus. Nilai minimum - 0% => Perbandingan tidak terjadi untuk panjang apa pun dari subsekuensi umum dua objek yang dibandingkan. Nilai default - 75% => Perbandingan terjadi jika persentase elemen yang dihapus dan disisipkan dari dua objek yang dibandingkan terhadap semua elemen objek tersebut tidak lebih dari 75. Nilai maksimum - 100% => Perbandingan terjadi pada panjang apa pun dari subsekuensi umum dua objek yang dibandingkan.
