Biedt uitzonderingen die kunnen worden gegooid tijdens het vergelijkingsproces in GroupDocs.Comparison.

De belangrijkste exceptieklassen in dit pakket zijn:

* [ComparisonException](../../com.groupdocs.comparison.common.exceptions/comparisonexception) - The base exception class for all exceptions related to document comparison.
* [InvalidPasswordException](../../com.groupdocs.comparison.common.exceptions/invalidpasswordexception) - The exception that is thrown when an invalid password is provided for a password-protected document.
* [UnsupportedFileFormatException](../../com.groupdocs.comparison.common.exceptions/unsupportedfileformatexception) - The exception that is thrown when file of this format is not supported by Comparison.


De excepties in dit pakket bieden specifieke foutafhandeling en rapportage voor veelvoorkomende bewerkingen in GroupDocs.Comparison.
Ze maken een meer gedetailleerde foutdetectie en -afhandeling mogelijk, waardoor ontwikkelaars adequaat kunnen reageren op verschillende foutscenario's.


Voor meer details over het werken met revisies en bijgehouden wijzigingen in Word-documenten met GroupDocs.Comparison voor Java,
raadpleeg de [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
