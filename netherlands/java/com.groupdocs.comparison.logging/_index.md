Biedt klassen en interfaces voor logging in GroupDocs.Comparison. De loggingfunctionaliteit stelt je in staat verschillende gebeurtenissen en berichten vast te leggen en te monitoren tijdens de uitvoering van het vergelijkingsproces.

De belangrijkste klassen en interfaces in dit pakket zijn:

* com.groupdocs.comparison.logging.ILogger - The interface that defines the contract for a logger.
* [ComparisonLogger](../../com.groupdocs.comparison.logging/comparisonlogger) - Provides methods and a way to configure integrated or set user defined logger.
* com.groupdocs.comparison.logging.ConsoleLogger - Provides logger implementation which sends all messages to console.


Door de logfunctionaliteit te gebruiken, kun je aanpassen hoe logberichten worden verwerkt,
zoals ze naar een bestand, console of een andere bestemming naar keuze te schrijven.


Voor meer details over het werken met revisies en bijgehouden wijzigingen in Word-documenten met GroupDocs.Comparison voor Java,
raadpleeg de [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
