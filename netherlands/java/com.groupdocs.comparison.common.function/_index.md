Biedt functionele interfaces die toegang tot paginagegevens mogelijk maken tijdens het documentvergelijkingsproces.

De functionele interfaces in dit pakket worden gebruikt om paginagegevens te benaderen bij het uitvoeren van documentvergelijking met GroupDocs.Comparison.

De belangrijkste functionele interfaces in dit pakket zijn:

* [CreatePageStreamFunction](../../com.groupdocs.comparison.common.function/createpagestreamfunction) - Allows handling creating output stream used by Comparison to save pages data.
* [ReleasePageStreamFunction](../../com.groupdocs.comparison.common.function/releasepagestreamfunction) - Allows handling releasing output stream used by Comparison to save pages data.


Deze functionele interfaces kunnen worden gebruikt om aangepaste logica en gedrag te definiëren bij het werken met documentpagina's.
Ze bieden flexibiliteit om aan te passen hoe en waar pagina's worden verwerkt.


Voor meer details over het werken met revisies en bijgehouden wijzigingen in Word-documenten met GroupDocs.Comparison voor Java,
raadpleeg de [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
