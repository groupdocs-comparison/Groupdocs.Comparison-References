Het pakket biedt klassen om documenten te vergelijken voor alle populaire documentformaten.

De belangrijkste klassen in dit pakket zijn:

* [Comparer](../../com.groupdocs.comparison/comparer) is the entry point for comparing documents.
* [Document](../../com.groupdocs.comparison/document) provides details about a document.
* [ComparerSettings](../../com.groupdocs.comparison/comparersettings) defines settings for customizing logging behaviour.


De hoofdklasse van deze namespace is [Comparer](../../com.groupdocs.comparison/comparer). Deze klasse biedt methoden voor het toevoegen van documenten, het verkrijgen van wijzigingen, het vergelijken van documenten enz.

| Klasse | Beschrijving |
| --- | --- |
| [Comparer](../com.groupdocs.comparison/comparer) | De Comparer-klasse biedt functionaliteit voor het vergelijken van documenten en het genereren van vergelijkingsresultaten. |
| [ComparerSettings](../com.groupdocs.comparison/comparersettings) | Definieert instellingen voor het aanpassen van het gedrag van de [Comparer](../com.groupdocs.comparison/comparer) klasse. |
| [Document](../com.groupdocs.comparison/document) | Stelt een document voor het vergelijkingsproces voor. |
