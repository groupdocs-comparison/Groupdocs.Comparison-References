Biedt klassen voor het werken met componentstijlen in Cells-formaatbestanden.


De klassen in dit pakket stellen je in staat om te werken met verschillende stijlen en opmaakopties die specifiek zijn voor Cells-indelingsbestanden (bijv. Excel-bestanden).

Belangrijke klassen in dit pakket omvatten:

* [MergeType](../../com.groupdocs.comparison.cells.style/mergetype) - Represents the enumeration the type of cell merge.
