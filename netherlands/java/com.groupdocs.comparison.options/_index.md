Biedt klassen en interfaces voor het configureren van verschillende opties en instellingen die verband houden met documentvergelijking. Deze opties omvatten vergelijkingsinstellingen, laadopties, opslaanopties, stijlinstellingen en meer. Gebruik deze klassen om het gedrag en de weergave van het documentvergelijkingsproces aan te passen.

Belangrijke klassen in dit pakket:

* [CompareOptions](../../com.groupdocs.comparison.options/compareoptions) - Represents the options for document comparison.
* [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions) - Represents the options for loading documents.
* [SaveOptions](../../com.groupdocs.comparison.options.save/saveoptions) - Represents the options for saving comparison results.
* [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings) - Represents style settings for text formatting.


Voor meer details over het werken met optieklassen met GroupDocs.Comparison voor Java,
raadpleeg de [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
