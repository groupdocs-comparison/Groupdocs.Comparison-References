Biedt hulpprogrammaklassen met methoden die nuttig kunnen zijn bij het gebruik van de GroupDocs.Comparison API.


De klassen in dit pakket bieden verschillende hulpmethoden die kunnen helpen bij het werken
met de GroupDocs.Comparison API en het uitvoeren van algemene taken gerelateerd aan documentvergelijking.

Belangrijke klassen in dit pakket omvatten:

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


Deze hulpprogrammaklassen zijn bedoeld om algemene taken te vereenvoudigen en handige methoden te bieden voor het werken
met bestanden, paden en streams in de context van documentvergelijking met behulp van de GroupDocs.Comparison API.


Voor meer details over het werken met revisies en bijgehouden wijzigingen in Word-documenten met GroupDocs.Comparison voor Java,
raadpleeg de [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/).
