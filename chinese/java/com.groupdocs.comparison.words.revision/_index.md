提供用于在 GroupDocs.Comparison for Java 比较过程中表示 Word 文档修订和跟踪更改的类和接口。


此包中的类用于表示在比较过程中对 Word 文档所做的修订和修订痕迹。
这些修订包括插入、删除、格式更改以及对文档内容的其他修改。


此包中的关键类包括 [RevisionHandler](../../com.groupdocs.comparison.words.revision/revisionhandler)，
[RevisionAction](../../com.groupdocs.comparison.words.revision/revisionaction), and [RevisionInfo](../../com.groupdocs.comparison.words.revision/revisioninfo).


通过使用此包中的类和接口，您可以访问、分析并操作 Word 文档中的修订和修订痕迹。


欲了解更多关于在 Java 中使用 GroupDocs.Comparison 处理 Word 文档的修订和修订痕迹的细节，
请参阅 [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/)。



## 类

| 类 | 描述 |
| --- | --- |
| [ApplyRevisionOptions](../com.groupdocs.comparison.words.revision/applyrevisionoptions) | ApplyRevisionOptions 类允许您在修订应用到最终文档之前更新其状态。 |
| [RevisionHandler](../com.groupdocs.comparison.words.revision/revisionhandler) | 表示控制修订处理的类。 |
| [RevisionInfo](../com.groupdocs.comparison.words.revision/revisioninfo) | 表示文档中的一次修订。 |
