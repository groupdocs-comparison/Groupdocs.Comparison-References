提供实用类及方法，可在使用 GroupDocs.Comparison API 时发挥作用。


此包中的类提供各种实用方法，可帮助进行
使用 GroupDocs.Comparison API 并执行与文档比较相关的常见任务。

此包中的关键类包括：

* [Utils](../../com.groupdocs.comparison.common/utils) - Provides common helper methods which can be useful when using Comparison API.


这些实用类旨在简化常见任务，并提供便捷的方法用于
在使用 GroupDocs.Comparison API 进行文档比较时处理文件、路径和流。


欲了解更多关于在 Java 中使用 GroupDocs.Comparison 处理 Word 文档的修订和修订痕迹的细节，
请参阅 [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/)。
