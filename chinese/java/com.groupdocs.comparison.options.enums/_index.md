提供 GroupDocs.Comparison 中各种选项和设置的枚举。


此包中的类包含定义不同选项和设置的枚举。
用于在 GroupDocs.Comparison 中进行自定义和配置目的。
这些枚举用作各种方法和类的参数，以控制行为
以及文档比较过程的外观。


此包中的一些关键枚举包括 [ChangeType](../../com.groupdocs.comparison.result/changetype)，
com.groupdocs.comparison.cells.style.ComparisonStyle，以及更多。
这些枚举允许您获取更改类型、比较样式
以及文档比较过程的其他选项。


欲了解可用选项的更多细节以及如何在 GroupDocs.Comparison 中使用它们，
请参阅 [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/)。



## 枚举

| 枚举类型 | 描述 |
| --- | --- |
| [ComparisonType](../com.groupdocs.comparison.options.enums/comparisontype) | 表示要执行的比较类型。 |
| [FolderComparisonExtension](../com.groupdocs.comparison.options.enums/foldercomparisonextension) | FolderComparisonExtension 类是一个枚举，表示可用于文件夹比较的不同文件扩展名。 |
| [MetadataType](../com.groupdocs.comparison.options.enums/metadatatype) | 确定结果文档将从何处获取元数据信息。 |
| [PaperSize](../com.groupdocs.comparison.options.enums/papersize) | 表示文档比较的纸张尺寸选项。 |
| [PasswordSaveOption](../com.groupdocs.comparison.options.enums/passwordsaveoption) | 枚举在比较过程中在文档中保存密码信息的选项。 |
| [PreviewFormats](../com.groupdocs.comparison.options.enums/previewformats) | 枚举文档比较支持的预览格式。 |
