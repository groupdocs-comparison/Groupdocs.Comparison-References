提供函数式接口，以便在文档比较过程中访问页面数据。

此包中的函数式接口用于在使用 GroupDocs.Comparison 进行文档比较时访问页面数据。

此包中的主要函数式接口有：

* [CreatePageStreamFunction](../../com.groupdocs.comparison.common.function/createpagestreamfunction) - Allows handling creating output stream used by Comparison to save pages data.
* [ReleasePageStreamFunction](../../com.groupdocs.comparison.common.function/releasepagestreamfunction) - Allows handling releasing output stream used by Comparison to save pages data.


这些函数式接口可用于在处理文档页面时定义自定义逻辑和行为。
它们提供灵活性，以自定义页面的处理方式和保存位置。


欲了解更多关于在 Java 中使用 GroupDocs.Comparison 处理 Word 文档的修订和修订痕迹的细节，
请参阅 [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/)。



## 接口

| 接口 | 描述 |
| --- | --- |
| [CreatePageStreamFunction](../com.groupdocs.comparison.common.function/createpagestreamfunction) | 用于创建 Comparison 保存预览图像的输出流的函数式接口。 |
| [ReleasePageStreamFunction](../com.groupdocs.comparison.common.function/releasepagestreamfunction) | 用于关闭 Comparison 用于保存预览图像的输出流的函数式接口。 |
