提供用于处理文档比较结果的类和接口。比较结果包括有关更改、修订、差异以及其他比较相关数据的信息。

此包中的关键类：

* [ChangeInfo](../../com.groupdocs.comparison.result/changeinfo) - Represents information about a specific change in the comparison result.
* [PageInfo](../../com.groupdocs.comparison.result/pageinfo) - Represents information about a page in the comparison result.
* [StyleChangeInfo](../../com.groupdocs.comparison.result/stylechangeinfo) - Represents information about a style change in a compared document.


欲了解使用 GroupDocs.Comparison for Java 处理比较过程结果的更多细节，
请参阅 [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/)。



## 类

| 类 | 描述 |
| --- | --- |
| [ChangeInfo](../com.groupdocs.comparison.result/changeinfo) | ChangeInfo 类表示文档比较中特定更改的信息。 |
| [PageInfo](../com.groupdocs.comparison.result/pageinfo) | PageInfo 类表示文档中特定页面的信息。 |
| [Rectangle](../com.groupdocs.comparison.result/rectangle) | Rectangle 类表示文档上的更改区域。 |
| [StyleChangeInfo](../com.groupdocs.comparison.result/stylechangeinfo) | StyleChangeInfo 类表示已比较文档中样式更改的信息。 |
