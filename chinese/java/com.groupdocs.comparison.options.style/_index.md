提供用于在 GroupDocs.Comparison 中对文档比较输出的视觉外观进行样式设置和配置的类和选项。


此包中的类用于定义和自定义文档比较输出的各种样式方面，例如颜色，
高亮、下划线等。它们允许您控制比较结果中添加、删除和修改内容的视觉外观。


此包中的关键类包括 [StyleSettings](../../com.groupdocs.comparison.options.style/stylesettings)。
包中的类提供方法和属性，以定义和配置比较结果中不同组件和元素的样式设置。
您可以设置字体样式、颜色、高亮、下划线以及其他格式选项，以实现所需的更改视觉呈现。


欲了解使用 GroupDocs.Comparison 对文档比较输出的样式和外观进行配置的更多细节，
请参阅 [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/)。



## 类

| 类 | 描述 |

| [StyleSettings](../com.groupdocs.comparison.options.style/stylesettings) | 此类表示文本格式的样式设置。 |
