提供用于 GroupDocs.Comparison 本地化的类和接口。本地化功能允许您根据不同语言或地区偏好自定义比较过程中显示的文本和消息。

此包中的主要类和接口有：

* [SupportedLocales](../../com.groupdocs.comparison.localization/supportedlocales) - A class provides constants representing the supported locales for GroupDocs.Comparison.


通过使用本地化功能，您可以自定义 GroupDocs.Comparison 中使用的文本和消息，以匹配用户的语言或偏好。


欲了解更多关于在 Java 中使用 GroupDocs.Comparison 处理 Word 文档的修订和修订痕迹的细节，
请参阅 [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/)。
