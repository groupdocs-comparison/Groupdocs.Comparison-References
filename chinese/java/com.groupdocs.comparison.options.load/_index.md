提供用于在 GroupDocs.Comparison 中配置加载文档的类和选项。


此包中的类用于使用特定选项加载源文档和目标文档。
它们提供用于指定文档格式、加载受密码保护的文档的选项，
设置字体目录等。


此包中的关键类是 [LoadOptions](../../com.groupdocs.comparison.options.load/loadoptions)。
包中的类允许您配置与不同相关的特定选项和设置
文档格式，以实现准确且定制的文档比较。


有关使用 GroupDocs.Comparison 加载和配置文档的更多详细信息，
请参阅 [GroupDocs.Comparison Documentation](../https://docs.groupdocs.com/comparison/java/)。
