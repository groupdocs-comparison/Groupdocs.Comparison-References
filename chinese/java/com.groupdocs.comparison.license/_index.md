提供用于处理 GroupDocs.Comparison 许可证的类。


此包中的类允许您管理和应用 GroupDocs.Comparison 的许可证。
您可以加载和设置许可证文件，检查许可证状态，并执行与许可证相关的操作。


要使用与许可证相关的功能，您需要 GroupDocs 提供的有效许可证文件。
您可以使用 [License](../../com.groupdocs.comparison.license/license) 类加载许可证文件，然后将其应用于 GroupDocs.Comparison 库。


有关在 GroupDocs.Comparison 中使用许可证的更多详细信息，请参阅
[Licensing FAQ](../https://purchase.groupdocs.com/faqs/licensing).
