## WordCompareOptions.ShowRevisions property

获取或设置结果文档是否保持修订标记可见。如果为 false，所有修订均被接受，结果显示为最终文本。仅当 [`DisplayMode`](../displaymode) 设置为 Highlight 时，此设置才有意义。默认值为 true。

```csharp
public bool ShowRevisions { get; set; }
```
