该命名空间提供允许为文档比较过程指定附加选项的类。

## 类

| 类 | 描述 |
| --- | --- |
| [ApplyChangeOptions](./applychangeoptions) | 允许在将更改应用到生成的文档之前更新更改列表。 |
| [CompareOptions](./compareoptions) | 允许设置不同的比较选项。 |
| [DiagramMasterSetting](./diagrammastersetting) | 图表主设置。 |
| [FileAuthorMetadata](./fileauthormetadata) | 有关文档作者元数据的信息。 |
| [GetChangeOptions](./getchangeoptions) | 此选项允许按类型过滤更改。 |
| [IgnoreChangeSensitivitySettings](./ignorechangesensitivitysettings) | 此选项允许根据相似度百分比忽略更改。 |
| [LoadOptions](./loadoptions) | 允许在加载文档时指定其他选项。 |
| [OriginalSize](./originalsize) | 表示原始页面尺寸。仅用于比较不同格式的图像。 |
| [PagesSetup](./pagessetup) | 指定在比较中包含哪些页面。 |
| [PdfCompareOptions](./pdfcompareoptions) | PDF 文档特定的比较选项。继承自 [`CompareOptions`](../groupdocs.comparison.options/compareoptions) 的通用选项。 |
| [PreviewOptions](./previewoptions) | 表示文档预览选项。 |
| [PreviewResolution](./previewresolution) | 表示文档预览生成的分辨率设置。 |
| [SaveOptions](./saveoptions) | 允许在保存文档时指定其他选项（例如密码）。 |
| [Size](./size) | 文档大小。 |
| [StyleSettings](./stylesettings) | 样式设置。允许为更改定义样式规则。用于 [`CompareOptions`](../groupdocs.comparison.options/compareoptions) 类中。 |
| [WordCompareOptions](./wordcompareoptions) | Word 文档特定的比较选项。继承自 [`CompareOptions`](../groupdocs.comparison.options/compareoptions) 的通用选项。 |
